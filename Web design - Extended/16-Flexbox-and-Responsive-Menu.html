CSS — подреждане с Flexbox и адаптивно меню

Всички предметиУеб дизайн - СППУеб дизайн - Учебна практикаУеб дизайн - Разширена подготовка

След урока ще можете да:

  • различавате flex контейнер от неговите елементи;
  • управлявате посока, пренасяне и разстояния;
  • създавате меню, използваемо на широк и тесен екран.

1. Контейнер и елементи

Flexbox подрежда непосредствените деца на контейнер по една основна ос. Задаваме display: flex на родителя, а връзките в него стават flex елементи. Вложен текст или икона вътре във връзка не става отделен елемент на външното меню.

При flex-direction: row подредбата е по ред, а при column — по колона. Посоката на основната ос влияе на значението на подравняването. Не използвайте визуално пренареждане, за да прикриете нелогичен ред в HTML: клавиатурната навигация трябва да остава разбираема.

2. Разстояние и свободно място

gap задава разстояние между елементите. justify-content управлява разпределението по основната ос, а align-items — по напречната. Това са различни задачи от вътрешния отстъп padding на отделния бутон.

За меню с дълги български надписи оставете възможност за пренасяне чрез flex-wrap: wrap. Не смалявайте текста до нечетим размер само за да поберете всички връзки на един ред.

3. Адаптивно меню

При тесен екран една колона често е по-разбираема от претъпкан ред. Използвайте медийна заявка, която сменя посоката, когато подредбата вече не се побира. Изборът на граница се проверява с реалните надписи, не само с имената на модели телефони.

Менюто трябва да работи и без мишка. Използвайте истински връзки, видим фокус и достатъчно място около надписите. Ако няма нужда от скрито меню, видимата колона е напълно подходящо решение и не изисква JavaScript.

Пример

.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 0.75rem;
  align-items: center;
}
.menu a { padding: 0.6rem 1rem; }
@media (max-width: 40rem) {
  .menu { flex-direction: column; align-items: stretch; }
}

Класът menu се поставя върху nav, съдържащ връзките. В HTML запазете смисления ред на страниците.

Практическа задача

  1. Създайте меню с „Начало“, „Нашите проекти“, „Предстоящи събития“ и „Контакти“.
  2. Приложете примерния CSS и сравнете широк и тесен прозорец.
  3. Добавете още една дълга връзка и проверете пренасянето.
  4. Преминете с Tab, активирайте връзка с Enter и проверете видимия фокус.
  5. Сравнете margin, padding и gap: променете само едно от тях и опишете разликата.

Предавате: HTML и CSS файловете, два изгледа на менюто и кратко описание на проверките.

Самопроверка

Къде се задава display: flex?

На контейнера, чиито непосредствени деца искаме да подредим.

Какво прави flex-wrap?

Позволява пренасяне на елементите на нов ред, когато няма достатъчно място.

Нужен ли е JavaScript за видимо меню в колона?

Не. Тази подредба може да се реализира само с HTML и CSS.
