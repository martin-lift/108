  • letter-spacing – променя разредката между символите. Може да бъде normal (без промяна на разредката) или число с мерна единица. Може да приема отрицателни стойности.

p {
  text-align: justify;
  font-family: 'Times New Roman';
  font-size: 12px;
  color: #00ffff;
  font-weight: bold
  line-height: 1;
}

Форматиране на фон

Външният вид на уеб сайта зависи от използването на подходящи фонове както на целите страници, така и на отделните елементи.

Цветът на фона се задава, като на свойството background-color се присвоява стойност в някой от приложимите формати.

Пример:

h1 {background-color: red;}

За фон на уеб елемент може да се използва и изображение. То се задава с background-image. За посочване на пътя до избраното изображение се използва функцията url('URL').

Пример:

body {
  background-image: url('proba.gif');
}

По подразбиране изображението се повтаря вертикално и хоризонтално до запълване на целия елемент. Свойството background-repeat служи за управление на запълването.

Приема стойности: repeat – изображението се повтаря както хоризонтално, така и вертикално, repeat-x (repeat-y) – изображението се повтаря само хоризонтално (вертикално), no-repeat – изображението не се повтаря.

Пример:

body {
  background-image: url('proba.gif');
  background-repeat: repeat-y;
}

В примера изображението ще се повтаря по вертикала.

Свойството background-attachment определя дали фоновото изображение ще е фиксирано спрямо видимата област от страницата (fixed), или ще се движи при превъртане с елемента (scroll).

Пример:

body {
  background-image: url('proba.gif');
  background-repeat: repeat-y;
  background-attachment: fixed;
}

В примера изображението е фиксирано.

Свойството background-position определя началната позиция на изображението. Задават се хоризонтална и вертикална стойност в проценти или мерни единици, или комбинация от служебните думи left, center, right (за хоризонтално позициониране) и top, center, bottom (за вертикално). Ако е посочена само една стойност, другата се приема за center.

Пример:

body {
  background-image: url('banner.jpeg');
  background-repeat: no-repeat;
}
body { background-position: right top; }
/* аналогично на background-position:
  100% 0% */
body { background-position: top center; }
/* 50% 0% */
body { background-position: center; }
/* 50% 50% */
body { background-position: bottom; }
/* 50% 100% */

Използване на рамки

Основни свойства за рамки:

  • border-color – цвят на рамката.
  • border-style – стил на рамката, който има няколко варианта (none, dotted, dashed, solid, double, groove, ridge, inset, outset), фиг. 1.
  • border-width – дебелина на рамката, която се определя в пиксели или друга мерна единица.

Изброените свойства могат да се задават като списък от до 4 стойности (както описахме по-горе) или отделно, напр. border-top-color, border-right-width, border-bottom-style и т.н. Много често рамката се задава в съкратен формат:

border: border-width border-style border-color;
