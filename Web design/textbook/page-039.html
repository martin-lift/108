Добавяне и използване на шрифтове

Както споменахме по-рано, на текстовите елементи се задават шрифтове със свойството font-family. По подразбиране браузърът използва само шрифтовете, налични в системата. За да има алтернатива, задаваме списък с разделител запетая (,). Имена, които съдържат интервал, се поставят в кавички, напр. 'Times New Roman'.

Пример:

p {
  font-family: Tahoma, Verdana, sans-serif;
}

Браузърът ще потърси Tahoma, ако не е достъпен – Verdana. Ако и той липсва, ще се използва sans-serif, който е от набора универсални шрифтове, налични във всички браузъри: sans-serif, serif, monospace, cursive, fantasy.

За да сме сигурни, че документът се показва, както очакваме, можем да добавим шрифт, наличен на сървъра, чрез CSS правилото @font-face:

@font-face {
  font-family: myFont;
  src: url(myfont_file.woff);
}

След това използваме във font-family както обикновено:

Пример:

p {
  font-family: myFont, 'Times New Roman', serif;
}

Уеб услуги за шрифтове

Удобен начин да разнообразим визията на сайта с различни шрифтове са уеб услугите. Една от най-използваните е Google Fonts, предлагаща над 1000 шрифтови семейства. На адрес https://fonts.google.com/ можем да търсим и разглеждаме, като настройваме различни параметри – категории, езици, размер, стил и др. След като изберем нужните ни начертания, услугата предлага готов код, който да вмъкнем в нашата страница (фиг. 2):

<style>
  @import
  url('https://fonts.googleapis.com/css2?family=Open+Sans&display=swap');
</style>

Показания код с правилото @import вмъкваме в секцията <head> на HTML документа или, без тага <style>, в началото на нашия външен CSS файл. След това можем да използваме шрифта по стандартния начин:

font-family: 'Open Sans', sans-serif;
