# Test-Student.ps1

**Цел:** проверява от учителския компютър дали конкретен ученически компютър може да бъде администриран през WinRM.

**Употреба:** `.\Test-Student.ps1 -Number 24`

**Действия:** сглобява `307-Student-24.local`, проверява TCP/5985, иска интерактивно локалната администраторска парола за `307-Student-24\108SU`; изпълнява само четене: `hostname`, `whoami`, WinRM status и LATFP; проверява дали отдалеченият hostname е очакваният.

**Резултат:** успешен или неуспешен тест. При невъзможно разрешаване на .local името първо диагностицирайте mDNS/LLMNR/мрежата. При `Access is denied` проверявайте Security event 4625 и данните за вход; не променяйте UAC на сляпо.

**Ограничения:** проверката не удостоверява криптографски името на отдалечената машина; изисква предварително настроен TrustedHosts и достъпен WinRM; не доказва всички административни операции и не променя конфигурацията.
