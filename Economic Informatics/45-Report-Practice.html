Урок 45: Обобщен отчет – упражнение

За какво е този урок?

Отчетът съчетава таблица, диаграма и извод с числова опора. Ще сравните брой и стойност, всички и платени продажби и ще проверите четимостта при печат.

Как работим с формули?

Формулата започва със знак =. Използваме английски имена на функциите и разделител ;. Ако програмата изисква запетая между аргументите, заменете ; с ,. Десетичният разделител зависи от настройките. За постоянен процент можете да въведете 10% вместо десетично число.

За избор на клетка или диапазон въведете адреса в полето за име вляво от лентата за формули и натиснете Enter. За копиране надолу използвайте малкия квадрат в долния десен ъгъл на избраната клетка. Excel и LibreOffice Calc поддържат тези действия. При препратка към друг лист изберете клетките с мишката — Excel обикновено показва !, а Calc може да показва точка.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 45-report-practice-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Създайте отчет по търговец

Маркирайте Продажби!A1:P25. Excel: Insert → PivotTable → From Table/Range; изберете New Worksheet. Calc: Data → Pivot Table → Insert or Edit → Current selection; в Source and Destination изберете New sheet. Настройте полетата според задачата и наречете получения лист По търговец. В Calc можете да оставите диалога отворен до настройване на задължителните полета. При по-късни промени отворете Data → Pivot Table → Edit Layout.

Поставете Търговец в Rows в Excel или Row Fields в Calc.

В Excel плъзнете Стойност в Values; от менюто на полето → Value Field Settings → Summarize Values By → Sum. В Calc плъзнете Стойност в Data Fields; двойно щракване върху полето → Function = Sum. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

В Excel плъзнете Номер в Values; от менюто на полето → Value Field Settings → Summarize Values By → Count. В Calc плъзнете Номер в Data Fields; двойно щракване върху полето → Function = Count. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

Проверка: Анна 447,60; Борис 727,45; Вера 601,00 EUR; по 8 записа.

Задача 2. Създайте отчет по продукт и месец

Маркирайте Продажби!A1:P25. Excel: Insert → PivotTable → From Table/Range; изберете New Worksheet. Calc: Data → Pivot Table → Insert or Edit → Current selection; в Source and Destination изберете New sheet. Настройте полетата според задачата и наречете получения лист По продукт и месец. В Calc можете да оставите диалога отворен до настройване на задължителните полета. При по-късни промени отворете Data → Pivot Table → Edit Layout.

Поставете Продукт в Rows в Excel или Row Fields в Calc.

Поставете Дата в Columns / Column Fields, а Стойност във Values / Data Fields с функция Sum. Групирайте датите по Years и Months.

Проверка: Общата стойност на всички продукти за трите месеца е 1776,05 EUR.

Задача 3. Добавете филтри за статус

Поставете Статус в Filters в Excel или Page Fields / Filter Fields в Calc. Изберете желания обхват от филтъра над отчета.

Добавете това поле и в двата отчета. Първо оставете всички статуси.

Задача 4. Визуализирайте сравнението

Създайте лист Отчет. Добавете колонна PivotChart към отчета по търговец със само показателя за сума в EUR. Не поставяйте броя продажби като втора парична серия. При нужда създайте отделна малка Pivot само със Стойност, свързана към същия източник, и дайте същия филтър за статус.

Щракнете вътре в съответната Pivot таблица. Excel → PivotTable Analyze → PivotChart; изберете Column → Clustered Column. Calc → Insert → Chart — програмата трябва да разпознае Pivot източника; изберете Column → Clustered Column. Не включвайте общия резултат като отделна категория. Заглавие Всички продажби по търговец (EUR); числова ос в EUR; без 3D ефекти.

Преместете диаграмата в Отчет чрез Move Chart в Excel или изрязване и поставяне на рамката в Calc.

Задача 5. Посочете водещия продукт

По обобщението за всички статуси в Отчет!A3 запишете „Принтерна хартия — най-голяма обща стойност: 411,25 EUR“. Уточнете, че това са всички продажби преди отстъпки. Не го наричайте най-голямо количество.

Проверка: Следва Тетрадка с 382,50 EUR.

Задача 6. Сравнете всички и платените продажби

Създайте лист „Всички търговци“ с бутона +. От По търговец копирайте сумите и броя за всички статуси и поставете само стойностите: Excel → Paste Special → Values; Calc → Edit → Paste Special → Paste Only Values. Това е запазено наблюдение, което не се обновява автоматично.

Създайте лист „Всички продукти“ с бутона +. От По продукт и месец копирайте пълното обобщение за всички статуси и поставете само стойностите: Excel → Paste Special → Values; Calc → Edit → Paste Special → Paste Only Values. Това е запазено наблюдение, което не се обновява автоматично.

В основните Pivot отчети изберете Платена. Ако има отделна Pivot за диаграмата, задайте същия филтър и там и обновете заглавието ѝ на „Платени продажби по търговец (EUR)“. В Отчет!A4 и A5 запишете два извода с обхват и числа. Например: „Всички продажби са 1776,05 EUR, а платените са 242,60 EUR.“ и „По всички продажби води Борис — 727,45 EUR; по платени води Вера — 127,20 EUR.“

Не изваждайте тези суми, за да твърдите автоматично неплатен дълг: сред останалите статуси има и Отказана.

Задача 7. Настройте и прегледайте печата

В Отчет подредете диаграмата и изводите без припокриване. Excel → Page Layout → Print Area → Set Print Area; Scale to Fit: Width = 1 page, Height = Automatic. Calc → Format → Print Ranges → Define; Format → Page Style → Sheet → Scale: fit print range to width 1 page, височина без принудително ограничение. Изберете Landscape, ако помага. Отворете File → Print / Print Preview и проверете, че заглавията и числата се четат; не намалявайте текста до нечетим размер.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате завършената работа.

  1. File → Save As (Запиши като).
  2. Excel: Documents → 45-full-Ime-Familia.xlsx; формат Excel Workbook (.xlsx). Calc: Documents → 45-full-Ime-Familia.ods; формат ODF Spreadsheet (.ods). Заменете Ime-Familia с вашето име и фамилия.
  3. Използвайте собствения формат на програмата, за да запазите обобщаващите таблици и връзките на диаграмите. Предава се само един файл, според използваната програма.
  4. Запишете, затворете и отворете отново същия файл в същата програма. Проверете полетата, филтрите и обобщенията. Запишете с Ctrl+S.

Какво трябва да остане: Двата основни отчета с филтър Платена; запазени обобщения за всички статуси; Отчет с подходяща диаграма, водещ продукт, два числови извода и настройка за една страница по ширина.
