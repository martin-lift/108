Урок 42: Обобщени таблици – конфигуриране

За какво е този урок?

Функцията във Values определя дали виждате сума, средна или брой. Ще поставите едно поле два пъти с различни функции и ще групирате истински дати по месеци и години.

Как работим с формули?

Формулата започва със знак =. Използваме английски имена на функциите и разделител ;. Ако програмата изисква запетая между аргументите, заменете ; с ,. Десетичният разделител зависи от настройките. За постоянен процент можете да въведете 10% вместо десетично число.

За избор на клетка или диапазон въведете адреса в полето за име вляво от лентата за формули и натиснете Enter. За копиране надолу използвайте малкия квадрат в долния десен ъгъл на избраната клетка. Excel и LibreOffice Calc поддържат тези действия. При препратка към друг лист изберете клетките с мишката — Excel обикновено показва !, а Calc може да показва точка.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 42-pivot-configuration-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Създайте обобщение по продукт

Маркирайте Продажби!A1:P25. Excel: Insert → PivotTable → From Table/Range; изберете New Worksheet. Calc: Data → Pivot Table → Insert or Edit → Current selection; в Source and Destination изберете New sheet. Настройте полетата според задачата и наречете получения лист По продукт. В Calc можете да оставите диалога отворен до настройване на задължителните полета. При по-късни промени отворете Data → Pivot Table → Edit Layout.

Поставете Продукт в Rows в Excel или Row Fields в Calc.

В Excel плъзнете Стойност в Values; от менюто на полето → Value Field Settings → Summarize Values By → Sum. В Calc плъзнете Стойност в Data Fields; двойно щракване върху полето → Function = Sum. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

Задача 2. Проверете сумата и числовия формат

Проверете Sum, а не Count за Стойност. Excel → Value Field Settings → Number Format → Number, два знака. Calc → маркирайте числовите резултати → Ctrl+1 → Number, два знака. Оставете стойностите числови.

Проверка: Принтерна хартия: 411,25 EUR.

Задача 3. Добавете средната стойност

Добавете Стойност втори път в Values / Data Fields.

В Excel плъзнете Стойност в Values; от менюто на полето → Value Field Settings → Summarize Values By → Average. В Calc плъзнете Стойност в Data Fields; двойно щракване върху полето → Function = Average. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

При нужда преименувайте двата показателя на Обща стойност и Средна продажба, за да се различават. Средната е на първичен запис, не средно от групови средни.

Проверка: Принтерна хартия: 102,8125 EUR, показани като 102,81.

Задача 4. Добавете брой продажби

В Excel плъзнете Номер в Values; от менюто на полето → Value Field Settings → Summarize Values By → Count. В Calc плъзнете Номер в Data Fields; двойно щракване върху полето → Function = Count. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

Проверка: За всеки продукт има 4 записа; общо 24. Не сумирайте текстовите номера.

Задача 5. Подредете продуктите по стойност

Excel → десен бутон върху стойност от Sum → Sort → Largest to Smallest. Calc → Edit Layout → двойно щракване върху Продукт в Row Fields → Options → Sort by сумата на Стойност, Descending. Не сортирайте по Average или по име.

Проверка: Принтерна хартия; Тетрадка; Класьор; Папка; Маркер; Химикал.

Задача 6. Създайте отделно обобщение по месеци

Маркирайте Продажби!A1:P25. Excel: Insert → PivotTable → From Table/Range; изберете New Worksheet. Calc: Data → Pivot Table → Insert or Edit → Current selection; в Source and Destination изберете New sheet. Настройте полетата според задачата и наречете получения лист По месеци. В Calc можете да оставите диалога отворен до настройване на задължителните полета. При по-късни промени отворете Data → Pivot Table → Edit Layout.

Поставете Дата в Rows в Excel или Row Fields в Calc.

В Excel плъзнете Стойност в Values; от менюто на полето → Value Field Settings → Summarize Values By → Sum. В Calc плъзнете Стойност в Data Fields; двойно щракване върху полето → Function = Sum. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

В обобщението изберете една истинска дата. Excel → десен бутон → Group → Months и Years. Calc → Data → Group and Outline → Group → интервали Months и Years. Не групирайте само по име на месец, когато има няколко години.

Проверка: 2026: септември 544,80; октомври 713,55; ноември 517,70 EUR при всички продажби.

Задача 7. Сравнете трите показателя

В Продажби!P27 опишете за Принтерна хартия: обща стойност 411,25 EUR, средна продажба 102,8125 EUR, брой 4. Проверете 102,8125 × 4 = 411,25. Не умножавайте показаната закръглена 102,81, за да проверявате точната сума.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате завършената работа.

  1. File → Save As (Запиши като).
  2. Excel: Documents → 42-full-Ime-Familia.xlsx; формат Excel Workbook (.xlsx). Calc: Documents → 42-full-Ime-Familia.ods; формат ODF Spreadsheet (.ods). Заменете Ime-Familia с вашето име и фамилия.
  3. Използвайте собствения формат на програмата, за да запазите обобщаващите таблици и връзките на диаграмите. Предава се само един файл, според използваната програма.
  4. Запишете, затворете и отворете отново същия файл в същата програма. Проверете полетата, филтрите и обобщенията. Запишете с Ctrl+S.

Какво трябва да остане: По продукт със Sum, Average и Count и подредба по обща стойност; По месеци с трите месеца на 2026; сравнение P27.
