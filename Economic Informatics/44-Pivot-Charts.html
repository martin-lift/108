Урок 44: Обобщени диаграми

За какво е този урок?

PivotChart показва обобщени данни и реагира на филтрите на своята Pivot таблица. Колонната диаграма сравнява търговци, а линейната показва месечна динамика. Ще обозначите обхвата и единиците.

Как работим с формули?

Формулата започва със знак =. Използваме английски имена на функциите и разделител ;. Ако програмата изисква запетая между аргументите, заменете ; с ,. Десетичният разделител зависи от настройките. За постоянен процент можете да въведете 10% вместо десетично число.

За избор на клетка или диапазон въведете адреса в полето за име вляво от лентата за формули и натиснете Enter. За копиране надолу използвайте малкия квадрат в долния десен ъгъл на избраната клетка. Excel и LibreOffice Calc поддържат тези действия. При препратка към друг лист изберете клетките с мишката — Excel обикновено показва !, а Calc може да показва точка.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 44-pivot-charts-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Обобщете стойността по търговец

Маркирайте Продажби!A1:P25. Excel: Insert → PivotTable → From Table/Range; изберете New Worksheet. Calc: Data → Pivot Table → Insert or Edit → Current selection; в Source and Destination изберете New sheet. Настройте полетата според задачата и наречете получения лист По търговец. В Calc можете да оставите диалога отворен до настройване на задължителните полета. При по-късни промени отворете Data → Pivot Table → Edit Layout.

Поставете Търговец в Rows в Excel или Row Fields в Calc.

В Excel плъзнете Стойност в Values; от менюто на полето → Value Field Settings → Summarize Values By → Sum. В Calc плъзнете Стойност в Data Fields; двойно щракване върху полето → Function = Sum. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

Поставете Статус в Filters в Excel или Page Fields / Filter Fields в Calc. Изберете желания обхват от филтъра над отчета.

Първоначално оставете всички статуси.

Задача 2. Добавете колонна обобщена диаграма

Щракнете вътре в съответната Pivot таблица. Excel → PivotTable Analyze → PivotChart; изберете Column → Clustered Column (Групирана колонна). Calc → Insert → Chart — програмата трябва да разпознае Pivot източника; изберете Column → Clustered Column (Групирана колонна). Не включвайте общия резултат като отделна категория. Заглавие Продажби по търговец (EUR); числова ос в EUR; без 3D ефекти.

Проверка: Три колони: 447,60; 727,45; 601,00 EUR.

Задача 3. Уточнете заглавие и единици

Променете заглавието на колонната диаграма на „Стойност на продажбите по търговец“. Задайте заглавие на числовата ос EUR. Оста трябва да започва от 0 и да не смесва количество и стойност.

Задача 4. Създайте отделно обобщение по месец

Маркирайте Продажби!A1:P25. Excel: Insert → PivotTable → From Table/Range; изберете New Worksheet. Calc: Data → Pivot Table → Insert or Edit → Current selection; в Source and Destination изберете New sheet. Настройте полетата според задачата и наречете получения лист По месеци. В Calc можете да оставите диалога отворен до настройване на задължителните полета. При по-късни промени отворете Data → Pivot Table → Edit Layout.

Поставете Дата в Rows в Excel или Row Fields в Calc.

В Excel плъзнете Стойност в Values; от менюто на полето → Value Field Settings → Summarize Values By → Sum. В Calc плъзнете Стойност в Data Fields; двойно щракване върху полето → Function = Sum. Числово поле трябва да остане число; текстовият Номер се брои с Count за непразни записи.

Поставете Статус в Filters в Excel или Page Fields / Filter Fields в Calc. Изберете желания обхват от филтъра над отчета.

В обобщението изберете една истинска дата. Excel → десен бутон → Group → Months и Years. Calc → Data → Group and Outline → Group → интервали Months и Years. Не групирайте само по име на месец, когато има няколко години.

Проверка: 2026: септември 544,80; октомври 713,55; ноември 517,70 EUR при всички продажби.

Задача 5. Добавете линейна обобщена диаграма

Щракнете вътре в съответната Pivot таблица. Excel → PivotTable Analyze → PivotChart; изберете Line with Markers (Линейна с маркери). Calc → Insert → Chart — програмата трябва да разпознае Pivot източника; изберете Line with Markers (Линейна с маркери). Не включвайте общия резултат като отделна категория. Заглавие Стойност на продажбите по месец (EUR); числова ос в EUR; без 3D ефекти.

Проверка: Три точки в ред септември, октомври, ноември 2026; 544,80, 713,55 и 517,70 EUR.

Задача 6. Проверете реакцията при филтър

Създайте лист „Всички търговци“ с бутона +. От По търговец копирайте обобщените числови резултати при всички статуси и поставете само стойностите: Excel → Paste Special → Values; Calc → Edit → Paste Special → Paste Only Values. Това е запазено наблюдение, което не се обновява автоматично.

Създайте лист „Всички месеци“ с бутона +. От По месеци копирайте обобщените резултати за трите месеца при всички статуси и поставете само стойностите: Excel → Paste Special → Values; Calc → Edit → Paste Special → Paste Only Values. Това е запазено наблюдение, което не се обновява автоматично.

Във всяка от двете Pivot таблици изберете Статус = Платена. Проверете, че свързаната диаграма се променя. Това са два отделни отчета — промяната на единия филтър не гарантира промяна на другия.

Проверка: По търговец: 22,50; 92,90; 127,20. По месец: 78,50; 57,60; 106,50 EUR. Общата стойност е 242,60.

Задача 7. Подредете отчета и запишете извод

Създайте лист „Отчет“. Преместете двете диаграми в него, без да ги превръщате в изображения: Excel → Chart Design → Move Chart → Object in Отчет; Calc → изберете рамката → Ctrl+X, отворете Отчет → Ctrl+V. Разположете ги една под друга или една до друга, без да закриват клетки с изводи. В A1 запишете „Платени продажби — EUR“, а в A3 кратък извод с число, например „Най-голяма платена стойност има Вера: 127,20 EUR“.

Calc: създаване на PivotChart.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате завършената работа.

  1. File → Save As (Запиши като).
  2. Excel: Documents → 44-full-Ime-Familia.xlsx; формат Excel Workbook (.xlsx). Calc: Documents → 44-full-Ime-Familia.ods; формат ODF Spreadsheet (.ods). Заменете Ime-Familia с вашето име и фамилия.
  3. Използвайте собствения формат на програмата, за да запазите обобщаващите таблици и връзките на диаграмите. Предава се само един файл, според използваната програма.
  4. Запишете, затворете и отворете отново същия файл в същата програма. Проверете полетата, филтрите и обобщенията. Запишете с Ctrl+S.

Какво трябва да остане: По търговец и По месеци с филтър Платена; числовите наблюдения за всички статуси; Отчет с двете свързани диаграми и числов извод.
