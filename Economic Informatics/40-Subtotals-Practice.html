Урок 40: Списъци и междинни суми – упражнение

За какво е този урок?

Ще сравните два разреза на едни и същи продажби: по търговец и по продукт. Отделните копия запазват междинните суми, а SUMIF върху първичните записи служи за независима проверка.

Как работим с формули?

Формулата започва със знак =. Използваме английски имена на функциите и разделител ;. Ако програмата изисква запетая между аргументите, заменете ; с ,. Десетичният разделител зависи от настройките. За постоянен процент можете да въведете 10% вместо десетично число.

За избор на клетка или диапазон въведете адреса в полето за име вляво от лентата за формули и натиснете Enter. За копиране надолу използвайте малкия квадрат в долния десен ъгъл на избраната клетка. Excel и LibreOffice Calc поддържат тези действия. При препратка към друг лист изберете клетките с мишката — Excel обикновено показва !, а Calc може да показва точка.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 40-subtotals-practice-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Създайте копие по търговец

За копие на лист: Excel → десен бутон върху раздела → Move or Copy → Create a copy; Calc → Sheet → Move or Copy Sheet → Copy. Дайте посоченото ново име.

Наречете копието „По търговец“.

Задача 2. Обобщете стойността по търговец

В По търговец маркирайте целия диапазон A1:P25 → Data → Sort. Посочете, че първият ред е със заглавия. Ключ Търговец, ред Ascending. Сортирайте всички колони заедно, никога само една колона.

Excel: Data → Subtotal. At each change in = Търговец; Use function = Sum; Add subtotal to = Стойност (K). Calc: Data → Subtotals; 1st Group → Group by = Търговец; отбележете Стойност (K) и функция Sum. Източникът трябва да е предварително сортиран по Търговец. При подготвена Excel таблица първо Table Design → Convert to Range.

Проверка: 447,60; 727,45; 601,00 EUR.

Задача 3. Създайте отделно копие по продукт

За копие на лист: Excel → десен бутон върху раздела → Move or Copy → Create a copy; Calc → Sheet → Move or Copy Sheet → Copy. Дайте посоченото ново име.

Направете второ копие на оригиналния Продажби — не на листа с вече вмъкнати междинни редове. Наречете го „По продукт“.

В По продукт маркирайте целия диапазон A1:P25 → Data → Sort. Посочете, че първият ред е със заглавия. Ключ Продукт, ред Ascending. Сортирайте всички колони заедно, никога само една колона.

Задача 4. Обобщете количества и стойности по продукт

Excel: Data → Subtotal. At each change in = Продукт; Use function = Sum; Add subtotal to = Количество (H) и Стойност (K). Calc: Data → Subtotals; 1st Group → Group by = Продукт; отбележете Количество (H) и Стойност (K) и функция Sum. Източникът трябва да е предварително сортиран по Продукт. При подготвена Excel таблица първо Table Design → Convert to Range.

Проверка: Тетрадка: 85 броя, 382,50 EUR. Принтерна хартия: 47 броя, 411,25 EUR. Общото количество е 363, общата стойност — 1776,05.

Задача 5. Създайте независими контроли

В оригиналния Продажби въведете: R2 =SUMIF(C2:C25;"Анна";K2:K25), R3 същото за Борис, R4 същото за Вера. Не включвайте междинните листове в тези диапазони.

Проверка: 447,60; 727,45; 601,00 EUR.

Задача 6. Намерете водещия търговец

Сравнете трите контролни суми с груповите резултати. Най-големият оборот е на Борис: 727,45 EUR. Това е стойност на всички учебни продажби преди отстъпки, а не непременно получени плащания.

Задача 7. Напишете извод с числова опора

В Продажби!P27 запишете извод за водещ търговец и продукт по стойност: Борис — 727,45 EUR; Принтерна хартия — 411,25 EUR. Уточнете показателя и че разглеждате всичките 24 продажби. Най-голямо количество и най-голяма стойност не са един и същ показател.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате лесно завършената работа.

  1. Изберете File (Файл) → Save As (Запиши като); в Excel при нужда Browse (Преглед).
  2. Изберете Documents (Документи) и име 40-full-Ime-Familia.xlsx, като замените Ime-Familia с вашето име и фамилия.
  3. Запазете като Excel Workbook (.xlsx). В Calc потвърдете използването на Excel 2007–365 формат, ако програмата попита.
  4. Затворете и отворете отново същия файл. Проверете резултата и запишете с Ctrl+S.

Какво трябва да остане: Продажби с R2:R4 и извод P27; По търговец със суми K; По продукт със суми H и K.
