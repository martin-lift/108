Урок 32: Проверка на въведените данни

За какво е този урок?

Проверката на данни ограничава въвеждането. Ще зададете правила за количества, цени, дати и дължина на код; ще добавите помощ и блокираща грешка и ще проверите граничните стойности.

Как работим с формули?

Формулата започва със знак =. Използваме английски имена на функциите и разделител ;. Ако програмата изисква запетая между аргументите, заменете ; с ,. Десетичният разделител зависи от настройките. За постоянен процент можете да въведете 10% вместо десетично число.

За избор на клетка или диапазон въведете адреса в полето за име вляво от лентата за формули и натиснете Enter. За копиране надолу използвайте малкия квадрат в долния десен ъгъл на избраната клетка. Excel и LibreOffice Calc поддържат тези действия. При препратка към друг лист изберете клетките с мишката — Excel обикновено показва !, а Calc може да показва точка.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 32-data-validation-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Ограничете количествата

Изберете H2:H25.

  • Excel: Data (Данни) → Data Validation (Проверка на данни) → Settings (Настройки). Allow = Whole number, Data = between, Minimum = 1, Maximum = 100.
  • Calc: Data → Validity (Валидност) → Criteria (Критерии). Allow = Whole Numbers, Data = between, Minimum = 1, Maximum = 100.

Проверка: Допускат се цели числа от 1 до 100 включително.

Задача 2. Добавете помощ и блокираща грешка

За H2:H25 отворете отново диалога за проверка на данни. Excel → Input Message: включете съобщение „Количество: 1–100“; Error Alert: включете показването на грешка и Style = Stop. Calc → Input Help: включете същото съобщение; Error Alert: включете Show error message и Action = Stop. Запишете ясна грешка, която обяснява допустимия вход. Stop блокира обикновеното директно въвеждане на невалидна стойност.

Задача 3. Ограничете цените

Изберете I2:I25.

  • Excel: Data (Данни) → Data Validation (Проверка на данни) → Settings (Настройки). Allow = Custom; формула =AND(ISNUMBER(I2);I2>0;I2<=1000).
  • Calc: Data → Validity (Валидност) → Criteria (Критерии). Allow = Custom; формула =AND(ISNUMBER(I2);I2>0;I2<=1000).

За I2:I25 отворете отново диалога за проверка на данни. Excel → Input Message: включете съобщение „Цена: положително число до 1000 EUR“; Error Alert: включете показването на грешка и Style = Stop. Calc → Input Help: включете същото съобщение; Error Alert: включете Show error message и Action = Stop. Запишете ясна грешка, която обяснява допустимия вход. Stop блокира обикновеното директно въвеждане на невалидна стойност.

Относителният ред I2 позволява всеки ред да проверява собствената си цена. Нулата не е положителна цена.

Задача 4. Ограничете датите

Изберете B2:B25.

  • Excel: Data (Данни) → Data Validation (Проверка на данни) → Settings (Настройки). Allow = Date, Data = between; начална дата =DATE(2026;9;1), крайна =DATE(2026;11;30).
  • Calc: Data → Validity (Валидност) → Criteria (Критерии). Allow = Date, Data = between; въведете начална 2026-09-01 и крайна 2026-11-30 като дати.

За B2:B25 отворете отново диалога за проверка на данни. Excel → Input Message: включете съобщение „Дата: от 01.09.2026 до 30.11.2026 включително“; Error Alert: включете показването на грешка и Style = Stop. Calc → Input Help: включете същото съобщение; Error Alert: включете Show error message и Action = Stop. Запишете ясна грешка, която обяснява допустимия вход. Stop блокира обикновеното директно въвеждане на невалидна стойност.

Задача 5. Ограничете дължината на кода

Изберете E2:E25.

  • Excel: Data (Данни) → Data Validation (Проверка на данни) → Settings (Настройки). Allow = Text length, Data = equal to, Length = 4.
  • Calc: Data → Validity (Валидност) → Criteria (Критерии). Allow = Text length, Data = equal to, Length = 4.

За E2:E25 отворете отново диалога за проверка на данни. Excel → Input Message: включете съобщение „Код: точно 4 символа“; Error Alert: включете показването на грешка и Style = Stop. Calc → Input Help: включете същото съобщение; Error Alert: включете Show error message и Action = Stop. Запишете ясна грешка, която обяснява допустимия вход. Stop блокира обикновеното директно въвеждане на невалидна стойност.

Дължина 4 не доказва, че кодът съществува в каталога. За това е необходим списък или отделна справочна проверка.

Задача 6. Проверете четирите гранични входа

В H2 опитайте последователно директно въвеждане на 0, 1, 100 и 101. При блокирана стойност натиснете Cancel (Отказ), за да остане последната допустима. В P2 напишете кои стойности са приети и кои — отхвърлени. Накрая върнете първоначалното H2 = 5.

Проверка: 1 и 100 са приети; 0 и 101 са блокирани.

Задача 7. Проверете съществуващите данни

Excel → Data → Data Validation → Circle Invalid Data. Calc → Tools → Detective → Mark Invalid Data. Проверете маркираните клетки; при първоначалните данни не трябва да има нарушения на създадените четири правила. В P3 запишете резултата от проверката и че H2 отново е 5. Правилата не поправят автоматично старите стойности; поставяне на данни може да заобиколи част от проверките, затова тази последна проверка е полезна.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате лесно завършената работа.

  1. Изберете File (Файл) → Save As (Запиши като); в Excel при нужда Browse (Преглед).
  2. Изберете Documents (Документи) и име 32-full-Ime-Familia.xlsx, като замените Ime-Familia с вашето име и фамилия.
  3. Запазете като Excel Workbook (.xlsx). В Calc потвърдете използването на Excel 2007–365 формат, ако програмата попита.
  4. Затворете и отворете отново същия файл. Проверете резултата и запишете с Ctrl+S.

Какво трябва да остане: Четирите правила за H, I, B и E, съобщенията и Stop; H2 = 5; резултатите от проверките в P2:P3.
