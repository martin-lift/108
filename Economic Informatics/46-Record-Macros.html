Урок 46: Макроси в Excel – записване

За какво е този урок?

Използвайте настолния Excel или LibreOffice Calc и останете в същата програма за записа и проверката. Excel за уеб не създава и не изпълнява VBA макроси. Excel записва VBA в .xlsm; Calc записва LibreOffice Basic в .ods. Това са различни технологии и не разчитаме на прехвърляне на записания код между програмите.

Макросът повтаря записани действия. Ще запишете само оформление, ще го изпълните върху копие и ще проверите, че е съхранен в самата работна книга.

Как работим с макроси?

Excel: File → Options → Customize Ribbon → включете Developer. Calc: ако Tools → Macros → Record Macro липсва, Tools → Options → LibreOffice → Advanced → Enable macro recording. Използвайте само собствените макроси в учебното копие; началният файл няма макроси.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 46-record-macros-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Запазете във формат за макроси

Използвайте настолния Excel или LibreOffice Calc и останете в същата програма за записа и проверката. Excel за уеб не създава и не изпълнява VBA макроси. Excel записва VBA в .xlsm; Calc записва LibreOffice Basic в .ods. Това са различни технологии и не разчитаме на прехвърляне на записания код между програмите.

Преди запис изберете File → Save As. Excel: 46-full-Ime-Familia.xlsm, тип Excel Macro-Enabled Workbook. Calc: 46-full-Ime-Familia.ods, тип ODF Spreadsheet. Заменете Ime-Familia с вашето име. Не запазвайте завършения макрос в .xlsx.

Задача 2. Подгответе програмата и листа

Excel: File → Options → Customize Ribbon → включете Developer. Calc: ако Tools → Macros → Record Macro липсва, Tools → Options → LibreOffice → Advanced → Enable macro recording. Използвайте само собствените макроси в учебното копие; началният файл няма макроси.

Отворете лист Продажби. Заглавията в изчистения файл са без удебеляване, а числата са без фиксирани два знака, за да се вижда промяната. Запомнете първите стойности: количество 5, цена 4,5 и стойност 22,5. Макросът ще променя само оформлението.

Задача 3. Започнете FormatReport

Excel: в активния учебен лист изключете Developer → Use Relative References за абсолютния запис. Developer → Record Macro, име FormatReport, Store macro in = This Workbook, без клавишна комбинация. Calc: Tools → Macros → Record Macro; името и мястото се избират след спиране. Не превключвайте към други документи или листове по време на записа.

Не съхранявайте в Personal Macro Workbook / My Macros, защото те няма да бъдат предадени с файла.

Задача 4. Запишете оформлението на заглавията

Докато записът е включен, изберете A1:P1 чрез полето за име и Enter. Excel → Home → Bold и Wrap Text. Calc → Ctrl+1 → Font → Bold и Alignment → Wrap text automatically. Ако използвате избор в Calc, предпочитайте клавиатурата; записът на избор с мишката е ограничен. Не въвеждайте нови стойности в таблицата.

Задача 5. Запишете числовия формат и спрете

По време на същия запис изберете I2:M25. Ctrl+1 → Number / Numbers → Number, два десетични знака. Потвърдете.

Excel: Developer → Stop Recording. Calc: Stop Recording → в Save macro in изберете самия текущ документ, а не My Macros. В него Standard → създайте модул при нужда, име на макроса FormatReport → Save. Записът трябва да се съхрани в предавания файл.

В Проверка!B2 запишете името FormatReport и че е в текущия документ. Тази бележка се въвежда след спирането на записа.

Задача 6. Изпробвайте върху копие

За копие на лист: Excel → десен бутон върху раздела → Move or Copy → Create a copy; Calc → Sheet → Move or Copy Sheet → Copy. Дайте посоченото ново име.

Копирайте Продажби като Тест. В Тест изключете Bold и Wrap Text на A1:P1 и задайте General за I2:M25. Изберете клетка от Тест и изпълнете FormatReport. По време на първоначалния запис не е трябвало да се записва преминаване към конкретен лист, за да работи оформлението върху активното копие.

За изпълнение: Excel → Developer → Macros → FormatReport → Run; Calc → Tools → Macros → Run Macro → текущият документ → Standard → модулът → FormatReport → Run. Уверете се, че е активен правилният лист.

Проверка: И Тест получава получер, пренасяне и два знака; входните количества и цени остават същите.

В Проверка!B3 запишете какво се възстанови.

Задача 7. Проверете съхранението на макроса

Запишете в .xlsm за Excel или .ods за Calc. Затворете и отворете отново собствения файл в същата програма. Проверете в списъка с макроси дали FormatReport е наличен в документа. Ако програмата пита за изпълнение, разрешавайте само собствения запис в това учебно копие. В Проверка!B4 запишете резултата и отново запазете.

Excel: запис на макрос · Calc: запис и ограничения.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате завършената работа.

  1. File → Save As (Запиши като).
  2. Excel: Documents → 46-full-Ime-Familia.xlsm; формат Excel Macro-Enabled Workbook (.xlsm). Calc: Documents → 46-full-Ime-Familia.ods; формат ODF Spreadsheet (.ods). Заменете Ime-Familia с вашето име и фамилия.
  3. Използвайте собствения формат на програмата, за да запазите макросите. Предава се само един файл, според използваната програма.
  4. Запишете, затворете и отворете отново същия файл в същата програма. Проверете че собствените ви макроси са налични в книгата, а не само в личната библиотека. Запишете с Ctrl+S.

Какво трябва да остане: Продажби и Тест с правилно оформление, макрос FormatReport в документа и три наблюдения в Проверка. Предава се .xlsm от Excel или .ods от Calc.
