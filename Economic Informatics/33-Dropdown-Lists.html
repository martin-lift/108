Урок 33: Падащи списъци – упражнение

За какво е този урок?

Падащите списъци ограничават входа до общ справочник. Ще използвате именувани диапазони за статуси и кодове и ще създадете формуляр с три проверявани полета.

Как работим с формули?

Формулата започва със знак =. Използваме английски имена на функциите и разделител ;. Ако програмата изисква запетая между аргументите, заменете ; с ,. Десетичният разделител зависи от настройките. За постоянен процент можете да въведете 10% вместо десетично число.

За избор на клетка или диапазон въведете адреса в полето за име вляво от лентата за формули и натиснете Enter. За копиране надолу използвайте малкия квадрат в долния десен ъгъл на избраната клетка. Excel и LibreOffice Calc поддържат тези действия. При препратка към друг лист изберете клетките с мишката — Excel обикновено показва !, а Calc може да показва точка.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 33-dropdown-lists-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Прегледайте допустимите статуси

В Справочници!K2:K5 има точно четири статуса: Платена, Нова, Отказана, Изпратена. Заглавието K1 не участва в списъка. Уеднаквените стойности позволяват надеждни справки.

Задача 2. Дайте име на диапазона за статуси

В Справочници изберете K2:K5. Excel → Formulas → Define Name; Calc → Sheet → Named Ranges and Expressions → Define. Име Статуси, обхват на името Workbook / Document (целият документ). Проверете абсолютния адрес към Справочници и потвърдете.

Задача 3. Създайте списък за статусите

Изберете J2:J25.

  • Excel: Data (Данни) → Data Validation (Проверка на данни) → Settings (Настройки). Allow = List, Source = =Статуси; включете In-cell dropdown.
  • Calc: Data → Validity (Валидност) → Criteria (Критерии). Allow = Cell range, Source = Статуси; включете Show selection list.

Проверка: При избор на клетка от J има стрелка с четирите статуса.

Задача 4. Създайте списък за кодовете

В Справочници изберете A2:A7. Excel → Formulas → Define Name; Calc → Sheet → Named Ranges and Expressions → Define. Име Кодове, обхват на името Workbook / Document (целият документ). Проверете абсолютния адрес към Справочници и потвърдете.

Изберете E2:E25.

  • Excel: Data (Данни) → Data Validation (Проверка на данни) → Settings (Настройки). Allow = List, Source = =Кодове; включете In-cell dropdown.
  • Calc: Data → Validity (Валидност) → Criteria (Критерии). Allow = Cell range, Source = Кодове; включете Show selection list.

Проверка: Списъкът съдържа P001–P006, без заглавие.

Задача 5. Добавете помощ и блокираща грешка

За J2:J25 отворете отново диалога за проверка на данни. Excel → Input Message: включете съобщение „Изберете статус от списъка“; Error Alert: включете показването на грешка и Style = Stop. Calc → Input Help: включете същото съобщение; Error Alert: включете Show error message и Action = Stop. Запишете ясна грешка, която обяснява допустимия вход. Stop блокира обикновеното директно въвеждане на невалидна стойност.

За E2:E25 отворете отново диалога за проверка на данни. Excel → Input Message: включете съобщение „Изберете съществуващ код“; Error Alert: включете показването на грешка и Style = Stop. Calc → Input Help: включете същото съобщение; Error Alert: включете Show error message и Action = Stop. Запишете ясна грешка, която обяснява допустимия вход. Stop блокира обикновеното директно въвеждане на невалидна стойност.

Задача 6. Проверете двата списъка

Опитайте директно да въведете „Непознат“ в J2 и P999 в E2. И двата опита трябва да бъдат блокирани; натиснете Cancel. После изберете допустими стойности от стрелките. Накрая оставете първоначалните J2 = Платена и E2 = P001. В Проверки!B2:B4 запишете реакциите при невалиден статус, невалиден код и допустим избор.

Проверка: Невалидният вход е блокиран, допустимият избор е приет.

Задача 7. Подгответе формуляр с проверки

В лист Формуляр вече има полета, без условия за работа в самия файл. За B2 задайте списък Кодове; за B3 — цяло число между 1 и 100; за B4 — списък Статуси. Добавете подходящи входни съобщения и Stop за всяко поле. Попълнете един допустим запис: P001, 5, Платена. Имената са с обхват на целия документ, за да работят и на този лист.

Calc: дефиниране на имена.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате лесно завършената работа.

  1. Изберете File (Файл) → Save As (Запиши като); в Excel при нужда Browse (Преглед).
  2. Изберете Documents (Документи) и име 33-full-Ime-Familia.xlsx, като замените Ime-Familia с вашето име и фамилия.
  3. Запазете като Excel Workbook (.xlsx). В Calc потвърдете използването на Excel 2007–365 формат, ако програмата попита.
  4. Затворете и отворете отново същия файл. Проверете резултата и запишете с Ctrl+S.

Какво трябва да остане: Двата именувани диапазона; списъци E и J със Stop; E2 = P001 и J2 = Платена; попълнен валиден Формуляр и резултатите в Проверки.
