Урок 47: Макроси – упражнение

За какво е този урок?

Използвайте настолния Excel или LibreOffice Calc и останете в същата програма за записа и проверката. Excel за уеб не създава и не изпълнява VBA макроси. Excel записва VBA в .xlsm; Calc записва LibreOffice Basic в .ods. Това са различни технологии и не разчитаме на прехвърляне на записания код между програмите.

Абсолютният макрос използва записан адрес. Относителният работи спрямо активната позиция. Ще проверите разликата върху два блока и ще опишете границите на повторението.

Как работим с макроси?

Excel: File → Options → Customize Ribbon → включете Developer. Calc: ако Tools → Macros → Record Macro липсва, Tools → Options → LibreOffice → Advanced → Enable macro recording. Използвайте само собствените макроси в учебното копие; началният файл няма макроси.

Работен файл

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено ги записва там.

  1. Натиснете Windows + E и отворете File Explorer (Файлов мениджър) → Downloads (Изтегляния), или избраното от вас място.
  2. Отворете 47-macro-practice-clean.xlsx в Excel или Calc. Ако Excel покаже Enable Editing (Разрешаване на редактирането), натиснете го.

Файлът съдържа само данни, заглавия и места за резултатите. Жълтите клетки са за работа. Условията и обясненията са в урока.

Задача 1. Запазете собствено копие с макроси

Използвайте настолния Excel или LibreOffice Calc и останете в същата програма за записа и проверката. Excel за уеб не създава и не изпълнява VBA макроси. Excel записва VBA в .xlsm; Calc записва LibreOffice Basic в .ods. Това са различни технологии и не разчитаме на прехвърляне на записания код между програмите.

Excel: 47-full-Ime-Familia.xlsm, Excel Macro-Enabled Workbook. Calc: 47-full-Ime-Familia.ods, ODF Spreadsheet. Записвайте и тествайте само в това копие.

Задача 2. Запишете абсолютен макрос

Excel: File → Options → Customize Ribbon → включете Developer. Calc: ако Tools → Macros → Record Macro липсва, Tools → Options → LibreOffice → Advanced → Enable macro recording. Използвайте само собствените макроси в учебното копие; началният файл няма макроси.

Excel: в активния учебен лист изключете Developer → Use Relative References за абсолютния запис. Developer → Record Macro, име HeaderAbsolute, Store macro in = This Workbook, без клавишна комбинация. Calc: Tools → Macros → Record Macro; името и мястото се избират след спиране. Не превключвайте към други документи или листове по време на записа.

По време на записа изберете A1:P1 чрез полето за име и приложете Bold и Wrap Text. Това записва фиксираната област на активния лист.

Excel: Developer → Stop Recording. Calc: Stop Recording → в Save macro in изберете самия текущ документ, а не My Macros. В него Standard → създайте модул при нужда, име на макроса HeaderAbsolute → Save. Записът трябва да се съхрани в предавания файл.

Задача 3. Подгответе два еднакви блока

Създайте лист „Блокове“ с бутона +. В A1:C4 въведете таблица: заглавия Продукт, Количество, Цена EUR; Тетрадка, 5, 4,5; Папка, 20, 6; Химикал, 12, 2,4. Копирайте я в A7:C10. Заглавията трябва първоначално да са без получер и без пренасяне, за да се вижда ефектът на макроса.

Задача 4. Създайте относителен макрос

Excel: преди запис изберете Блокове!A1. Включете Developer → Use Relative References → Record Macro, име HeaderRelative, This Workbook. С клавиатурата задръжте Shift и натиснете Right два пъти, за да изберете трите клетки от текущата позиция. Задайте Bold и Wrap Text и спрете записа. По време на относителния запис не избирайте фиксиран адрес чрез полето за име.

Calc: няма същия Excel превключвател за относителен VBA запис. За същата учебна цел използвайте кратък Basic макрос, който взема началната позиция от избраната клетка. Tools → Macros → Organize Macros → Basic → текущият документ → Standard → модул → Edit. Въведете следния макрос в модула и запазете в документа:

Sub HeaderRelative
  Dim a As Variant, s As Object, h As Object
  a = ThisComponent.CurrentSelection.getRangeAddress()
  s = ThisComponent.Sheets.getByIndex(a.Sheet)
  h = s.getCellRangeByPosition(a.StartColumn, a.StartRow, a.StartColumn + 2, a.StartRow)
  h.CharWeight = 150
  h.IsTextWrapped = True
End Sub

Изберете една клетка, преди да го изпълнявате. Кодът форматира три клетки на същия ред, започвайки от текущата позиция. При нужда изпълнете го от A1, за да оформите първото заглавие, както при записа в Excel.

Задача 5. Изпълнете от втория блок

Изберете точно A7, а не целия диапазон, и изпълнете HeaderRelative.

За изпълнение: Excel → Developer → Macros → HeaderRelative → Run; Calc → Tools → Macros → Run Macro → текущият документ → Standard → модулът → HeaderRelative → Run. Уверете се, че е активен правилният лист.

Проверка: Форматират се A7:C7 — заглавието на втория блок. Данните на редове 8–10 остават същите.

Задача 6. Сравнете с абсолютния адрес

В Блокове изберете F7 и изпълнете HeaderAbsolute. Проверете коя област се променя. Ако записът не съдържа фиксирано преминаване към лист Продажби, той ще приложи записания A1:P1 върху активния лист Блокове, независимо от F7.

За изпълнение: Excel → Developer → Macros → HeaderAbsolute → Run; Calc → Tools → Macros → Run Macro → текущият документ → Standard → модулът → HeaderAbsolute → Run. Уверете се, че е активен правилният лист.

Проверка: Абсолютният адрес е A1:P1, а не областта до активната F7. Относителният пример от A7 е A7:C7.

Задача 7. Запишете правилата за повторение

В Блокове!E2:E4 запишете: в E2 — работим върху копие и първо проверяваме активния лист; в E3 — HeaderAbsolute използва фиксиран A1:P1, HeaderRelative — три клетки от текущата позиция; в E4 — размерът не се разширява автоматично при нова таблица и Undo може да не възстанови изпълненото от макрос. Проверете, че и двата макроса са в самия документ и че количествата и цените в двата блока са запазени.

Проверка и записване

Documents (Документи) е стандартна папка в Windows за личните ви документи и работни файлове. Използвайте я, за да намирате завършената работа.

  1. File → Save As (Запиши като).
  2. Excel: Documents → 47-full-Ime-Familia.xlsm; формат Excel Macro-Enabled Workbook (.xlsm). Calc: Documents → 47-full-Ime-Familia.ods; формат ODF Spreadsheet (.ods). Заменете Ime-Familia с вашето име и фамилия.
  3. Използвайте собствения формат на програмата, за да запазите макросите. Предава се само един файл, според използваната програма.
  4. Запишете, затворете и отворете отново същия файл в същата програма. Проверете че собствените ви макроси са налични в книгата, а не само в личната библиотека. Запишете с Ctrl+S.

Какво трябва да остане: Макроси HeaderAbsolute и HeaderRelative в документа; Продажби и Блокове с двата еднакви блока, изпълнените проверки и бележки E2:E4. Предава се .xlsm от Excel или .ods от Calc.
