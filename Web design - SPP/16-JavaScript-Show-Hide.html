JavaScript - Показване и скриване на съдържание чрез бутон

Свържете бутон с JavaScript функция, която показва и скрива допълнителна информация.

След урока ще можете да:

  • избирате HTML елемент чрез неговия id;
  • свързвате събитието click с функция;

1. Как работи задачата

HTML създава бутона и блока с подробности. В началото блокът има атрибут hidden и не се показва. JavaScript реагира на избиране на бутона и сменя това състояние.

  • document.querySelector("#info") намира елемента с id="info".
  • const задава име, чрез което използваме намерения елемент.
  • function toggleInfo() описва действията, които искаме да се изпълняват заедно.
  • ! обръща логическата стойност: истина става неистина и обратно.
  • addEventListener("click", toggleInfo) свързва функцията със събитието.

aria-controls посочва управлявания блок, а aria-expanded описва дали той е разгънат. Променяме и надписа на бутона, за да е ясно какво ще стане при следващото натискане.

6. JavaScript — поведението

const button = document.querySelector("#toggle-info");
const info = document.querySelector("#info");

function toggleInfo() {
  info.hidden = !info.hidden;
  button.setAttribute("aria-expanded", String(!info.hidden));

  if (info.hidden) {
    button.textContent = "Покажи подробности";
  } else {
    button.textContent = "Скрий подробности";
  }
}

button.addEventListener("click", toggleInfo);

  1. Създайте пример в CodePen и проверете първоначалното състояние.
  2. Заменете текста с пояснение към вашия проект.

9. Самопроверка

Защо използваме различни id?

id трябва да е уникално в документа, за да можем да изберем точно желания елемент.

Изпълнява ли се функцията веднага при addEventListener?

Не. Предаваме функцията като действие, което да се изпълни при събитието click.

Изтриваме ли текста при скриване?

Не. Елементът остава в документа; променя се състоянието hidden.
