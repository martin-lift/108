Адаптивна уеб страница — упражнение

Променете готова страница така, че да се използва удобно на телефон и компютър.

1. Припомнете си адаптивния дизайн

Уеб страниците се разглеждат на смартфони, таблети, лаптопи и настолни компютри. Добрият дизайн осигурява удобно четене и използване при различни размери на екрана.

Адаптивният дизайн (responsive design) позволява съдържанието и подредбата да се приспособяват към наличното пространство.

При проектиране е важно:

  • Подредбата да е гъвкава. Няколко колони на широк екран могат да се подредят в една колона на телефон.
  • Текстът да е четим. Потребителят трябва да може да чете без увеличаване на страницата.
  • Изображенията да се побират в екрана. Те трябва да запазват пропорциите си и да не излизат извън съдържанието.
  • Навигацията да е удобна. Менютата и бутоните трябва да се използват лесно както с мишка, така и с докосване.
  • Да няма ненужно хоризонтално превъртане. Основното съдържание трябва да се побира в ширината на екрана.

Често се започва с дизайн за малък екран – подходът mobile first. След това оформлението се разширява за по-големи екрани.

Практическа задача: Скицирайте една и съща уеб страница за телефон и за компютър. Покажете как се променят менюто, колоните и изображенията, като запазите основното съдържание.

2. Начален файл и откриване на проблемите

Изтеглете страницата за упражнение. Отворете я в редактор и в браузър. Изображението е вградено във файла, така че не са необходими допълнителни файлове.

Началният вариант нарочно има фиксирани размери. Първо го разгледайте в широк прозорец, после стеснете прозореца. Запишете: има ли хоризонтално превъртане, побира ли се изображението и колко място остава за текста?

.site { width: 960px; margin: auto; }
.layout { display: flex; gap: 24px; }
.intro { width: 620px; }
.card { width: 300px; }
.intro img { width: 620px; height: 240px; }

3. Добавете viewport

В head добавете следния елемент. Той позволява на мобилния браузър да използва ширината на устройството за изгледа на страницата:

<meta name="viewport" content="width=device-width,initial-scale=1">

Самият viewport не поправя фиксираните размери в CSS. След него трябва да промените и правилата за подредба.

4. Заменете фиксираните размери

В CSS намерете петте правила за .site, .layout, .intro, .card и .intro img. Заменете ги със следните правила, вместо да оставяте старите по-долу:

* { box-sizing: border-box; }
.site { width: calc(100% - 2rem); max-width: 960px; margin: auto; }
.layout { display: grid; grid-template-columns: 2fr 1fr; gap: 24px; }
.intro, .card { min-width: 0; }
.intro img { max-width: 100%; height: auto; display: block; }
nav { flex-wrap: wrap; }
@media (max-width: 700px) {
  .layout { grid-template-columns: 1fr; }
  h1 { font-size: 1.8rem; }
}
  • max-width ограничава ширината на голям екран, без да принуждава тесния екран да я побере.
  • max-width: 100% и height: auto запазват пропорциите на изображението.
  • При ширина до 700 пиксела медийната заявка подрежда колоните в една колона.
  • flex-wrap позволява на връзките в менюто да преминат на нов ред.
  • box-sizing: border-box включва рамката и вътрешните отстъпи в зададената ширина.

5. Проверете в няколко размера

  1. Запазете файла и презаредете браузъра.
  2. Сравнете ширини около 390, 700 и 1100 пиксела чрез преоразмеряване или режима за устройства в браузъра.
  3. Проверете текста, менюто, изображението и блока за срещата.
  4. Уверете се, че няма ненужно хоризонтално превъртане.
  5. Преминете с клавиша Tab през двете връзки в менюто и проверете накъде водят.
  6. Променете заглавието с по-дълъг текст и проверете отново.

За сравнение след собствената работа отворете примерния адаптивен вариант. Не прикривайте проблемите чрез overflow-x: hidden: първо поправете елемента, който излиза извън екрана.

Резултат: работеща адаптивна страница и кратки бележки кои правила сте променили и какво сте проверили.

6. Самопроверка

Достатъчно ли е да добавим viewport?

Не. Трябва да премахнем и неподходящите фиксирани размери и да приспособим подредбата.

Защо height: auto е полезно за изображението?

При променяща се ширина височината се определя така, че пропорциите да се запазят.

Кога се прилага @media (max-width: 700px)?

Когато ширината на изгледа е най-много 700 CSS пиксела, включително точно 700.

Защо проверяваме и междинен размер?

Проблем може да се появи преди или след смяната на подредбата, а не само на най-тесния екран.
