Обобщаващи таблици и диаграми — упражнение

Всички уроци

За какво е този урок?

Обобщаване, филтриране, сравняване на сума и средна стойност и обновяване на данни.

След добавяне на запис разширете източника и обновете отчета. Филтър за януари и февруари няма да покаже ред от май. Различните състояния се запазват в отделни отчети.

Изтеглете и отворете файла

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено записва файла там.

  1. Натиснете Windows + E, отворете File Explorer (Файлов мениджър) и Downloads (Изтегляния). Ако сте избрали друго място при изтеглянето, отворете него.
  2. Отворете 18-pivot-tables-charts-exercise-clean.xlsx с Excel или Calc. В Excel натиснете Enable Editing (Разрешаване на редактирането), ако се появи такава лента.

Работният файл съдържа само данни и места за резултати. Всички задачи и обяснения са тук, в мисията.

Обобщаващата таблица групира записите и изчислява обобщения. Обобщаващата диаграма е свързана с нея. Готовите резултати запишете като .xlsx в Excel или .ods в Calc, за да запазите обектите в собствения формат на програмата.

Задача 1. Обобщение по региони и категории

Източник: лист Данни, диапазон A1:F13. Създайте отделна обобщаваща таблица в нов лист 1-Суми.

  1. Върнете се в източника и маркирайте диапазона заедно със заглавията.
  2. Excel: Insert (Вмъкване) → PivotTable (Обобщаваща таблица) → New Worksheet (Нов работен лист) → OK. Преименувайте новия лист на 1-Суми.
  3. Calc: Data (Данни) → Pivot Table (Обобщаваща таблица) → Insert or Edit (Вмъкване или редактиране) → Current selection (Текуща селекция). В Source and Destination (Източник и местоназначение) изберете New sheet (Нов лист). След създаването го преименувайте на 1-Суми.
  4. Разположете полетата така: Регион в Rows (Строки) / Row Fields (Полета по редове), Категория в Columns (Колони) / Column Fields (Полета по колони), Продажби във Values (Стойности) / Data Fields (Полета с данни), с функция Sum (Сума). Останалите области са празни.
  5. За избор на функцията: Excel → Value Field Settings (Настройки на поле за стойности); Calc → двукратно щракване върху полето в Data Fields. Потвърдете функцията и диалозите.

Проверка: Общата сума е 51300 лв. Запад — 16200; Изток — 18000; Юг — 17100. Оставете този отчет без филтър.

Задача 2. Филтър за януари и февруари

Източник: лист Данни, диапазон A1:F13. Създайте отделна обобщаваща таблица в нов лист 2-Филтър.

  1. Върнете се в източника и маркирайте диапазона заедно със заглавията.
  2. Excel: Insert (Вмъкване) → PivotTable (Обобщаваща таблица) → New Worksheet (Нов работен лист) → OK. Преименувайте новия лист на 2-Филтър.
  3. Calc: Data (Данни) → Pivot Table (Обобщаваща таблица) → Insert or Edit (Вмъкване или редактиране) → Current selection (Текуща селекция). В Source and Destination (Източник и местоназначение) изберете New sheet (Нов лист). След създаването го преименувайте на 2-Филтър.
  4. Разположете полетата така: Регион в Rows (Строки) / Row Fields (Полета по редове), Категория в Columns (Колони) / Column Fields (Полета по колони), Продажби във Values (Стойности) / Data Fields (Полета с данни), с функция Sum (Сума), Месец във Filters (Филтри) / Page Fields (Полета на страница). Останалите области са празни.
  5. За избор на функцията: Excel → Value Field Settings (Настройки на поле за стойности); Calc → двукратно щракване върху полето в Data Fields. Потвърдете функцията и диалозите.

От филтъра Месец изберете само Януари и Февруари. В Excel включете Select Multiple Items (Избор на няколко елемента). В Calc от списъка на филтъра оставете отметки само на тези два месеца.

Проверка: Общо 22300 лв. Запад — 6000; Изток — 8500; Юг — 7800. Запазете филтъра.

Задача 3. Диаграма към филтрираната таблица

В лист 2-Филтър използвайте вече създадената обобщаваща таблица за януари и февруари.

Създайте обобщаваща колонна диаграма към тази таблица:

  • Excel: щракнете в обобщаващата таблица → Insert (Вмъкване) → PivotChart (Обобщаваща диаграма) → Column → Clustered Column (Групирана колонна).
  • Calc: щракнете в обобщаващата таблица → Insert (Вмъкване) → Chart (Диаграма). Calc разпознава таблицата. Изберете Column (Колонна) и завършете помощника.

Поставете диаграмата вдясно от таблицата, така че да не закрива данни. Общият сбор не трябва да е отделна категория в диаграмата.

Проверка: Диаграмата има три региона и серии за категориите. Тя показва филтрирания отчет с общ сбор 22300.

Задача 6. Включване на реда и обновяване

В „5-Обновяване“ разширете източника до Данни-обновяване!A1:F14. Само Refresh върху стария диапазон A1:F13 не включва новия ред.

  • Excel: щракнете в отчета → PivotTable Analyze (Анализ на обобщаваща таблица) → Change Data Source (Промяна на източника) → посочете A1:F14 от „Данни-обновяване“ → OK. След това десен бутон в таблицата → Refresh (Обновяване).
  • Calc: щракнете в отчета на „5-Обновяване“ → Data → Pivot Table → Delete (Изтриване). В „Данни-обновяване“ маркирайте A1:F14 → Data → Pivot Table → Insert or Edit → Current selection. Поставете Регион в Row Fields, Категория в Column Fields и Продажби в Data Fields с функция Sum. В Source and Destination изберете Selection (Избор) за резултата и посочете A1 на „5-Обновяване“. Потвърдете. После Data → Pivot Table → Refresh (Обновяване). Така диапазонът включва и ред 14.

Оставете всички месеци видими. В A25 напишете старата обща сума, новата и разликата.

Проверка: Общо 60300 лв.; Запад 25200; Изток 18000; Юг 17100. Разликата е 9000. Категория Техника вече е 45800 лв.

Задача 7. Три извода от анализа

Добавете лист Изводи с бутона + долу. В A1, A3 и A5 запишете по един извод: водещ регион, водеща категория и промяна след новия запис. За всеки посочете число и листа на отчета. Разграничете началните данни от данните след обновяването.

Проверка: В началото води Изток с 18000, а след новия запис — Запад с 25200. Техника е 36800 преди и 45800 след добавянето.

Записване и проверка

Documents (Документи) е стандартна папка в Windows за вашите документи и работни файлове. Използвайте я, за да намирате лесно завършената работа.

  1. Изберете File (Файл) → Save As (Запиши като). В Excel при нужда натиснете Browse (Преглед).
  2. Изберете Documents (Документи), въведете 18-full-Ime-Familia.xlsx в Excel или 18-full-Ime-Familia.ods в Calc. Заменете Ime-Familia с вашето име и фамилия.
  3. Запишете файла. Затворете и отворете отново същия файл в същата програма. Проверете резултатите от задачите и запазете с Ctrl+S.

Проверете, че обобщаващите таблици са редактируеми обекти, а не снимки или ръчно изписани крайни числа.
