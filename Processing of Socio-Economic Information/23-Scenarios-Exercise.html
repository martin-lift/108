Сценарии — бюджет на събитие

За какво е този урок?

Ще сравните варианти за бюджет на събитие чрез запазени сценарии. Входните клетки са Бюджет!B2:B5: цена на билет, посетители, разход на посетител и фиксирани разходи. B6:B8 съдържат готови формули.

Резултат = посетители × (цена − разход на посетител) − фиксирани разходи. При 500 посетители: 500 × (18 − 5) − 3500 = 3000 лв. За маркиране на B2:B5 използвайте полето за име вляво от лентата за формули. Формулите остават извън сценария.

Изтеглете и отворете файла

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено записва файла там.

  1. Натиснете Windows + E, отворете File Explorer (Файлов мениджър) и Downloads (Изтегляния). Ако сте избрали друго място при изтегляне, отворете него.
  2. Отворете 23-scenarios-exercise-clean.xlsx с Excel или Calc. В Excel натиснете Enable Editing (Разрешаване на редактирането), ако се появи такава лента.

Всички задачи и обяснения са тук, в този урок. Работният файл съдържа само необходимите данни, готови елементи и места за резултати.

Задача 1. Три сценария за посетители

Създайте три отделни сценария. Цената е 18 лв., разходът на посетител е 5 лв., фиксираните разходи са 3500 лв.

Запазете сценарий 400 посетители за Бюджет!B2:B5 със стойности по редове 18, 400, 5, 3500.

  • Excel: маркирайте B2:B5 → Data → What-If Analysis → Scenario Manager → Add. Въведете името; Changing cells е $B$2:$B$5 → OK. Въведете четирите стойности в Scenario Values → OK. Изберете името → Show → Close.
  • Calc: първо въведете четирите стойности в B2:B5, после маркирайте диапазона → Tools → Scenarios. Въведете името, задайте настройките по-долу → OK.

В Calc при създаване на сценарии оставете рамката видима и изключете Copy back, Copy entire sheet и Prevent changes. Така въвеждането на следващ вариант не променя вече запазения.

Запазете сценарий 500 посетители за Бюджет!B2:B5 със стойности по редове 18, 500, 5, 3500.

  • Excel: маркирайте B2:B5 → Data → What-If Analysis → Scenario Manager → Add. Въведете името; Changing cells е $B$2:$B$5 → OK. Въведете четирите стойности в Scenario Values → OK. Изберете името → Show → Close.
  • Calc: първо въведете четирите стойности в B2:B5, после маркирайте диапазона → Tools → Scenarios. Въведете името, задайте настройките по-долу → OK.

В Calc при създаване на сценарии оставете рамката видима и изключете Copy back, Copy entire sheet и Prevent changes. Така въвеждането на следващ вариант не променя вече запазения.

Запазете сценарий 650 посетители за Бюджет!B2:B5 със стойности по редове 18, 650, 5, 3500.

  • Excel: маркирайте B2:B5 → Data → What-If Analysis → Scenario Manager → Add. Въведете името; Changing cells е $B$2:$B$5 → OK. Въведете четирите стойности в Scenario Values → OK. Изберете името → Show → Close.
  • Calc: първо въведете четирите стойности в B2:B5, после маркирайте диапазона → Tools → Scenarios. Въведете името, задайте настройките по-долу → OK.

Проверка: Резултатите са съответно 1700, 3000 и 4950 лв.

Задача 4. Сравнение на петте сценария

Показване: в Excel — Data → What-If Analysis → Scenario Manager → изберете име → Show → Close. В Calc — F5 → Navigator → Scenarios → двукратно щракване върху името. Може да използвате и списъка в рамката на сценария.

Покажете всеки от петте сценария и запишете резултата от Бюджет!B8 в съответния ред B2:B6 на „Сравнение“. Това са запазени резултати преди редакция; те не се обновяват автоматично.

Проверка: 1700; 3000; 4950; 4000; 2500 лв.

Задача 5. Положителен резултат над 3000 лв.

Показване: в Excel — Data → What-If Analysis → Scenario Manager → изберете име → Show → Close. В Calc — F5 → Navigator → Scenarios → двукратно щракване върху името. Може да използвате и списъка в рамката на сценария.

Намерете един сценарий с резултат строго над 3000 лв. В Изводи!B2 запишете името, а в B3 — проверената сума.

Проверка: 650 посетители — 4950 лв. или Цена 20 — 4000 лв. Сумата точно 3000 не изпълнява условието.

Задача 6. Редакция на сценарий

Показване: в Excel — Data → What-If Analysis → Scenario Manager → изберете име → Show → Close. В Calc — F5 → Navigator → Scenarios → двукратно щракване върху името. Може да използвате и списъка в рамката на сценария.

Покажете „650 посетители“ и запазете копие като 650-преди със стойности 18, 650, 5, 3500.

  • Excel: в Scenario Manager изберете „650 посетители“ → Edit. Сменете името на 700 посетители, запазете B2:B5 → OK. В Scenario Values сменете само B3 на 700 → OK → Show.
  • Calc: покажете „650 посетители“. В Navigator → Scenarios → десен бутон върху него → Properties. Преименувайте на 700 посетители, включете Copy back и оставете Prevent changes изключено → OK. В B3 въведете 700. После в Properties изключете Copy back. Превключете към друг сценарий и обратно, за да проверите запазването.

В Сравнение!B7 запишете новия резултат. Първоначалният резултат в B4 остава.

Проверка: 5600 лв.; увеличение с 650 лв. спрямо 4950.

Задача 7. Препоръка с числови аргументи

В Изводи!B4 посочете вариант, а в B5 напишете две изречения: получения резултат и какви цена, посетители и разходи предполага той. Разграничете печеливш вариант от гарантиран резултат — посещаемостта е предположение.

Записване и проверка

Documents (Документи) е стандартна папка в Windows за вашите документи и работни файлове. Използвайте я, за да намирате лесно завършената работа.

  1. File (Файл) → Save As (Запиши като). Изберете Documents (Документи).
  2. Запишете като 23-full-Ime-Familia.xlsx в Excel или 23-full-Ime-Familia.ods в Calc, за да запазите обектите в собствения формат на програмата. Заменете Ime-Familia с вашето име и фамилия.
  3. Затворете и отворете отново същия файл в същата програма. Проверете резултатите и запишете с Ctrl+S.

Какво трябва да остане във файла: Видими листове: Бюджет, Сравнение и Изводи. Шест сценария: 400 посетители, 500 посетители, 700 посетители, Цена 20, Разход 6 и 650-преди. В Сравнение!B2:B7 остават 1700, 3000, 4950, 4000, 2500 и 5600. Запазени са изборът над 3000 и препоръката. Накрая покажете 500 посетители.

Сценариите или обобщаващите обекти трябва да останат запазени и редактируеми.
