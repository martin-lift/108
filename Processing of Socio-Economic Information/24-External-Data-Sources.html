Четене на данни от външни източници

За какво е този урок?

Външните данни могат да идват от CSV, текстов файл или друга работна книга. При импорт проверяваме разделителя, кодировката и типа на всяка колона. UTF-8 позволява правилно показване на кирилицата.

В лист „Импорт“ има шест записа A01–A06. Датите и стойностите първоначално са текст. „1 430“ изисква проверка, а при A05 стойността липсва. Число, записано като текст, може да изглежда като число, но да се обработва различно във формули.

Изтеглете и отворете файла

Изтеглете изчистения работен файл (.xlsx).

Downloads (Изтегляния) е стандартна папка в Windows за файловете, които изтегляте от интернет. Браузърът обикновено записва файла там.

  1. Натиснете Windows + E, отворете File Explorer (Файлов мениджър) и Downloads (Изтегляния). Ако сте избрали друго място при изтегляне, отворете него.
  2. Отворете 24-external-data-sources-clean.xlsx с Excel или Calc. В Excel натиснете Enable Editing (Разрешаване на редактирането), ако се появи такава лента.

Всички задачи и обяснения са тук, в този урок. Работният файл съдържа само необходимите данни, готови елементи и места за резултати.

Задача 1. Експортирайте листа като CSV

CSV е текстов файл с един ред за всеки запис и знак между полетата. Той не пази листове и оформление. Затова направете отделно временно копие на „Импорт“:

  • Excel: десен бутон върху раздела Импорт → Move or Copy → To book: (new book) → включете Create a copy → OK. В новата книга File → Save As → CSV UTF-8. Запишете 24-import.csv в Downloads.
  • Calc: Sheet → Move or Copy Sheet → To document: new document, с включено Copy → OK. File → Save As → Text CSV; включете Edit filter settings. Изберете UTF-8 и разделител точка и запетая. Запишете 24-import.csv в Downloads.

Потвърдете използването на CSV формата. Затворете временното копие. Оригиналната работна книга с трите листа остава отворена.

Задача 2. Импортирайте с правилните настройки

Импортирайте CSV в нова временна книга и проверете в предварителния изглед, че има пет колони и четима кирилица.

  • Excel: Ctrl+N → Data → From Text/CSV → изберете 24-import.csv. Задайте File Origin: 65001 Unicode (UTF-8). Изберете разделителя, който разделя данните на пет колони — Comma или Semicolon според експорта. За Data Type Detection изберете Do not detect data types, за да заредите стойностите като текст → Load.
  • Calc: File → Open → CSV файла. В Text Import изберете UTF-8 и същия разделител. В предварителния изглед щракнете върху колона Стойност и задайте тип Text, за да запазите текстовите числа за следващите задачи. За Дата изберете Date (YMD). Потвърдете.

Преименувайте заредения лист на Заредени чрез двукратно щракване върху раздела. Копирайте го в оригиналната работна книга: Excel — десен бутон върху раздела → Move or Copy → оригиналната книга → Create a copy; Calc — Sheet → Move or Copy Sheet → оригиналния документ → Copy. После затворете временната книга. В оригиналната трябва да има Импорт, Проверка, Бележки и Заредени.

Задача 3. Проверете типовете данни

В лист Проверка въведете в B2 =ISNUMBER('Заредени'!D2) и в C2 =ISTEXT('Заредени'!D2). Копирайте B2:C2 надолу до ред 7. В Calc изберете D2 от „Заредени“ с мишката, за да се изпише неговата препратка с точка.

TRUE означава „вярно“, FALSE — „невярно“. При зададения текстов импорт D2:D5 и D7 са текст; D6 е празна. След проверката запазете резултатите като стойности: копирайте B2:C7, после Paste Special → Values в Excel или Edit → Paste Special → Paste Only Values в Calc върху същите клетки. Така следващите поправки няма да променят проверката при импорт.

Проверка: Пет текстови стойности и една липсваща. Празната D6 не е нито число, нито текст.

Задача 4. Коригирайте текстовата стойност 1 430

В Заредени!D4 заменете текста „1 430“ с числото 1430, без интервал и без апостроф. Ако клетката има формат Text, първо изберете General (Общ) в Excel или Format Cells → Numbers → Number в Calc, после въведете 1430 отново и натиснете Enter.

Проверка: D4 е число 1430. Останалите записи са запазени. Самото числово оформление не превръща текст в число.

Задача 5. Отбележете липсващата стойност

В „Заредени“ открийте записа с код A05. Стойността D6 е празна. В E6 напишете Липсваща стойност. Оставете D6 празна — липсващото число не е нула.

Задача 6. Еднакъв формат за датите

Работете в Заредени!B2:B7. Excel: ако датите са текст, маркирайте колоната → Data → Text to Columns → Next → Next → Date: YMD → Finish. След това Ctrl+1 → Custom и формат yyyy-mm-dd. Calc: датите вече са разчетени като Date (YMD) при импорта; Ctrl+1 → Numbers → Date, с код YYYY-MM-DD.

Проверка: Датите изглеждат като 2026-01-05. Първата е 5 януари 2026 г., а последната — 12 януари. Форматът не променя самата дата.

Задача 7. Опишете настройките при импорт

В лист Бележки попълнете B2 с действителния разделител, B3 с UTF-8, а B4 с две кратки изречения защо кодировката, разделителят и типовете на колоните бяха важни. Посочете и празната стойност A05.

Записване и проверка

Documents (Документи) е стандартна папка в Windows за вашите документи и работни файлове. Използвайте я, за да намирате лесно завършената работа.

  1. File (Файл) → Save As (Запиши като). Изберете Documents (Документи).
  2. Запишете като 24-full-Ime-Familia.xlsx. В Calc потвърдете използването на избрания Excel формат, ако програмата попита. Заменете Ime-Familia с вашето име и фамилия.
  3. Затворете и отворете отново същия файл в същата програма. Проверете резултатите и запишете с Ctrl+S.

Какво трябва да остане във файла: Четири листа: Импорт с първоначалните данни; Заредени с шестте импортирани записа, числото 1430, отбелязаната липса A05 и еднакви дати; Проверка с фиксираните резултати при импорт; Бележки с настройките. CSV е междинен файл; предайте само завършената работна книга.
