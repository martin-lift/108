Електронни таблици - сортиране

Сортиране по един и няколко признака. Запазване на целостта на записите.

Всички уроциПредишен урок

1. Какво е сортиране?

Сортирането подрежда записите според избрана колона: по азбучен ред, по числова стойност, по дата или по друг критерий. При сортиране трябва да се маркира цялата таблица, за да останат данните за всеки запис на един ред.

2. Сортиране по няколко критерия

Когато стойностите по първия критерий са еднакви, вторият критерий определя реда. Например: първо по клас, след това по среден успех в низходящ ред.

В Excel използвайте Data → Sort и Add Level за допълнителни критерии.

3. Файл за упражнения

Свалете 03-sorting-practice.xlsx.

Задача 1

Сортирайте учениците по име във възходящ ред.

Задача 2

Сортирайте по среден успех в низходящ ред.

Задача 3

Сортирайте първо по клас, а вътре в класа – по среден успех.

Задача 4

Сортирайте по град, след това по отсъствия във възходящ ред.

Задача 5

При равен успех добавете втори критерий „Резултат тест“ в низходящ ред.
