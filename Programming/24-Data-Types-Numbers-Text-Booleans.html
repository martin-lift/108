Програмиране - Типове данни. Числа, текст и логически стойности

В урок 23 създавахме променливи за цели числа. Сега ще избираме какъв вид стойности да пазим: цели числа, числа с дробна част, текст или логически стойности.

1. Какво определя типът?

Тип данни определя вида на стойността и допустимите действия с нея. Числото 12 и текстът „12“ изглеждат сходно на екрана, но не се използват еднакво. Изборът започва от смисъла: брой предмети, измерена дължина, име или отговор „да/не“.

ВидPythonC#Примерна употреба
Цяло числоint; например 12int; например 12Брой тетрадки
Число с дробна частfloat; например 21.5double; например 21.5Температура или дължина
Текстов низstr; например "София"string; например "София"Име, адрес, код на изделие
Логическа стойностbool: True или Falsebool: true или falseДали условие е изпълнено

Имената float и double в таблицата обозначават избраните тук типове; те не са еднакви имена на един и същ тип. C# има и други числови типове, които не са необходими за тези начални примери.

2. Цели числа и ограничение на диапазона

Целите числа нямат дробна част: −5, 0, 12. В Python int може да нараства според необходимото и наличната памет. C# int е 32-битов тип със знак с диапазон от −2 147 483 648 до 2 147 483 647. Това е връзка с фиксирания брой битове от урок 6.

Не приемай, че едно и също име int означава еднакъв диапазон в двата езика. В задачите тук избираме стойности, които се побират. За много големи числа в C# е нужен подходящ друг тип или различен подход.

3. Числа с дробна част

При измервания често е нужна дробна част. В кода използваме десетична точка: 21.5, а не 21,5. Примерни присвоявания са temperature = 21.5 в Python и double temperature = 21.5; в C#.

Тези типове използват плаваща запетая — начин за представяне на числа с ограничена точност. Много десетични дроби се пазят приблизително, а не точно. Например математическото равенство 0.1 + 0.2 = 0.3 не гарантира напълно еднакви битови резултати при пресмятане с тези типове. Не избирай типа само по начина, по който числото изглежда на екрана.

4. Текст и число с еднакъв запис

В урок 22 сравнихме текст и израз. При + разликата става видима: между числа знакът означава събиране; между два низа — съединяване, тоест подреждане на символите един след друг.

5. Сравни число и текст

Числовото събиране дава 15. Съединяването на „12“ и „3“ дава текста „123“. В C# string е типът за текст; в Python стойността в кавички е от тип str.

Python

number = 12
text = "12"
print(number + 3)
print(text + "3")

C#

using System;

int number = 12;
string text = "12";
Console.WriteLine(number + 3);
Console.WriteLine(text + "3");

Изход на двете програми:

15
123

Пощенски код или код на изделие често се пази като текст, дори да съдържа само цифри. Например „0042“ трябва да запази нулите в началото и не е количество за събиране. Не смесвай число и текст с + без ясна цел: Python ще откаже пряко събиране на int и str, а C# може да образува текст при съединяване с низ. За еднакво поведение избирай типа съзнателно.

6. Логически стойности

От урок 17 знаеш, че условието е вярно или невярно. Такива резултати се пазят с типа bool. В Python пишем True и False с главна първа буква; в C# — true и false с малки букви.

Знакът > сравнява две стойности и получава логически резултат. За проверка на равенство в двата езика използваме ==. Един знак = присвоява стойност; два знака == сравняват. В следващия пример само извеждаме резултата от условие — още не избираме клон на програма.

7. Запази резултат от сравнение

И двете стойности са логически. При извеждане с използваните операции и двата езика показват True. Това е изходният текст; литералът в C# кода остава true с малка буква. Литерал наричаме стойност, записана направо в кода.

Python

temperature = 21.5
is_warm = temperature > 20
is_ready = True
print(is_warm)
print(is_ready)

C#

using System;

double temperature = 21.5;
bool isWarm = temperature > 20;
bool isReady = true;
Console.WriteLine(isWarm);
Console.WriteLine(isReady);

Изход на двете програми:

True
True

8. Тип на стойност и тип на променлива

В Python името може по-късно да се свърже със стойност от друг тип: след присвояване на 12 може да му присвоим текст. Това не прави числото и текста взаимозаменяеми. В C# променлива, декларирана като int, не може после да получи произволен текст. Компилаторът проверява съвместимостта с декларирания тип.

Използвай едно име за един смисъл, дори когато езикът допуска смяна на вида на стойността. Така се избягват грешки и програмата се проследява по-лесно.

9. Избор на тип и задачи

  1. Избери тип на двата езика за: брой ученици; средна температура; име на град; дали файлът е намерен.
  2. Какво ще се получи при 7 + 5 и при съединяване на „7“ и „5“?
  3. Защо кодът на артикул „0012“ е подходящ за текст?
  4. Какъв е логическият резултат от 5 > 8 и от 5 == 5?
  5. Защо не можем да очакваме всеки Python int да се побере в C# int?
Отговори
  1. int / int; float / double; str / string; bool / bool.
  2. Числото 12 и текстът „75“.
  3. Запазва водещите нули и обозначава идентичност, а не количество.
  4. Невярно и вярно: False и True при показване.
  5. Диапазонът на C# int е фиксиран до 32 бита със знак.

Запомни: типът определя какво означава стойността и как работят операциите. Кавичките превръщат записа в текст; те не са само украса на число.
