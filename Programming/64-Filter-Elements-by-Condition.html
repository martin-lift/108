Програмиране - Проверка на елементите на масив или списък по зададено условие

Ще съчетаем обхождането на запазена структура с условие за всеки елемент. Подходът напомня урок 53, но данните вече са съхранени.

1. Условие при всяка позиция

Посещаваме всички елементи, а извеждаме само избраните. Наличието на условие не намалява броя посещения — за да знаем дали стойността отговаря, първо трябва да я проверим.

2. Изведи положителните с индексите им

На всеки изходен ред са индексът и стойността. Нулата не е положителна.

Python

values = [-3, 0, 4, 7]
for i in range(len(values)):
    if values[i] > 0:
        print(i, values[i])

C#

using System;

int[] values = new int[] { -3, 0, 4, 7 };
for (int i = 0; i < values.Length; i = i + 1)
{
    if (values[i] > 0)
    {
        Console.Write(i);
        Console.Write(" ");
        Console.WriteLine(values[i]);
    }
}

Изход на двете програми:

2 4
3 7

3. Когато няма съвпадение

Само условното извеждане не показва нищо, ако няма подходящ елемент. За изрично съобщение може да използваме флаг — логическа променлива, която помни дали е настъпило събитие.

4. Покажи съобщение при липса

Флагът започва като невярно и става вярно само при съвпадение. Проверяваме го след цялото обхождане.

Python

values = [-3, 0, -1]
found = False
for value in values:
    if value > 0:
        print(value)
        found = True
if not found:
    print("Няма положителни")

C#

using System;

int[] values = new int[] { -3, 0, -1 };
bool found = false;
foreach (int value in values)
{
    if (value > 0)
    {
        Console.WriteLine(value);
        found = true;
    }
}
if (!found)
{
    Console.WriteLine("Няма положителни");
}

Изход на двете програми:

Няма положителни

5. Различни критерии

За стойности от 10 до 20 използвай две сравнения с И. За стойности извън интервала използвай ИЛИ. За четни използвай остатък при деление на 2. Не поставяй „Няма“ в else за всеки елемент: една неподходяща стойност не доказва, че всички са неподходящи.

6. Самостоятелни задачи

  1. Изведи стойностите от [0, 5] включително.
  2. Провери празна структура с флаг за наличие.
  3. Защо съобщението за липса е след цикъла?
  4. Какво е различното, ако искаме индексите вместо стойностите?
Отговори и насоки
  1. В Python: (value >= 0) and (value <= 5). В C#: (value >= 0) && (value <= 5).
  2. Флагът остава невярно и се показва съобщение.
  3. Трябва да сме проверили всички елементи.
  4. Използваме индексен цикъл и извеждаме i.

Запомни: Разделяй проверката на всеки елемент от окончателния извод за цялата структура.
