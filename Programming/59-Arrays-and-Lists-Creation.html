Програмиране - Едномерни масиви и списъци. Предназначение и създаване

Досега обработвахме входните стойности веднага и пазехме само обобщения. Когато трябва да използваме данните отново, е удобно да съхраним цяла поредица под общо име.

1. Елемент, индекс и дължина

Елемент е една стойност в поредицата. Индекс е номерът на позицията, а дължина — броят елементи. Едномерна структура има една редица от позиции. В Python ще използваме списък, а в C# — едномерен масив.

Списъкът запазва реда и допуска повторени стойности. Масивът също пази стойностите по позиции. Те са различни структури, въпреки че много от началните алгоритми върху тях са еднакви.

2. Създай поредица и празна структура

Квадратните скоби с изброени стойности създават Python списък. C# int[] означава масив от цели числа; new създава масива. len(...) е функция за дължината на Python списъка. В C# свойство е именувана характеристика; тук я прочитаме чрез точка след името на масива. Свойството values.Length дава броя елементи на масива. Length няма скоби за извикване.

Python

values = [4, 7, 2]
empty = []
print(len(values))
print(len(empty))

C#

using System;

int[] values = new int[] { 4, 7, 2 };
int[] empty = new int[0];
Console.WriteLine(values.Length);
Console.WriteLine(empty.Length);

Изход на двете програми:

3
0

Python списъкът може да расте чрез добавяне, което ще използваме при въвеждането. C# масивът се създава с определена дължина; промяната на съдържание не променя автоматично дължината.

4. Кога е нужна цялата поредица?

За еднократно намиране на сума е достатъчна натрупваща променлива. За повторно показване, промяна на определен елемент или търсене след приключване на входа е нужна запазена структура. Изборът следва какво ще правим по-късно с данните.

Не бъркай празен списък с масив от три нули: първият има дължина 0, а вторият — 3 и съдържа действителни стойности. Следващият урок ще разгледа достъпа по индекс.

5. Самостоятелни задачи

  1. Създай поредица от 5, 5, 0 и покажи дължината.
  2. Каква е дължината на празната структура?
  3. Защо повторенията не се премахват автоматично?
  4. За намиране на сума само веднъж задължителен ли е масив?
Отговори и насоки
  1. И в двата езика дължината е 3.
  2. 0.
  3. Всяка позиция пази своя елемент; не се изисква стойностите на различните позиции да са различни.
  4. Не, може да се натрупва при прочитане.

Запомни: Различавай съдържанието от дължината и избирай съхранение на поредица, когато ще използваш елементите отново.
