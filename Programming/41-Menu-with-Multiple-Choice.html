Програмиране - Създаване на програма с меню чрез многовариантен избор. Упражнение

Ще създадем еднократно меню: показваме възможностите, прочитаме номер и изпълняваме едно действие. Повторението на меню изисква цикъл, който предстои.

1. Договор между менюто и избора

Всеки показан номер трябва да има действие. Избор 0 ще означава „край без изчисление“. Непредвиденият номер трябва да получи разбираемо съобщение. Това разграничение не бива да се скрива в математическите изрази.

Ще използваме правоъгълник със страни 3 и 5. Избор 1 намира лице, избор 2 — обиколка. Данните са зададени в кода, за да се съсредоточим върху менюто.

2. Меню за правоъгълник

Програмата прочита един избор, показва един резултат и приключва. Въвежданият номер не е включен в показания изход.

Въведи последователно: 1. След всяка стойност натисни Enter.

Python

print("1 - Лице")
print("2 - Обиколка")
print("0 - Край")
choice = int(input())
a = 3
b = 5
match choice:
    case 1:
        print(a * b)
    case 2:
        print(2 * (a + b))
    case 0:
        print("Край")
    case _:
        print("Невалиден избор")

C#

using System;

Console.WriteLine("1 - Лице");
Console.WriteLine("2 - Обиколка");
Console.WriteLine("0 - Край");
int choice = int.Parse(Console.ReadLine() ?? "");
int a = 3;
int b = 5;
switch (choice)
{
    case 1:
        Console.WriteLine(a * b);
        break;
    case 2:
        Console.WriteLine(2 * (a + b));
        break;
    case 0:
        Console.WriteLine("Край");
        break;
    default:
        Console.WriteLine("Невалиден избор");
        break;
}

Изход на двете програми:

1 - Лице
2 - Обиколка
0 - Край
15

3. Проследяване и разширяване

Провери всеки номер от менюто, както и поне един непоказан номер. Ако добавиш действие, първо промени видимия списък, после добави съответния case и тест. Не използвай един номер за две различни действия.

При въвеждане на буква вместо число текущите int / Parse ще съобщят грешка. Случаят по подразбиране обработва непредвидена вече прочетена числова стойност, а не грешка при преобразуването. Това е разлика между валидност на записа и валидност на избора.

4. Кога да прочетем допълнителните данни?

Ако някои действия изискват различни данни, въведи ги вътре в избрания case. Ако всички изчисления използват едни и същи страни, можеш да ги прочетеш общо преди switch / match. При избор „Край“ не е нужно да изискваш ненужни величини.

5. Самостоятелни задачи

  1. Добави избор 3 за сбора на двете страни.
  2. Промени програмата да прочита страните, когато е избрано изчисление.
  3. Защо избор 9 не трябва да даде нулево лице по подразбиране?
  4. Трябва ли менюто да се създава отново при всяко стартиране на файла?
Отговори и насоки
  1. Добави надпис и case за a + b; резултатът е 8.
  2. Използвай вход вътре в нужните случаи или обща проверка за избор 1/2.
  3. Номерът е невалиден, а не изчисление с резултат 0.
  4. Кодът показва менюто при всяко изпълнение; не създаваме нов проект.

Запомни: Менюто, случаите и тестовете трябва да съвпадат. default / case _ не замества обработката на нечислов вход.
