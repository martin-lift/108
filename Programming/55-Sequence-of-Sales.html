Програмиране - Обработка на поредица от продажби чрез цикъл. Упражнение

Ще обединим сигнал за край, натрупване на оборот и условно броене. За упражнението сумите са цели парични единици.

1. Ясен договор за вход

Въвеждат се неотрицателни суми на продажби. −1 означава край и не е продажба. Друга отрицателна стойност е невалидна и не участва в резултатите. Нулата е допустима продажба с нулева стойност и увеличава броя.

Търсим общ оборот, брой допустими продажби и брой продажби над 100. Използвай до 100 суми от 0 до 100000, така че натрупването да се побира в C# int.

2. Натрупай оборот и броячи

Стойността −1 се проверява преди обработката. Новият вход е след двата клона, затова след невалидна сума също се придвижваме напред.

Въведи последователно: 100, 150, 0, -2, 50, -1. След всяка стойност натисни Enter.

Python

total = 0
count = 0
large_count = 0
amount = int(input())
while amount != -1:
    if amount < 0:
        print("Невалидна сума")
    else:
        total = total + amount
        count = count + 1
        if amount > 100:
            large_count = large_count + 1
    amount = int(input())
print(total)
print(count)
print(large_count)

C#

using System;

int total = 0;
int count = 0;
int largeCount = 0;
int amount = int.Parse(Console.ReadLine() ?? "");
while (amount != -1)
{
    if (amount < 0)
    {
        Console.WriteLine("Невалидна сума");
    }
    else
    {
        total = total + amount;
        count = count + 1;
        if (amount > 100)
        {
            largeCount = largeCount + 1;
        }
    }
    amount = int.Parse(Console.ReadLine() ?? "");
}
Console.WriteLine(total);
Console.WriteLine(count);
Console.WriteLine(largeCount);

3. Проследи какво участва

В примера 100, 150, 0 и 50 са четири продажби с обща стойност 300. Само 150 е строго над 100. −2 води до съобщение, но не увеличава нито оборота, нито броя. −1 приключва четенето и не достига условието за невалидна сума.

4. Разширяване със средна продажба

Можем да използваме total и count за средна продажба, но само когато count > 0. При първи вход −1 показваме „Няма продажби“, ако задачата иска средно. Не делим на броя въведени редове, защото той включва невалидните суми и сигнала за край.

Отдели въпроса за запис на число от въпроса за допустима сума. Този пример предполага коректни целочислени записи; за нечислов текст можеш да приложиш проверката от урок 54.

5. Самостоятелни задачи

  1. Добави средна продажба с проверка за count = 0.
  2. Промени прага на „поне 100“.
  3. Провери 0, 0, −1.
  4. Защо новото четене не трябва да е само в допустимия клон?
Отговори и насоки
  1. Изчисли total / count; в C# използвай total * 1.0 / count.
  2. Условието става amount >= 100.
  3. Оборот 0, брой 2, големи продажби 0.
  4. Иначе при невалидна стойност цикълът ще остане върху нея.

Запомни: Сигналът за край, невалидният вход и допустимата продажба са различни случаи. Натрупвай само избраните данни.
