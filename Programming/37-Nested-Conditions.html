Програмиране - Вложени условни конструкции

Вложена условна конструкция е проверка вътре в блок на друга проверка. До вътрешната стигаме само по избрания външен път.

1. Път до вътрешното условие

Външно условие избира по-голяма група случаи. Вътрешно условие разделя тази група допълнително. В Python второто if има още едно ниво отстъп, а в C# — свои фигурни скоби в блока. Вътрешният else принадлежи на вътрешното if.

2. Първо допустимост, после четност

За отрицателна стойност проверката за четност вътре не е нужна за тази задача и се пропуска. Нулата е допустима и четна.

Въведи последователно: 0. След всяка стойност натисни Enter.

Python

n = int(input())
if n >= 0:
    if n % 2 == 0:
        print("Неотрицателно четно")
    else:
        print("Неотрицателно нечетно")
else:
    print("Недопустимо")

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
if (n >= 0)
{
    if (n % 2 == 0)
    {
        Console.WriteLine("Неотрицателно четно");
    }
    else
    {
        Console.WriteLine("Неотрицателно нечетно");
    }
}
else
{
    Console.WriteLine("Недопустимо");
}

Изход на двете програми:

Неотрицателно четно

„Не се проверява“ не е същото като False: изпълнението не достига тази част. При проследяване записвай само действително изпълнените проверки.

4. Вложен избор или съставно условие?

Ако е нужно само действие при две едновременно верни условия, И може да даде по-кратък запис. Ако са нужни различни съобщения за провала на първото и второто условие, вложените конструкции запазват разграничението.

Например при проверка на две положителни страни можем първо да проверим a, после b. Така съобщението уточнява коя страна е недопустима. Използвай толкова нива, колкото са нужни за смисъла; при много категории веригата от урок 36 често е по-четима.

5. Към кое if принадлежи else?

В Python това се определя от отстъпа: else е подравнен със своето if. В C# изричните скоби премахват двусмислието. Първо оформи блоковете и едва после добавяй действията в тях. Не мести else на друго ниво, без да промениш очакваните пътища.

6. Самостоятелни задачи

  1. Проследи програмата за −4, 1 и 2.
  2. Провери две положителни страни с различни съобщения за грешна първа и грешна втора страна.
  3. Може ли вътрешният if да се изпълни при n = −2?
  4. Опиши кога съставно условие с И може да замени двете проверки.
Отговори и насоки
  1. Недопустимо; неотрицателно нечетно; неотрицателно четно.
  2. Първо a > 0, а в неговия допустим клон b > 0.
  3. Не, външното условие е невярно.
  4. Когато е нужно само общо действие при две верни условия и отделните причини не се извеждат.

Запомни: При вложени условия следвай действителния път и пази ясна принадлежността на всеки блок и else.
