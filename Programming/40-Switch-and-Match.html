Програмиране - Многовариантен избор. Конструкция SWITCH

Когато различните действия зависят от конкретната стойност на един избор, многовариантната конструкция прави случаите видими на едно място.

1. Една стойност, няколко конкретни случая

В C# използваме switch (choice), последван от блок с етикети case. В Python 3.10 и по-нови версии има match choice: с отделни case. Тук използваме само съпоставяне с конкретни цели числа, без по-сложни образци.

Случай по подразбиране обработва непредвидена стойност: default в C#, а case _ в Python. Долната черта в този case е универсален образец, а не променлива за резултата.

2. Избери действие по номер

Стойността на choice се съпоставя с 1 и 2. При 7 се избира случаят по подразбиране.

Въведи последователно: 2. След всяка стойност натисни Enter.

Python

choice = int(input())
match choice:
    case 1:
        print("Събиране")
    case 2:
        print("Изваждане")
    case _:
        print("Непознат избор")

C#

using System;

int choice = int.Parse(Console.ReadLine() ?? "");
switch (choice)
{
    case 1:
        Console.WriteLine("Събиране");
        break;
    case 2:
        Console.WriteLine("Изваждане");
        break;
    default:
        Console.WriteLine("Непознат избор");
        break;
}

3. Защо C# има break тук?

break; прекратява текущия switch и продължава след неговия блок. Тук не означава край на цялата програма. В C# непразен case не може просто да продължи в следващия; изписваме break, за да завършим случая.

В Python след изпълнението на съвпадналия case конструкцията match приключва. Не добавяме break в нея. Отстъпите показват кое действие принадлежи на всеки случай.
