Програмиране - Преброяване на елементи, отговарящи на условие. Упражнение

При броене не спираме след първото съвпадение: трябва да видим цялата структура. Ще разграничим наличие, брой и сума.

1. Какво увеличаваме?

Броячът започва от 0 и се увеличава с 1 при всяко изпълнено условие. Сумата би се увеличила със стойността на елемента. Флагът би пазил само дали има поне едно съвпадение. Тези резултати не са взаимозаменяеми.

2. Брой стойности над въведен праг

Строго над 5 е само 8. Повторените стойности се броят всяка поотделно, когато удовлетворяват условието.

Въведи последователно: 5. След всяка стойност натисни Enter.

Python

values = [0, 5, 8, 5, -1]
threshold = int(input())
count = 0
for value in values:
    if value > threshold:
        count = count + 1
print(count)

C#

using System;

int[] values = new int[] { 0, 5, 8, 5, -1 };
int threshold = int.Parse(Console.ReadLine() ?? "");
int count = 0;
foreach (int value in values)
{
    if (value > threshold)
    {
        count = count + 1;
    }
}
Console.WriteLine(count);

3. Проверка на брояча

След обработване на k елемента броячът е броят съвпадения сред тези k позиции. Той не може да е отрицателен или да надхвърля k. След края резултатът е между 0 и дължината включително.

За празна структура резултатът е 0. За структура, в която всички отговарят на условието, резултатът е нейната дължина. Това са полезни контролни случаи.

4. Нови критерии без нов алгоритъм

За преброяване на нули смени условието с value == 0. За затворен интервал свържи двете сравнения с И. Началният брояч и начинът на увеличение остават същите.

Не използвай break след първия подходящ елемент. Това би отговорило само за наличие и броят няма да е пълен. Не нулирай count вътре в цикъла и не извеждай окончателен резултат преди края.

5. Самостоятелни задачи

  1. Преброй стойности >= 5 в основния масив.
  2. Преброй нулите.
  3. Какъв е резултатът при праг 100?
  4. Защо две срещания на числото 5 могат да добавят две към брояча?
Отговори и насоки
  1. 3.
  2. 1.
  3. 0.
  4. Броим позиции, които отговарят на условието, а не различни числови стойности.

Запомни: За точен брой провери всички елементи и увеличавай с 1 за всяко съвпадение.
