Програмиране - Натрупване на сума и преброяване чрез цикъл

Ще обработваме поредица от стойности, без да ги пазим всички. Сума и брояч съхраняват само необходимото обобщение.

1. Две различни роли на променливите

Натрупваща променлива пази постепенно получаван резултат. За сума започваме от 0 и добавяме всяка стойност. Брояч пази брой събития и се увеличава с 1. Не добавяме самото число към брояча, когато искаме да преброим положителните стойности.

Началните стойности се задават преди цикъла. Ако total = 0 е в тялото, натрупаното ще се изтрива при всяка итерация.

2. Сума на всички и брой положителни

Първо въвеждаме n от 0 до 100, после n цели стойности от −1000 до 1000. Тази област пази сумата в диапазона на C# int. Изходът е сума и брой положителни.

Въведи последователно: 4, 3, -2, 0, 3. След всяка стойност натисни Enter.

Python

n = int(input())
total = 0
positive_count = 0
for i in range(n):
    value = int(input())
    total = total + value
    if value > 0:
        positive_count = positive_count + 1
print(total)
print(positive_count)

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
int total = 0;
int positiveCount = 0;
for (int i = 0; i < n; i = i + 1)
{
    int value = int.Parse(Console.ReadLine() ?? "");
    total = total + value;
    if (value > 0)
    {
        positiveCount = positiveCount + 1;
    }
}
Console.WriteLine(total);
Console.WriteLine(positiveCount);

Изход на двете програми:

4
2

Нулата влиза в сумата, но не увеличава положителния брояч. Условието > 0 е строго; >= 0 би преброило и нулата.

4. Кое се прави винаги и кое условно?

Сумата на всички стойности се обновява при всяко повторение. Броячът се обновява само във верния клон. Ако искаме сума само на положителните, преместим и добавянето в този клон. Имената трябва да показват различния смисъл: total срещу positive_total.

Празната поредица при n = 0 има сума 0 и брой 0. Тялото не се изпълнява и началните стойности са крайните резултати.

5. Самостоятелни задачи

  1. Промени брояча да брои нули.
  2. Натрупай само положителните стойности.
  3. Намери изхода за 2, −5, 3 при n = 3.
  4. Защо total и positive_count не трябва да се нулират вътре?
Отговори и насоки
  1. Условието е value == 0.
  2. Добавяй value само при value > 0.
  3. Сума 0 и два положителни елемента.
  4. Ще се загубят резултатите от предишните итерации.

Запомни: Сумата натрупва стойности, броячът — събития. Задай началото веднъж и обновявай само на правилното място.
