Програмиране - Контролна работа върху условни конструкции

Контролна работа върху сравнения, логически оператори, if, вложени условия и многовариантен избор. Работи самостоятелно и показвай причината за всеки избран клон.

Общо: 30 точки. Покажи проследяването и обоснови избраните конструкции. При четене на код предвиди резултата, преди да го изпълниш. За задачите за съставяне дай решения на Python и C#.

1. Логически изрази — 4 точки

За x = 10 намери стойността на (x >= 10) И (x < 20) и на (x < 10) ИЛИ (x > 20). Запиши двата израза на Python и C#. За всеки израз: правилен синтаксис — 1 т.; резултат с обяснение — 1 т.

2. Проследяване — 6 точки

За кода в края запиши всички изходни редове, стойността на всяка извършена проверка и обясни дали двете if са независими. Изход — 2 т.; проверки — 2 т.; обяснение — 2 т.

3. Състави програма — 12 точки

Прочети цяло количество. Отрицателно количество е недопустимо. При брой под 10 цената за брой е 5, при 10–19 — 4, а при поне 20 — 3. Цената се прилага върху всички бройки. Дай програми на Python и C#, които показват общата цена или съобщение за невалидност. За всеки език: вход — 1 т.; допустимост — 1 т.; правилни диапазони — 2 т.; пресмятане — 1 т.; изход — 1 т.

4. Меню — 4 точки

Опиши меню с избор 1 за проверка на четност, 2 за проверка на знак и 0 за край. Посочи случаите по подразбиране в двата езика и защо са нужни. Меню и случаи — 2 т.; обработка на непознат номер — 2 т.

5. Тестови случаи — 4 точки

За програмата за количество избери четири входа, които проверяват различни граници или невалидност. За всеки запиши очакван резултат и кратко обяснение. По 1 т. за смислен тест с правилно очакване.

6. Код за проследяване

Python

n = 12
if n >= 10:
    print("A")
if n % 2 == 0:
    print("B")
else:
    print("C")

C#

using System;

int n = 12;
if (n >= 10)
{
    Console.WriteLine("A");
}
if (n % 2 == 0)
{
    Console.WriteLine("B");
}
else
{
    Console.WriteLine("C");
}

7. Проверка преди предаване

  • Описани ли са допустимите входни стойности?
  • Показани ли са промените в променливите и очакваните резултати?
  • Проверени ли са границите, равните стойности и празният случай, когато е допустим?
  • Съвпадат ли алгоритмите на двата езика?
