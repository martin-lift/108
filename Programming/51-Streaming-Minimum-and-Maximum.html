Програмиране - Намиране на най-малка и най-голяма стойност сред последователно въведени числа

За най-малката и най-голямата стойност не е нужно да пазим цялата поредица. Достатъчни са текущ минимум и максимум.

1. Правилно начално задаване

Текущ минимум е най-малката стойност сред вече прочетените. Аналогично текущият максимум е най-голямата. При непразна поредица започваме и двата с първото число.

Не започвай автоматично от 0. При само отрицателни числа 0 не е правилен максимум, защото изобщо не присъства. Първата действителна стойност дава коректно начало без специални огромни граници.

2. Минимум и максимум при последователно четене

След първия вход остават n - 1 числа, затова броячът започва от 1 и е под n. При n = 1 цикълът е празен.

Въведи последователно: 3, -9, -2, -5. След всяка стойност натисни Enter.

Python

n = int(input())
if n <= 0:
    print("Няма данни")
else:
    first = int(input())
    minimum = first
    maximum = first
    for i in range(1, n):
        value = int(input())
        if value < minimum:
            minimum = value
        if value > maximum:
            maximum = value
    print(minimum)
    print(maximum)

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
if (n <= 0)
{
    Console.WriteLine("Няма данни");
}
else
{
    int first = int.Parse(Console.ReadLine() ?? "");
    int minimum = first;
    int maximum = first;
    for (int i = 1; i < n; i = i + 1)
    {
        int value = int.Parse(Console.ReadLine() ?? "");
        if (value < minimum)
        {
            minimum = value;
        }
        if (value > maximum)
        {
            maximum = value;
        }
    }
    Console.WriteLine(minimum);
    Console.WriteLine(maximum);
}

3. Проследяване

Нов входminimummaximum
-9-9-9
-2-9-2
-5-9-2

След всяка итерация двете променливи обобщават всички прочетени до момента числа. Равна стойност не изисква промяна. Това не променя коректността, когато една и съща крайна стойност се среща повече от веднъж.

4. Не обърквай стойност с брой

Минимумът е стойност, а не позиция или брой елементи. В този алгоритъм не пазим местата на числата. Ако задачата иска колко пъти се среща максимумът, ще са нужни допълнителни правила и брояч.

При неположителен брой не прочитаме „първа стойност“, защото няма такава. Проверяваме броя, преди да използваме този начин за начално задаване.

5. Самостоятелни задачи

  1. Защо начално maximum = 0 е грешно при −8, −3, −7?
  2. Проследи 5, 2, 9, 1.
  3. Колко числа се прочитат в цикъла при n = 4?
  4. Какви са резултатите при една стойност −6?
Отговори и насоки
  1. Ще запази несъществуващата 0 вместо −3.
  2. Минимум 1, максимум 9.
  3. Три; първото е прочетено преди цикъла.
  4. И минимумът, и максимумът са −6.

Запомни: Започни от първата действителна стойност и обработи всяка следваща точно веднъж.
