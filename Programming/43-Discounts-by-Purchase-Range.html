Програмиране - Изчисляване на отстъпки според стойността на покупката. Упражнение

Ще приложим последователни проверки към различни проценти на отстъпка. Правилата са учебни и се прилагат върху цялата покупка.

1. Опиши диапазоните без празнини

Нека сумата е неотрицателно цяло число. Под 100 няма отстъпка; от 100 до под 500 отстъпката е 5%; при поне 500 е 10%. Границите 100 и 500 принадлежат на по-високия процент. Първо отхвърляме отрицателната стойност, после проверяваме праговете в ясен ред.

Процентът определяме чрез условия, а крайната сума изчисляваме с една обща формула. Така не повтаряме изчислението в три клона и намаляваме риска от различни формули.

2. Избери процент и пресметни

Входът е цяло число за началната сума. Първият изходен ред е процентът, вторият — крайната сума с два дробни знака. Форматирането е познато от урок 28.

Въведи последователно: 200. След всяка стойност натисни Enter.

Python

subtotal = int(input())
if subtotal < 0:
    print("Недопустима сума")
else:
    if subtotal >= 500:
        percent = 10
    elif subtotal >= 100:
        percent = 5
    else:
        percent = 0
    final_total = subtotal * (1 - percent / 100)
    print(percent)
    print(format(final_total, ".2f"))

C#

using System;
using System.Globalization;

int subtotal = int.Parse(Console.ReadLine() ?? "");
if (subtotal < 0)
{
    Console.WriteLine("Недопустима сума");
}
else
{
    int percent;
    if (subtotal >= 500)
    {
        percent = 10;
    }
    else if (subtotal >= 100)
    {
        percent = 5;
    }
    else
    {
        percent = 0;
    }
    double finalTotal = subtotal * (1 - percent / 100.0);
    Console.WriteLine(percent);
    Console.WriteLine(finalTotal.ToString(
        "F2", CultureInfo.InvariantCulture));
}

190.00

3. Защо проверяваме 500 преди 100?

Всяка сума поне 500 е и поне 100. При обратен ред първото вярно условие ще даде само 5%. Тест с 200 няма да открие тази грешка, защото и двата реда на проверки дават 5% за него.

4. Граници и точност

СумаПроцентПричина
990Под първия праг
1005Първият праг се включва
4995Под втория праг
50010Вторият праг се включва

Това е процент върху цялата сума, а не отделни части по различни ставки. Както в урок 28, float и double са приблизителни типове; оформянето до два знака е показване на резултата, а не точна десетична аритметика.

5. Самостоятелни задачи

  1. Добави праг 1000 с отстъпка 15%. Къде трябва да стои?
  2. Намери резултата за 600.
  3. Добави извеждане на спестената сума.
  4. Избери тестове около новия праг 1000.
Отговори и насоки
  1. Преди проверката за 500.
  2. 10% и крайна сума 540.00.
  3. В Python: saved = subtotal - final_total. В C#: double saved = subtotal - finalTotal;. За вход 200 спестената сума е 10.00.
  4. 999, 1000 и 1001.

Запомни: Подреди припокриващите се прагове и провери точно граничните стойности. Не бъркай отстъпка върху цялата сума с тарифа по части.
