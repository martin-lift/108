Програмиране - Повторно въвеждане до получаване на допустима стойност. Упражнение

Еднократното съобщение за грешка не дава възможност за поправяне в същото изпълнение. Ще повтаряме заявката до положително цяло число и ще различаваме нечислов текст от недопустима числова стойност.

1. Два вида проверка

Първо установяваме дали текстът може да се прочете като цяло число. След това проверяваме дали числото е положително. Цикълът продължава при неуспешно преобразуване или при стойност <= 0.

В Python try огражда действие, което може да предизвика грешка. except ValueError обработва конкретно грешка от невалидно числово преобразуване. Други грешки не се скриват с този запис.

В C# int.TryParse(text, out n) връща bool и записва полученото число в n при успех. out указва, че методът задава стойност на подадената променлива. При неуспех TryParse връща false; не разчитаме тогава на n като валидни данни.

2. Повтаряй до положително цяло

Подай достатъчно редове до валиден вход. При приключване на потока без такъв вход тези начални конзолни упражнения не решават задачата за повторна заявка. Използваме стойности, които се побират в C# int.

Въведи последователно: abc, 0, 3. След всяка стойност натисни Enter.

Python

n = 0
valid = False
print("Въведи положително цяло число")
while (not valid) or (n <= 0):
    text = input()
    try:
        n = int(text)
        valid = True
    except ValueError:
        valid = False
    if (not valid) or (n <= 0):
        print("Опитай отново")
print("Прието:", n)

C#

using System;

int n = 0;
bool valid = false;
Console.WriteLine("Въведи положително цяло число");
while ((!valid) || (n <= 0))
{
    string text = Console.ReadLine() ?? "";
    valid = int.TryParse(text, out n);
    if ((!valid) || (n <= 0))
    {
        Console.WriteLine("Опитай отново");
    }
}
Console.Write("Прието: ");
Console.WriteLine(n);

3. Кога спира цикълът?

При успех valid е вярно и n е положително. И двете причини за продължаване отпадат. В началото valid е невярно, затова първото прочитане е задължително. След всяка грешка се изпълнява ново прочитане, а не повторна проверка на един и същ текст.

Python int няма същата фиксирана граница като C# int. За сравними тестове избирай общия диапазон. Не приемай, че всяка стойност, която Python може да прочете, е допустима за C#.

4. Самостоятелни задачи

  1. Промени допустимата област на 1–10 включително.
  2. Защо само TryParse не проверява положителност?
  3. Какво става с текста „три“ в двата езика?
  4. Защо входът е вътре в цикъла?
Отговори и насоки
  1. Продължавай при неуспех или n < 1 или n > 10.
  2. Отрицателно число също е валиден целочислен запис.
  3. Преобразуването е неуспешно и се иска нов ред.
  4. За да получим нови данни след всеки отказ.

Запомни: Провери и числовия запис, и областта на стойността. Повтаряй входа, докато и двете изисквания са изпълнени.
