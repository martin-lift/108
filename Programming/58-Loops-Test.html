Програмиране - Контролна работа върху циклични конструкции

Самостоятелна работа върху while, for, натрупване, броене и условия в цикъл. Не са нужни масиви или списъци.

Общо: 30 точки. Покажи проследяването и обоснови избраните конструкции. При четене на код предвиди резултата, преди да го изпълниш. За задачите за съставяне дай решения на Python и C#.

1. Устройство на цикъл — 4 точки

Обясни начална стойност, условие, тяло и промяна на брояча. За всяко понятие дай кратък пример или роля. По 1 т.

2. Проследяване на кода — 6 точки

За кода в края запиши стойностите на i, total и count след всяка итерация и крайния изход. Таблица — 4 т.; изход — 2 т.

3. Състави програма — 12 точки

Въвежда се n от 0 до 100, после n цели числа от −1000 до 1000. Намери сумата и броя на положителните и тяхното средно. При липса на положителни изведи съобщение вместо деление. Дай Python и C# вариант. За всеки: вход и цикъл — 2 т.; правилна сума и брой — 2 т.; проверка и изход — 2 т.

4. Избор на цикъл — 4 точки

Обясни подходящ цикъл за точно n стойности и за четене до сигнал −1. Посочи къде се прочита новата стойност и дали сигналът участва. По 2 т. за всеки модел.

5. Тестове — 4 точки

Дай четири тестови набора за програмата за положителни числа: празен, без положителни, с една положителна стойност и смесен. Запиши очаквания резултат. По 1 т.

6. Код за проследяване

Python

total = 0
count = 0
for i in range(1, 5):
    if i % 2 == 0:
        total = total + i
        count = count + 1
print(total)
print(count)

C#

using System;

int total = 0;
int count = 0;
for (int i = 1; i <= 4; i = i + 1)
{
    if (i % 2 == 0)
    {
        total = total + i;
        count = count + 1;
    }
}
Console.WriteLine(total);
Console.WriteLine(count);

7. Проверка преди предаване

  • Описани ли са допустимите входни стойности?
  • Показани ли са промените в променливите и очакваните резултати?
  • Проверени ли са границите, равните стойности и празният случай, когато е допустим?
  • Съвпадат ли алгоритмите на двата езика?
