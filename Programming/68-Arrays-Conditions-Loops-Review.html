Програмиране - Масиви, условни конструкции и цикли. Обобщение и упражнение

Ще съчетаем обхождане, условие, промяна на елемент, брояч и сума в един алгоритъм.

1. План преди кода

Дадени са цели числа. Заменяме отрицателните с 0, преброяваме положителните и намираме сумата им. Първо уточняваме кои стойности проверяваме: в тази задача замяната на отрицателните с нула не променя положителните, затова броят и сумата им остават същите.

Нужен е индексен цикъл за замяната. Броячът и сумата се задават преди цикъла. Окончателните резултати се извеждат след него.

2. Обработи и провери резултата

Първите четири реда показват променените елементи. Python използва len и range, а C# — Length и индексен for. Действията и редът им са еднакви.

Python

values = [-2, 5, 0, 8]
count = 0
total = 0
for i in range(len(values)):
    if values[i] < 0:
        values[i] = 0
    if values[i] > 0:
        count = count + 1
        total = total + values[i]
for value in values:
    print(value)
print("Брой:", count)
print("Сума:", total)

C#

using System;

int[] values = new int[] { -2, 5, 0, 8 };
int count = 0;
int total = 0;
for (int i = 0; i < values.Length; i = i + 1)
{
    if (values[i] < 0)
    {
        values[i] = 0;
    }
    if (values[i] > 0)
    {
        count = count + 1;
        total = total + values[i];
    }
}
foreach (int value in values)
{
    Console.WriteLine(value);
}
Console.Write("Брой: ");
Console.WriteLine(count);
Console.Write("Сума: ");
Console.WriteLine(total);

4. Редът има значение

Ако вместо отрицателните заменяме положителните с 0, проверката след замяната вече няма да ги преброи. За брой на първоначалните положителни трябва да броим преди промяната или да запазим старата стойност в променлива. Винаги уточнявай дали резултатът се отнася за началните или за променените данни.

6. Упражнение с няколко условия

За списък от оценки от 2 до 6 преброй оценките поне 5 и намери сумата им. След това изведи индексите на всички двойки. Използвай отделен резултат за всяка задача и провери случай без нито една подходяща оценка.

7. Самостоятелни задачи

  1. Добави брояч за заменените отрицателни стойности.
  2. Промени условието за броене на неотрицателни стойности след замяната. Какво се получава?
  3. За [2, 6, 4, 5, 2] намери броя и сумата на оценките поне 5 и индексите на двойките.
  4. Кога обхождането по стойност е достатъчно?
Отговори и насоки
  1. Увеличавай отделен брояч в условието values[i] < 0, преди или при замяната. За примера той е 1.
  2. Всички елементи след замяната са неотрицателни; броят е дължината, в примера 4.
  3. Брой 2, сума 11, индекси 0 и 4.
  4. Когато само четем стойности и не ни трябва позиция за промяна или извеждане.

Запомни: Планирай кога четеш и кога променяш елемент. Това определя смисъла на броячите и сумите.
