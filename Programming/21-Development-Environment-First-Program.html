Програмиране - Среда за разработка. Създаване, записване и изпълнение на програма

В урок 20 разграничихме изходен код, компилатор и интерпретатор и прочетохме първите примери на Python и C#. Сега ще ги създадем като файлове, ще ги запазим и ще ги изпълним. След всяка промяна ще проверяваме дали стартираме актуалния запис.

1. Какво включва средата за разработка?

Редактор на код е приложение за писане и променяне на програмния текст. То може да показва номера на редове, да оцветява различни части на кода и да предлага довършване на имена. Тези помощни средства не доказват, че програмата е правилна.

Среда за разработка е съвкупност от редактор и инструменти за подготовка, стартиране и откриване на грешки. Разширение е добавка към редактора с допълнителни възможности. В този урок използваме Visual Studio Code (VS Code) в Windows.

Терминал е прозорец, в който въвеждаме команди за инструменти и виждаме техния изход. Познаваш конзолата от урок 19; в интегрирания терминал на редактора можем да стартираме програма и да видим резултата ѝ. Командата за стартиране се пише в терминала, а изходният код — във файла.

2. Необходимите инструменти

  • Visual Studio Code — общият редактор.
  • Python 3.10 или по-нова версия и разширението Python от Microsoft във VS Code — за Python файловете.
  • .NET SDK — инструментите за създаване, компилиране и стартиране на C# проекти. SDK означава комплект инструменти за разработка. Само .NET Runtime осигурява изпълнение, но не заменя SDK за създаването на проекта.

Ако инструментите вече са налични, използвай тях. След нова инсталация отвори редактора и терминала отново, за да могат да разпознаят командите. Разширението Python не съдържа самия интерпретатор.

3. Подготви работната папка

  1. Създай папка Lesson21 на удобно място в своите документи.
  2. Във VS Code избери File → Open Folder и отвори точно тази папка.
  3. В панела с файловете създай подпапка Python. Засега не създавай папка CSharp: инструментът ще я създаде с проекта.

Проект е организирана група файлове и настройки за едно приложение. Python примерът ни ще е един файл. За C# ще създадем конзолен проект — приложение с текстов вход и изход.

В края структурата ще съдържа:

Lesson21/
    Python/
        hello.py
    CSharp/
        CSharp.csproj
        Program.cs

Файлът с разширение .csproj пази настройките на C# проекта. Program.cs съдържа изходния код. При работа може да се появят и служебни папки с резултати от компилирането; не е нужно да ги редактираш.

4. Създай и запази Python файла

  1. В подпапката Python създай файл hello.py.
  2. Въведи Python примера по-долу. Използвай обикновени кавички ", а не типографските „ “.
  3. Натисни Ctrl+S. Това записва текущото съдържание във файла.
  4. Отвори палитрата с команди с Ctrl+Shift+P, избери Python: Select Interpreter и посочи инсталирания Python 3. Палитрата е поле за търсене на команди на редактора.
  5. С активен файл hello.py избери Run Python File in Terminal — бутона за изпълнение на целия Python файл.

5. Първа програма на двата езика

За Python запиши левия пример в Python/hello.py. За C# ще запишем десния пример в CSharp/Program.cs след създаването на проекта в следващия раздел. Не поставяй двата примера в един файл. Извикванията и кавичките са въведени в урок 20.

Python

print("Здравей, свят!")

C#

System.Console.WriteLine("Здравей, свят!");

Резултат и на двете програми:

Здравей, свят!

В терминала може да виждаш и командата, с която средата е стартирала Python, както и пътя до файла. Това не е част от изхода на нашата програма. Сравнявай реда със съобщението с очаквания резултат.

6. Създай и изпълни C# проекта

  1. Отвори Terminal → New Terminal. Работната папка на терминала трябва да е Lesson21, отворена в редактора.
  2. Въведи командата за проверка на SDK и натисни Enter:
dotnet --version

Трябва да се покаже номер на инсталирания SDK. Номерът може да е различен на различните компютри. Ако командата не е разпозната, провери дали е инсталиран .NET SDK и отвори нов терминал.

  1. В същия терминал създай конзолния проект:
dotnet new console --output CSharp

dotnet стартира инструмента на .NET; new console избира шаблон за конзолно приложение; --output CSharp задава папката за създадените файлове. Изпълни командата веднъж за този проект. За следващо стартиране не създавай проекта отново.

  1. Отвори създадения CSharp/Program.cs. Замени примерното му съдържание с C# реда от раздела „Първа програма на двата езика“.
  2. Запази с Ctrl+S. В същия терминал, още в Lesson21, изпълни:
dotnet run --project CSharp

run подготвя и стартира приложението. --project CSharp посочва папката на проекта спрямо текущата папка. .NET компилира необходимото преди изпълнението. Изчакай завършването: при първата подготовка може да е нужна интернет връзка за възстановяване на необходимите компоненти.

Очакваният изход на програмата е същият: Здравей, свят! Използваме инструкции направо в Program.cs, както беше обяснено в урок 20. За тези примери не е нужно да добавяш друга обвивка около реда.

7. Редактирай → запази → стартирай → провери

След успешното първо изпълнение замени съобщението и в двете програми с Първата ми програма. Запази и стартирай отново. Ако продължава да се вижда старият текст, провери файла, записването и проекта, който стартираш.

След това използвай следващите два реда вместо предишното съдържание. Всяко извикване извежда отделен ред. Знакът * за умножение е познат от урок 20.

8. Промяна и проверка на резултата

Алгоритъмът е линеен, както в урок 17: първо показваме съобщение, после резултата от изчисление. В Python редовете са в hello.py, а в C# — в Program.cs. Запази преди повторното стартиране.

Python

print("Проверка")
print(3 * 2)

C#

System.Console.WriteLine("Проверка");
System.Console.WriteLine(3 * 2);

Резултат и на двете програми:

Проверка
6

9. Провери реакцията при грешка

  1. В Python файла временно махни затварящата скоба на първия ред. Запази и стартирай.
  2. Прочети посочения файл, ред и съобщението за синтактична грешка. Върни скобата, запази и провери отново.
  3. В C# файла временно махни точката и запетаята след първата инструкция. Запази и стартирай проекта.
  4. Прочети съобщението на компилатора. Върни точката и запетаята, запази и стартирай отново.

Целта е да свържеш съобщението с конкретна промяна. Ако стартиране е неуспешно, това не е нов резултат от програмата; първо трябва да поправиш грешката.

11. Самостоятелни задачи

  1. Покажи съобщението „Уча програмиране“ и на двата езика. Запази и изпълни файловете.
  2. Промени изчислението така, че да намира цената на 4 билета по 3 лева. Какъв резултат очакваш?
  3. Затвори и отвори отново работната папка. Намери двата изходни файла и стартирай програмите.
  4. Обясни разликата между запазване на файл, компилиране и изпълнение.
  5. Кои команди създават проекта и кои само го стартират?
Проверка
  1. Смени само текста между кавичките. Не добавяй българските кавички от условието.
  2. Изразът е 4 * 3; очакваният резултат е 12.
  3. Python/hello.py и CSharp/Program.cs. За C# използвай съществуващия проект.
  4. Запазването записва текста; компилирането го преобразува; изпълнението извършва зададените действия.
  5. dotnet new console създава проект; dotnet run --project CSharp го подготвя и стартира. Run Python File in Terminal стартира избрания Python файл.

Запомни: работи в ясна папка, запазвай промените и проверявай резултата след всяко стартиране. Следващият урок ще разгледа по-подробно структурата на проста програма и извеждането на данни.
