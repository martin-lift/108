Програмиране - Условна конструкция с едно разклонение

В уроци 31 и 32 получавахме логически резултат. Сега условието ще определя дали да се извърши действие. Това е програмният запис на избора от блок-схемите.

1. Едно условно действие

Условна конструкция изпълнява блок само когато условието е вярно. Блок е група инструкции, които принадлежат на конструкцията. Ако проверката е невярна, блокът се пропуска и изпълнението продължава след него.

В Python пишем if условие: и отстъп от четири интервала за всяка инструкция в блока. Двоеточието е задължително. В C# пишем if (условие), а блокът е между фигурни скоби { }. Няма точка и запетая непосредствено след if.

2. Покажи предупреждение при малък запас

Входът е неотрицателен цял брой. Последното извеждане е извън блока и се изпълнява независимо от резултата на проверката.

Въведи последователно: 4. След всяка стойност натисни Enter.

Python

stock = int(input())
if stock < 5:
    print("Нисък запас")
print("Проверено")

C#

using System;

int stock = int.Parse(Console.ReadLine() ?? "");
if (stock < 5)
{
    Console.WriteLine("Нисък запас");
}
Console.WriteLine("Проверено");

Изход на двете програми:

Нисък запас
Проверено

Границата 5 не се включва. Ако задачата е „най-много 5“, условието трябва да е stock <= 5. Резултатът не се избира по това дали сме написали текст, а по стойността на логическия израз.

4. Няколко действия в един блок

Можем да присвоим нова стойност и след това да изведем съобщение. Всички инструкции, които трябва да зависят от условието, остават в един и същ блок. В Python еднаквият отстъп показва принадлежността. В C# тя се определя от фигурните скоби, а отстъпите улесняват четенето.

Не смесвай табулации и интервали в Python. В C# винаги използвай фигурни скоби в тези упражнения, включително за едно действие. Така добавянето на втора инструкция няма да промени неочаквано обхвата.

5. Самостоятелни задачи

  1. Промени границата така, че предупреждението да се показва и при запас 5.
  2. Покажи „Отрицателна стойност“ само при въведено число под нула.
  3. Защо „Проверено“ се извежда и при stock = 8?
  4. Какво ще стане, ако последният Python print бъде преместен навътре?
Отговори и насоки
  1. Използвай <= 5; провери 4, 5 и 6.
  2. Условието е number < 0; провери −1, 0 и 1.
  3. Инструкцията е след условния блок.
  4. И двете съобщения ще се извеждат само при вярното условие.

Запомни: Условието управлява само своя блок. След блока програмата продължава с общите инструкции.
