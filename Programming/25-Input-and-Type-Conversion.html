Програмиране - Въвеждане на данни и преобразуване на типове

Досега стойностите бяха зададени направо в кода. В този урок потребителят ще ги въвежда при изпълнение. Ще различаваме прочитането на текст от преобразуването му към число.

1. Входът идва като текст

В Python input() прочита един въведен ред и връща текстов низ. В C# това прави Console.ReadLine(). След въвеждането натискаме Enter; знакът за край на реда не става част от върнатия текст.

Ако въведеш 12, получаваш текста „12“, а не автоматично число. За изчисление трябва преобразуване на тип — създаване на стойност от необходимия вид чрез определени правила.

В C# ReadLine може да върне null — липса на стойност, когато входът е приключил. В примерите използваме ?? "": ако има текст, вземи него; ако има null, използвай празен низ. Това не проверява дали текстът е валидно число. Натискането само на Enter дава празен текст и също не е число.

2. Прочети име

Първо показваме какви данни очакваме. После програмата изчаква един ред и използва получения текст. В показания изход не включваме реда, който сам въвеждаш; терминалът може да го показва отделно.

Въведи последователно: Мая. След всяка стойност натисни Enter.

Python

print("Име:")
name = input()
print("Здравей,", name)

C#

using System;

Console.WriteLine("Име:");
string name = Console.ReadLine() ?? "";
Console.Write("Здравей, ");
Console.WriteLine(name);

Изход на двете програми:

Име:
Здравей, Мая

3. От текст към цяло число

В Python int(text) преобразува подходящ текст в цяло число. В C# използваме int.Parse(text); името Parse означава разчитане на текстов запис по очаквани правила. Неподходящият запис предизвиква грешка, вместо автоматично да стане нула.

В записа int(input()) първо се изпълнява вътрешното input, а след това int обработва резултата. Това е вложено извикване. В C# можем по същия начин да подадем резултата от ReadLine на Parse.

4. Обща цена от въведени цели числа

Въвеждаме неотрицателен брой и неотрицателна целочислена цена. Избираме малки стойности, така че произведението да се побере в C# int. Променливите и умножението са познати от уроци 23 и 20.

Въведи последователно: 3, 2. След всяка стойност натисни Enter.

Python

print("Брой:")
quantity = int(input())
print("Единична цена:")
unit_price = int(input())
total = quantity * unit_price
print("Общо:", total)

C#

using System;

Console.WriteLine("Брой:");
int quantity = int.Parse(Console.ReadLine() ?? "");
Console.WriteLine("Единична цена:");
int unitPrice = int.Parse(Console.ReadLine() ?? "");
int total = quantity * unitPrice;
Console.Write("Общо: ");
Console.WriteLine(total);

Изход на двете програми:

Брой:
Единична цена:
Общо: 6

5. От текст към число с дробна част

В Python използваме float(text), а в C# — double.Parse(...). За общите примери ще въвеждаме десетична точка: например 2.5. Настройките за показване и разчитане на числа според езика и региона се наричат култура в .NET.

За еднакво поведение на различни компютри C# примерът задава CultureInfo.InvariantCulture — фиксирани правила с десетична точка. Директивата using System.Globalization; позволява кратките имена на тези готови средства, както using System в урок 22. NumberStyles.Float задава разчитане на дробно число без разделители за групиране на хилядите; така запетаята не се приема вместо точка.

При извеждането area.ToString(...) създава текстов запис на числовата стойност. Подаваме същата култура, за да остане точката и в резултата. Това е изрично форматиране, а не промяна на самото число.

6. Лице на правоъгълник с дробни страни

Въведи положителни дължини с точка при дробната част. Дългите C# извиквания са пренесени на няколко реда за четимост; скобите и крайното ; запазват инструкцията цяла. При тези данни двата езика показват еднакъв запис. При други стойности представянето на цяло число с дробен тип може да е например 10.0 в Python и 10 в C# — стойността е една и съща.

Въведи последователно: 2.5, 4.5. След всяка стойност натисни Enter.

Python

print("Дължина:")
length = float(input())
print("Широчина:")
width = float(input())
area = length * width
print("Лице:", area)

C#

using System;
using System.Globalization;

Console.WriteLine("Дължина:");
double length = double.Parse(
    Console.ReadLine() ?? "",
    NumberStyles.Float,
    CultureInfo.InvariantCulture);
Console.WriteLine("Широчина:");
double width = double.Parse(
    Console.ReadLine() ?? "",
    NumberStyles.Float,
    CultureInfo.InvariantCulture);
double area = length * width;
Console.Write("Лице: ");
Console.WriteLine(
    area.ToString(CultureInfo.InvariantCulture));

Изход на двете програми:

Дължина:
Широчина:
Лице: 11.25

Python обикновено съобщава ValueError при невалиден числов текст; C# Parse съобщава FormatException. Това са имена на видове грешки при изпълнение. При цяло число извън диапазона на C# int може да се получи OverflowException. Подробното обработване на такива случаи ще изучим по-късно; тук наблюдавай съобщението, поправи входа и стартирай отново.

Валиден запис и допустима стойност за задачата са различни неща. Например −3 е валиден запис на цяло число, но не е допустим брой тетрадки. Текущите примери разчитат да подадеш стойности от описаната област; не извършват автоматична проверка на всички условия на задачата.

8. Провери с различни входни данни

Използвай тестовите случаи от урок 19: вход, очакван резултат и действителен резултат. За общата цена провери 3 и 2 → 6; 0 и 2 → 0; 4 и 3 → 12. За лицето провери 2.5 и 4.5 → 11.25 и 1.5 и 1.5 → 2.25. Подай и невалиден запис, за да видиш реакцията.

  1. Промени програмата за име така, че да показва „Добре дошъл, “ и въведеното име.
  2. Създай програма на двата езика, която прочита две цели числа и извежда техния сбор. Провери 7 и 5.
  3. Защо две прочитания на текста „12“ и „3“ не са достатъчни за числов сбор?
  4. Каква е разликата между int("3.5") и преобразуване на текста "3.5" към float?
  5. Защо отрицателният брой предмети изисква проверка, въпреки че преобразуването към цяло число може да успее?
Отговори и насоки
  1. Запази прочитането; промени само надписа в извеждането.
  2. Преобразувай всяко прочитане към int, събери стойностите и изведи 12.
  3. Те са низове; съединяването им дава „123“, а не числото 15.
  4. Първото е невалидно преобразуване от текст към цяло; float("3.5") дава дробна числова стойност.
  5. Типът позволява отрицателно число, но условието на задачата не го допуска.

Запомни: първо прочитаме текст, после го преобразуваме според нужния тип. Уточнявай допустимия вход и проверявай резултатите с няколко случая.
