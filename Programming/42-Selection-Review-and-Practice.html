Програмиране - Условни конструкции и многовариантен избор. Обобщение и упражнение

Ще избираме между условни конструкции и многовариантен избор според смисъла на задачата. Същият резултат може да се постигне с различни записи, но не всеки е еднакво ясен.

1. Кой вид избор е нужен?

НеобходимостКонструкция
Действие само при вярно условиеif
Два взаимно изключващи се пътяif / else
Няколко диапазонаif / elif / else или else if
Номера на командиmatch / switch
Допълнителна проверка по избран пътВложено if

Винаги започвай с входните данни и очакваните случаи. Изборът на конструкция идва след разбирането на задачата.

2. От номер към описание, после проверка

Въвеждат се две цели числа на отделни редове: команда и брой. При команда 1 проверяваме броя вътре в случая. Този пример винаги прочита двата реда, включително при команда 0.

Въведи последователно: 1, 3. След всяка стойност натисни Enter.

Python

choice = int(input())
count = int(input())
match choice:
    case 1:
        if count > 0:
            print(count * 5)
        else:
            print("Нужен е положителен брой")
    case 0:
        print("Край")
    case _:
        print("Непозната команда")

C#

using System;

int choice = int.Parse(Console.ReadLine() ?? "");
int count = int.Parse(Console.ReadLine() ?? "");
switch (choice)
{
    case 1:
        if (count > 0)
        {
            Console.WriteLine(count * 5);
        }
        else
        {
            Console.WriteLine("Нужен е положителен брой");
        }
        break;
    case 0:
        Console.WriteLine("Край");
        break;
    default:
        Console.WriteLine("Непозната команда");
        break;
}

3. Покритие на случаите

За горния пример са нужни: валидна команда с положителен брой; същата команда с нула или отрицателен брой; край; непозната команда. Само тестове за положителни количества няма да проверят останалите пътища.

Състави тестова таблица преди кода. След изпълнение отбележи кой case и кой вложен клон са били посетени. Съобщението „Край“ не означава, че цялата програма непременно е прекратена на този ред: след конструкцията може да има общи инструкции.

4. Подготовка за самостоятелно решение

Планирай по една задача за диапазони, за конкретни номера и за две вложени проверки. Към всяка добави обикновен вход, граница, равенство и недопустима стойност, когато тези случаи имат смисъл. Изпиши очакваните резултати, преди да стартираш програмата.

5. Самостоятелни задачи

  1. Направи меню 1 за четност и 2 за знак на въведено число.
  2. Класифицирай стойност в „под 10“, „от 10 до 20 включително“ и „над 20“.
  3. Провери двете страни на правоъгълник преди лице.
  4. За всяка от задачите посочи защо избраната конструкция е подходяща.
Отговори и насоки
  1. Използвай switch / match за командата и условие вътре в случая.
  2. Удобна е верига: x < 10; x <= 20; else.
  3. Изисквай a > 0 и b > 0 преди умножение.
  4. Номерата са конкретни случаи, диапазоните са неравенства, а допустимостта е логическа проверка.

Запомни: Различавай вида на избора от проверката на данните. Една програма може да съчетава switch / match с вложени условия.
