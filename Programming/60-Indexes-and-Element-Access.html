Програмиране - Индекси и достъп до елементите на масив или списък

Ще намираме конкретна стойност по нейния индекс. В общия модел на Python списъците и C# масивите първата позиция е 0.

1. Допустими положителни индекси

При дължина n общите неотрицателни индекси са от 0 до n - 1. За [8, 3, 5] индексите са 0, 1 и 2. Записът values[i] означава елемента на позиция i, а не числото i.

2. Първи и последен елемент

Последният индекс е дължината минус 1. Стойността на първия елемент е 8, а не 0.

Python

values = [8, 3, 5]
print(values[0])
print(values[len(values) - 1])

C#

using System;

int[] values = new int[] { 8, 3, 5 };
Console.WriteLine(values[0]);
Console.WriteLine(values[values.Length - 1]);

Изход на двете програми:

8
5

3. Проверка преди достъп

Индекс, равен на дължината, е извън общата област. При празна структура няма първи или последен елемент. Трябва да проверим, преди да използваме квадратните скоби.

Python допуска и отрицателни индекси за достъп от края, например −1. C# не приема отрицателен int като такъв индекс. В тези упражнения използваме общия неотрицателен модел и изрично отхвърляме отрицателните числа.

4. Прочети индекс и го провери

Проверката включва 0 и изключва дължината.

Въведи последователно: 1. След всяка стойност натисни Enter.

Python

values = [8, 3, 5]
index = int(input())
if (index >= 0) and (index < len(values)):
    print(values[index])
else:
    print("Невалиден индекс")

C#

using System;

int[] values = new int[] { 8, 3, 5 };
int index = int.Parse(Console.ReadLine() ?? "");
if ((index >= 0) && (index < values.Length))
{
    Console.WriteLine(values[index]);
}
else
{
    Console.WriteLine("Невалиден индекс");
}

Изход на двете програми:

3

5. Позиция в описание и индекс в кода

„Трети елемент“ в обикновения език е индекс 2. Ако потребителят въвежда номер от 1 до n, първо провери този диапазон и после извади 1. Не смесвай двете номерации в едни и същи указания.

6. Самостоятелни задачи

  1. Какъв е последният индекс при 7 елемента?
  2. Коя стойност е values[2] за [8, 3, 5]?
  3. Какви индекси има празна структура?
  4. Превърни въведен номер на елемент от 1 до 3 в индекс.
Отговори и насоки
  1. 6.
  2. 5.
  3. Няма допустим индекс за достъп.
  4. Първо провери 1 <= position <= 3, после index = position - 1.

Запомни: Преди достъп провери 0 <= index < дължината. Последният индекс не е равен на броя елементи.
