Програмиране - Промяна на елементи на масив или списък. Упражнение

Съхранените стойности могат да се променят по индекс. Достъпът от урок 60 вече ще бъде и отляво на присвояването.

1. Нова стойност на съществуваща позиция

values[index] = new_value заменя елемента на дадената позиция. Дължината остава същата и останалите позиции не се разместват. Проверяваме индекса преди присвояването, както преди прочитането.

2. Промени една позиция

Винаги се прочитат два реда: индекс и нова стойност. След това показваме цялата структура, включително след невалиден индекс.

Въведи последователно: 1, 99. След всяка стойност натисни Enter.

Python

values = [10, 20, 30]
index = int(input())
new_value = int(input())
if (index >= 0) and (index < len(values)):
    values[index] = new_value
    print("Променено")
else:
    print("Невалиден индекс")
for i in range(len(values)):
    print(values[i])

C#

using System;

int[] values = new int[] { 10, 20, 30 };
int index = int.Parse(Console.ReadLine() ?? "");
int newValue = int.Parse(Console.ReadLine() ?? "");
if ((index >= 0) && (index < values.Length))
{
    values[index] = newValue;
    Console.WriteLine("Променено");
}
else
{
    Console.WriteLine("Невалиден индекс");
}
for (int i = 0; i < values.Length; i = i + 1)
{
    Console.WriteLine(values[i]);
}

Промяната е по позиция, а не „замени всяка стойност 20“. Ако има няколко равни елемента, това присвояване засяга само посочения индекс.

4. Израз със старата стойност

Можем да използваме старата стойност вдясно: values[index] = values[index] + 1. Първо се прочита старият елемент, после се записва увеличеният. Това следва същото правило като промяна на обикновена променлива.

Не използвай невалидния индекс дори само за извеждане на „стара стойност“ преди проверката. Всяка операция с тази позиция трябва да е в допустимия клон.

5. Самостоятелни задачи

  1. Промени последния елемент на 0.
  2. Увеличи избрания елемент с 5 вместо да четеш нова стойност.
  3. Какво се случва с дължината след промяна?
  4. Защо при index = 3 няма промяна в основния пример?
Отговори и насоки
  1. Използвай индекс 2 за дадената структура.
  2. След валидиране присвои values[index] + 5.
  3. Остава 3.
  4. Допустимите индекси са 0, 1 и 2.

Запомни: Присвояването по индекс заменя елемент, а не добавя позиция. Провери индекса преди всяко използване.
