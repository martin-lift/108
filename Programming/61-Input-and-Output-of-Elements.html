Програмиране - Въвеждане и извеждане на елементи на масив или списък

Ще запазим n въведени стойности и едва след това ще ги покажем. Това позволява повторна работа с вече съхранените данни.

1. Създаване преди попълване

В Python започваме с празен списък и добавяме с append(value). Методът добавя една стойност в края и увеличава дължината с 1. В C# създаваме new int[n]: масив с n позиции, първоначално запълнени с нули. После присвояваме входа на всяка позиция.

Създай структурата веднъж преди цикъла. Ако я създаваш отново вътре, ще изтриваш предишните данни. За n = 0 няма елементи за попълване.

2. Прочети и после покажи

За упражненията избирай n до 100. Първият цикъл попълва, а вторият показва вече запазената поредица.

Въведи последователно: 3, 4, -2, 7. След всяка стойност натисни Enter.

Python

n = int(input())
if n < 0:
    print("Невалиден брой")
else:
    values = []
    for i in range(n):
        values.append(int(input()))
    print("Елементи:")
    for i in range(len(values)):
        print(values[i])

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
if (n < 0)
{
    Console.WriteLine("Невалиден брой");
}
else
{
    int[] values = new int[n];
    for (int i = 0; i < n; i = i + 1)
    {
        values[i] = int.Parse(Console.ReadLine() ?? "");
    }
    Console.WriteLine("Елементи:");
    for (int i = 0; i < values.Length; i = i + 1)
    {
        Console.WriteLine(values[i]);
    }
}

Изход на двете програми:

Елементи:
4
-2
7

3. Защо два цикъла?

Първото преминаване получава всички данни. Второто няма нов вход, а чете от структурата. Така можем да покажем същите данни още веднъж без потребителят да ги въвежда повторно.

В Python append не е присвояване на резултат в списъка. Не записвай values = values.append(...): методът променя списъка и не връща нов списък за това присвояване. Използвай го като отделно действие.

4. Дължина и брой прочитания

При Python след k добавяния дължината е k. При C# дължината е n още преди първото прочитане, но това не означава, че потребителските стойности вече са въведени. Непопълнените позиции съдържат началните нули.

5. Самостоятелни задачи

  1. Покажи всяка стойност два пъти, без ново четене.
  2. Провери нулев и отрицателен брой.
  3. Каква е разликата между append и присвояване на values[i]?
  4. Защо условието на изходния цикъл е i < Length, а не <=?
Отговори и насоки
  1. Добави второ извеждане в изходния цикъл или повтори обхождането.
  2. 0 дава само надписа; отрицателният брой дава съобщение.
  3. append създава нова крайна позиция; присвояването заменя съществуваща.
  4. Индексът Length е извън границите.

Запомни: Попълването и показването са отделни задачи. Броят повторения трябва да съответства на действителната дължина.
