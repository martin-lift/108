2. Сума и средно на избрани стойности

Подай n от 0 до 100 и стойности от −1000 до 1000. Делителят е броят избрани стойности, а не общото n.

Въведи последователно: 3, -5, 2, 4. След всяка стойност натисни Enter.

Python

n = int(input())
selected_sum = 0
selected_count = 0
for i in range(n):
    value = int(input())
    if value > 0:
        selected_sum = selected_sum + value
        selected_count = selected_count + 1
if selected_count == 0:
    print("Няма положителни")
else:
    average = selected_sum / selected_count
    print(format(average, ".2f"))

C#

using System;
using System.Globalization;

int n = int.Parse(Console.ReadLine() ?? "");
int selectedSum = 0;
int selectedCount = 0;
for (int i = 0; i < n; i = i + 1)
{
    int value = int.Parse(Console.ReadLine() ?? "");
    if (value > 0)
    {
        selectedSum = selectedSum + value;
        selectedCount = selectedCount + 1;
    }
}
if (selectedCount == 0)
{
    Console.WriteLine("Няма положителни");
}
else
{
    double average = selectedSum * 1.0 / selectedCount;
    Console.WriteLine(average.ToString(
        "F2", CultureInfo.InvariantCulture));
}

Изход на двете програми:

3.00

3. Четири въпроса към всеки цикъл

Какво е известно преди първата проверка? Какво е вярно след всяка итерация? Коя промяна води към край? Какво означава празният случай? Тези въпроси показват липсваща инициализация, неправилен делител или безкрайно повторение.

За максимум на избраните стойности първата избрана стойност, а не непременно първата прочетена, трябва да зададе началото. Ако нито една не е избрана, няма такъв максимум. Обмисли този случай, преди да пишеш условията.

4. Самостоятелни задачи

  1. Преброй числата от [10, 20] в поредица от n входа.
  2. Намери минимум и максимум на непразна поредица.
  3. Реши сума до сигнал 0 и уточни дали 0 е данни.
  4. Напиши тестове за средно само на положителните.
Отговори и насоки
  1. Брояч 0 и увеличение при двете включени граници.
  2. Начало от първата стойност, после n - 1 сравнения.
  3. При сигнал 0 той не се включва като обикновена стойност.
  4. Празна поредица, само неположителни, една положителна и смесени стойности.

Запомни: Пази различните обобщения отделно и проверявай празния случай според смисъла на резултата.
