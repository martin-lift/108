Програмиране - Изчисляване на средна стойност на въведени числа

Средното аритметично изисква едновременно сбор и брой. При празна поредица няма стойност, с която да разделим безопасно сумата.

1. Формула и празен случай

За n числа средното е total / n. При n = 0 делението е недопустимо и няма средна стойност. Не извеждаме 0 като заместител, защото средното 0 и липсата на данни са различни резултати.

За n > 0 прочитаме точно n стойности, натрупваме сумата и делим след цикъла. В C# умножаваме сумата по 1.0 преди делението, за да получим дробен резултат и при цели входни стойности.

2. Средно на n цели числа

Използвай n до 100 и входни стойности от −1000 до 1000. За n <= 0 не се прочитат допълнителни числа.

Въведи последователно: 3, 4, 4, 5. След всяка стойност натисни Enter.

Python

n = int(input())
if n <= 0:
    print("Няма допустим брой стойности")
else:
    total = 0
    for i in range(n):
        value = int(input())
        total = total + value
    average = total / n
    print(format(average, ".2f"))

C#

using System;
using System.Globalization;

int n = int.Parse(Console.ReadLine() ?? "");
if (n <= 0)
{
    Console.WriteLine("Няма допустим брой стойности");
}
else
{
    int total = 0;
    for (int i = 0; i < n; i = i + 1)
    {
        int value = int.Parse(Console.ReadLine() ?? "");
        total = total + value;
    }
    double average = total * 1.0 / n;
    Console.WriteLine(average.ToString(
        "F2", CultureInfo.InvariantCulture));
}

Изход на двете програми:

4.33

3. Брой прочетени или брой избрани?

Ако средното трябва да е само за положителните стойности, и сумата, и броят трябва да се обновяват при същото условие. Делителят тогава е броят на положителните, а не общото n. Отделно проверяваме дали този брой е 0.

Например при −5, 2, 4 общото средно е 0.33 при оформление до два знака, а средното на положителните е 3.00. Това са различни задачи с различен делител.

4. Контролни проверки

Входни стойностиОчакване
Едно числоСредното е самото число
Еднакви числаСредното е същата стойност
Противоположни числа с еднаква големинаСредното е 0
Няма стойностиСъобщение вместо деление

Форматирането до два знака се прави след изчислението. Не превръщай междинната сума в текст.

5. Самостоятелни задачи

  1. Изчисли средното на 1 и 2.
  2. Каква промяна е нужна за средно само на положителните?
  3. Защо проверката n > 0 трябва да е преди делението?
  4. Какво е средното на 5, 5, 5, 5?
Отговори и насоки
  1. 1.50.
  2. Условна сума и отделен брояч; проверка на брояча преди деление.
  3. Иначе нулевият брой би довел до невалидна операция.
  4. 5.00.

Запомни: Разделяй сбора на броя на точно същите стойности. Липсата на данни не е числово средно 0.
