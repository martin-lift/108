Програмиране - Самостоятелно решаване на задачи с условия и цикли. Упражнение

Ще изграждаш решение от текстово условие с повторение и избор. Започни с пример на ръка и запиши какво трябва да остане вярно след всяко прочитане.

1. Практическа задача: обработки по критерий

Прочети n числа. Намери броя и сумата на четните. Всяка стойност се посещава веднъж, но само избраните променят резултатите. Използваме познатата проверка за четност; нулата е четна, а отрицателните четни също се включват.

2. Сума и брой на четните

Ограничаваме n до 100 и стойностите до интервала −1000…1000. Сборът може да е нула, въпреки че има избрани числа.

Въведи последователно: 5, -2, 3, 4, 0, 5. След всяка стойност натисни Enter.

Python

n = int(input())
even_sum = 0
even_count = 0
for i in range(n):
    value = int(input())
    if value % 2 == 0:
        even_sum = even_sum + value
        even_count = even_count + 1
print(even_sum)
print(even_count)

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
int evenSum = 0;
int evenCount = 0;
for (int i = 0; i < n; i = i + 1)
{
    int value = int.Parse(Console.ReadLine() ?? "");
    if (value % 2 == 0)
    {
        evenSum = evenSum + value;
        evenCount = evenCount + 1;
    }
}
Console.WriteLine(evenSum);
Console.WriteLine(evenCount);

3. План за самостоятелните задачи

Опиши входа и края на четенето. Избери променливите за обобщение и началните им стойности. Запиши условието за избор. След цикъла реши как да се показва липса на избрани данни, ако резултатът е средно, минимум или максимум.

Разделяй тестовете по смисъл. Поредица без четни и поредица с четни, чиято сума е 0, имат еднаква сума, но различни броячи. Само сравнение на сумата няма да открие грешно броене.

4. Независими упражнения

Състави решения на двата езика, без да копираш само имената от примера. Подбери тестове с нула повторения, равни стойности, отрицателни числа и резултат точно на избран праг. При задачи със сигнал за край осигури той да бъде подаден.

5. Самостоятелни задачи

  1. Прочитай до −1 и преброй допустимите стойности над 50.
  2. За n числа намери средно само на нечетните.
  3. За непразна поредица намери разликата между максимума и минимума.
  4. За основния пример обясни разликата между входове [1, 3] и [−2, 2].
Отговори и насоки
  1. Не брои −1; след всяка стойност прочитай следваща.
  2. Условие value % 2 != 0; провери избрания брой преди деление.
  3. Използвай алгоритъма от урок 51 и изведи maximum - minimum.
  4. И двата сбора са 0; броят четни е съответно 0 и 2.

Запомни: Проверявай всяко изискване от условието с отделен смислен тест, а не само с един успешен пример.
