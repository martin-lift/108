Програмиране - Решаване на практически задачи с условни конструкции. Упражнение

Ще превръщаме текстови условия за цени и категории в последователни проверки. Всички тарифи тук са зададени учебни правила.

1. Уточни какво означава всеки диапазон

Нека доставка на пратка с положително цяло тегло струва 5 единици до 1 кг включително, 8 единици над 1 до 5 кг включително и 12 единици над 5 кг. Първо отхвърляме нулата и отрицателните стойности. После всеки следващ клон работи само с останалите допустими данни.

2. Избери фиксирана такса по тегло

Това е една такса за цялата пратка, избрана по диапазон. Не умножаваме таксата по теглото.

Въведи последователно: 5. След всяка стойност натисни Enter.

Python

weight = int(input())
if weight <= 0:
    print("Недопустимо тегло")
elif weight <= 1:
    print(5)
elif weight <= 5:
    print(8)
else:
    print(12)

C#

using System;

int weight = int.Parse(Console.ReadLine() ?? "");
if (weight <= 0)
{
    Console.WriteLine("Недопустимо тегло");
}
else if (weight <= 1)
{
    Console.WriteLine(5);
}
else if (weight <= 5)
{
    Console.WriteLine(8);
}
else
{
    Console.WriteLine(12);
}

Изход на двете програми:

8

3. Когато цената е по части

Друга задача може да има различен смисъл: първите три бройки струват по 10, а всяка следваща — по 7. За 4 бройки сумата е 3 × 10 + 1 × 7 = 37. Не прилагаме 7 върху всичките четири бройки.

4. Изчисли цена на две части

Броят е цяло число. Нулев брой е допустим и дава нулева сума. Проверяваме и стойности непосредствено около границата 3.

Въведи последователно: 4. След всяка стойност натисни Enter.

Python

count = int(input())
if count < 0:
    print("Невалиден брой")
elif count <= 3:
    print(count * 10)
else:
    print(30 + (count - 3) * 7)

C#

using System;

int count = int.Parse(Console.ReadLine() ?? "");
if (count < 0)
{
    Console.WriteLine("Невалиден брой");
}
else if (count <= 3)
{
    Console.WriteLine(count * 10);
}
else
{
    Console.WriteLine(30 + (count - 3) * 7);
}

Изход на двете програми:

37

5. От условието към проверките

Подчертай границите и думите „включително“, „над“, „всяка следваща“. Запиши формула за всеки клон, преди да пишеш код. След това избери дали една категория определя целия резултат или различни части от количеството се пресмятат по различен начин.

6. Самостоятелни задачи

  1. Разшири таблицата за тегло с 1, 2, 5 и 6.
  2. Каква е цената на 6 бройки при втората задача?
  3. Промени цената на следващите бройки от 7 на 8.
  4. Защо само тест с count = 2 не открива грешка във формулата за повече от 3?
Отговори и насоки
  1. Таксите са 5, 8, 8, 12.
  2. 30 + 3 × 7 = 51.
  3. Последният израз става 30 + (count - 3) * 8.
  4. Този вход не достига последния клон.

Запомни: Първо уточни смисъла на тарифата и включването на границите, после избери проверките и формулите.
