Програмиране - Целочислено деление и остатък от деление. Упражнение

В урок 26 разграничихме обикновеното и целочисленото деление. Сега ще намираме цяло частно и остатък и ще ги използваме за групиране, четност и отделяне на цифри.

1. Частно и остатък

При неотрицателно цяло число n и положителен цял делител d можем да запишем n = q × d + r, където q е цялото частно, а остатъкът r е от 0 до d - 1. Например 29 = 4 × 6 + 5.

РезултатPythonC# за int
Цяло частноn // dn / d
Остатъкn % dn % d

// в Python е оператор за деление със закръгляне към по-малкото цяло число. За неотрицателните числа тук той дава цялото частно. В C# целочисленото / отхвърля дробната част към нулата. % означава остатък, а не процент.

2. Разпредели 29 предмета в групи по 6

Получаваме 4 пълни групи и 5 останали предмета. Проверка: 4 * 6 + 5 = 29. Делителят е положителен и не е нула.

Python

n = 29
d = 6
quotient = n // d
remainder = n % d
print(quotient)
print(remainder)

C#

using System;

int n = 29;
int d = 6;
int quotient = n / d;
int remainder = n % d;
Console.WriteLine(quotient);
Console.WriteLine(remainder);

Изход на двете програми:

4
5

3. Отрицателни числа: важна разлика

Основните упражнения са с неотрицателни входове. Ако допуснем отрицателни числа, правилата на двата езика се различават:

ДействиеPythonC# с цели числа
−7, разделено целочислено на 3-7 // 3 = -3-7 / 3 = -2
Остатък-7 % 3 = 2-7 % 3 = -1
Проверка(-3) × 3 + 2 = -7(-2) × 3 - 1 = -7

Затова не пренасяй механично правило за положителни числа към отрицателни. В Python остатъкът има знака на делителя, когато не е нула; в C# при цели числа ненулевият остатък има знака на делимото.

4. Четност и делимост

Четно е цяло число, което се дели на 2 без остатък. За нечетно неотрицателно число остатъкът при деление на 2 е 1. Сравнението n % 2 == 0 дава логическа стойност; == е въведено в урок 24.

5. Провери дали число е четно

14 = 7 * 2 + 0, затова условието е вярно. Нулата също е четна. Извеждаме резултата от проверката, без да използваме условна конструкция.

Python

n = 14
is_even = n % 2 == 0
print(is_even)

C#

using System;

int n = 14;
bool isEven = n % 2 == 0;
Console.WriteLine(isEven);

Изход на двете програми:

True

6. От секунди към часове, минути и секунди

В един час има 3600 секунди, а в минута — 60. Пълните часове са цялото частно при деление на 3600. В останалите секунди намираме пълните минути, а последният остатък е броят секунди под 60.

7. Разложи продължителност

Въведи неотрицателен общ брой секунди. Трите изходни реда означават часове, минути и секунди. При 3665 проверката е 1 * 3600 + 1 * 60 + 5 = 3665.

Въведи последователно: 3665. След всяка стойност натисни Enter.

Python

total_seconds = int(input())
hours = total_seconds // 3600
remaining = total_seconds % 3600
minutes = remaining // 60
seconds = remaining % 60
print(hours)
print(minutes)
print(seconds)

C#

using System;

int totalSeconds = int.Parse(Console.ReadLine() ?? "");
int hours = totalSeconds / 3600;
int remaining = totalSeconds % 3600;
int minutes = remaining / 60;
int seconds = remaining % 60;
Console.WriteLine(hours);
Console.WriteLine(minutes);
Console.WriteLine(seconds);

Изход на двете програми:

1
1
5

8. Отделяне на десетични цифри

За неотрицателно цяло n последната цифра е n % 10. Целочисленото деление на 10 премахва последната цифра. Ако искаме цифрата на десетиците, първо премахваме единиците, а после вземаме остатъка при деление на 10.

9. Намери цифрите на 473

Примерът е за число от 0 до 999. Изходът е в ред единици, десетици, стотици. За по-дълго число n / 100 в C# или n // 100 в Python няма непременно да е една цифра.

Python

n = 473
ones = n % 10
tens = (n // 10) % 10
hundreds = n // 100
print(ones)
print(tens)
print(hundreds)

C#

using System;

int n = 473;
int ones = n % 10;
int tens = (n / 10) % 10;
int hundreds = n / 100;
Console.WriteLine(ones);
Console.WriteLine(tens);
Console.WriteLine(hundreds);

Изход на двете програми:

3
7
4

10. Самостоятелни задачи

  1. При 47 предмета и групи по 8 намери пълните групи и остатъка.
  2. Провери четността на 0, 9 и 20 чрез остатък.
  3. Преобразувай 7322 секунди в часове, минути и секунди.
  4. Намери сбора на цифрите на 508, като първо ги отделиш.
  5. Кое е грешно в твърдението „% 10 връща първата цифра“?
Отговори
  1. 5 групи и 7 предмета; 5 * 8 + 7 = 47.
  2. Остатъците са 0, 1, 0: четно, нечетно, четно.
  3. 2 часа, 2 минути, 2 секунди.
  4. 5 + 0 + 8 = 13.
  5. За неотрицателно число % 10 дава последната, тоест най-дясната десетична цифра.

Запомни: избери цялото частно за пълните групи и остатъка за останалото. Проверявай чрез n = q × d + r и спазвай областта на допустимия вход.
