Програмиране - Проследяване на условни конструкции с различни входни данни. Упражнение

След вложените условия от урок 37 ще проследяваме конкретни пътища и ще проверяваме дали програмата изпълнява точно изискваните действия.

1. Тестова таблица преди изпълнението

За всяка проверка запиши входа, стойността на условието, избрания клон и очаквания изход. След стартиране добави действителния изход. Разлика между двата изхода означава, че трябва да проверим алгоритъма, записаната програма или очакването си.

Не избирай само лесни входове. За праг 10 са полезни 9, 10 и 11. За две сравнявани числа включи и равенство. За вложен избор подбери вход за всеки достижим краен клон.

2. Сравни независими проверки с верига

Първите два if са независими и могат да изведат две букви. Последната верига извежда точно една категория.

Въведи последователно: 20. След всяка стойност натисни Enter.

Python

n = int(input())
if n >= 10:
    print("A")
if n >= 20:
    print("B")
if n >= 20:
    print("Голямо")
elif n >= 10:
    print("Средно")
else:
    print("Малко")

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
if (n >= 10)
{
    Console.WriteLine("A");
}
if (n >= 20)
{
    Console.WriteLine("B");
}
if (n >= 20)
{
    Console.WriteLine("Голямо");
}
else if (n >= 10)
{
    Console.WriteLine("Средно");
}
else
{
    Console.WriteLine("Малко");
}

B

Не прекратяваме цялата програма след първото вярно условие. Пропускането на останалите случаи се отнася само за една свързана верига.

4. Как да намериш причината

Ако на границата 20 получиш „Средно“, провери реда и знаците на условията. Ако очакваш само една буква, но виждаш две, провери дали не са използвани отделни if. Ако съобщение липсва при един вход, проследи дали променлива е зададена и дали извеждането не е попаднало в грешен блок.

Променяй по една причина и изпълнявай отново засегнатите тестове. Запази поне един тест от всеки клон, за да не поправиш един случай за сметка на друг.

5. Самостоятелни задачи

  1. Добави ред за n = 0 в тестовата таблица.
  2. Как ще се промени изходът за 20, ако вторият независим if стане elif / else if?
  3. Проследи максимум от урок 34 за равни отрицателни числа.
  4. Избери три теста, които различават > 10 от >= 10.
Отговори и насоки
  1. И двете букви се пропускат, категорията е „Малко“.
  2. B ще се пропусне, защото първата проверка вече е вярна.
  3. При −4 и −4 се избира вторият операнд и резултатът е −4.
  4. 9, 10, 11; решаващият тест е 10.

Запомни: Тествай пътищата и границите. Различавай независимите if от една свързана верига.
