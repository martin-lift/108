Програмиране - Цикъл с брояч

Когато знаем редицата на брояча, for събира управлението на повторението в по-ясен запис. Ще сравним Python range с трите части на C# for.

1. Начало, край и стъпка

В Python range(start, stop, step) описва редица от цели числа. Началото се включва, stop не се включва. Ако стъпката липсва, е 1; ако има само една граница, началото е 0. Стъпката не може да е 0.

for i in range(...): изпълнява тялото за всяка стойност от редицата. В C# for (начало; условие; промяна) има три части. Началото се извършва веднъж; условието — преди всяко тяло; промяната — след тялото.

2. Числата от 1 до n включително

За Python краят е n + 1, защото е изключен. В C# условието <= включва n. Входът е неотрицателно цяло число.

Въведи последователно: 3. След всяка стойност натисни Enter.

Python

n = int(input())
for i in range(1, n + 1):
    print(i)

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
for (int i = 1; i <= n; i = i + 1)
{
    Console.WriteLine(i);
}

Изход на двете програми:

1
2
3

3. Стъпка и посока

При range(2, 9, 2) получаваме 2, 4, 6, 8. При range(5, 0, -1) получаваме 5, 4, 3, 2, 1. Отрицателната стъпка изисква началото да е над изключения край, иначе редицата е празна.

4. Редицата 5, 3, 1

Началото е 5, стъпката е −2, а 0 не се включва. Тялото се изпълнява три пъти.

Python

for i in range(5, 0, -2):
    print(i)

C#

using System;

for (int i = 5; i > 0; i = i - 2)
{
    Console.WriteLine(i);
}

Изход на двете програми:

5
3
1

5. Разлики при брояча

В Python не променяй i вътре в този for, за да управляваш следващата стойност: тя идва от range. В C# броячът е променлива с изрична промяна, но също ще пазим промените в заглавната част за яснота. Често ще срещнеш i++ като кратък запис за увеличаване с 1 в C#; тук използваме познатото i = i + 1.

Променлива, декларирана в заглавието на C# for, не е достъпна след него. В Python името може да остане след изпълнението, но при празна редица може изобщо да не е получило стойност. Не разчитай на брояча след цикъла в тези задачи.

6. Самостоятелни задачи

  1. Изведи числата от 0 до 4.
  2. Изведи 10, 8, 6, 4, 2.
  3. Колко повторения има range(1, 5)?
  4. Защо range(1, n) не включва n?
Отговори и насоки
  1. range(5) в Python; в C# начало 0, условие i < 5.
  2. range(10, 0, -2); C# i = 10, i > 0, i = i - 2.
  3. Четири: 1, 2, 3, 4.
  4. Горната граница на range е изключена.

Запомни: Не пренасяй механично границите: range изключва края, а C# for следва написаното условие.
