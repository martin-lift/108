Програмиране - Търсене и промяна на данни в списък. Упражнение

Ще потърсим първото срещане на стойност и ще го заменим. Липсващата стойност трябва да остави структурата непроменена.

1. Раздели намирането от промяната

Входът е търсена стойност и нова стойност, всяка на отделен ред. Намираме първия индекс с линейно търсене. След цикъла проверяваме position. Само при успех заменяме точно един елемент.

Това разделяне позволява да проверим резултата преди достъпа. При position = −1 не изпълняваме values[position]. Индексът 0 означава намерен първи елемент.

2. Замени първото съвпадение

При вход 4 и 6 се променя само индекс 0. Второто срещане на 4 остава. Присвояването по индекс работи еднакво за Python списък и C# масив.

Въведи последователно: 4, 6. След всяка стойност натисни Enter.

Python

values = [4, 7, 4, 9]
target = int(input())
replacement = int(input())
position = -1
for i in range(len(values)):
    if values[i] == target:
        position = i
        break
if position == -1:
    print("Не е намерено")
else:
    values[position] = replacement
    print("Индекс:", position)
for value in values:
    print(value)

C#

using System;

int[] values = new int[] { 4, 7, 4, 9 };
int target = int.Parse(Console.ReadLine() ?? "");
int replacement = int.Parse(Console.ReadLine() ?? "");
int position = -1;
for (int i = 0; i < values.Length; i = i + 1)
{
    if (values[i] == target)
    {
        position = i;
        break;
    }
}
if (position == -1)
{
    Console.WriteLine("Не е намерено");
}
else
{
    values[position] = replacement;
    Console.Write("Индекс: ");
    Console.WriteLine(position);
}
foreach (int value in values)
{
    Console.WriteLine(value);
}

3. Първо, последно или всички?

За първо срещане прекратяваме с break. За последно пазим всеки намерен индекс до края и заменяме след цикъла. За всички срещания можем да заменяме направо при всяко съвпадение и да броим замените. Това са различни изисквания и водят до различни резултати при повторения.

4. Променените данни са ново състояние

След замяната следващо търсене работи с новите стойности. Ако заменим първото 4 с 6, следващото търсене на 4 ще намери индекс 2. Ако новата стойност е равна на старата, търсенето е успешно, но видимите стойности не се променят.

Замяната не променя дължината. При паралелните структури от урок 67 променяй правилната характеристика на намерения индекс и пази общото съответствие.

5. Самостоятелни задачи

  1. Замени всички срещания на 4 с 0 в началните данни.
  2. Как да замениш само последното 4?
  3. Какво се извежда при празна структура?
  4. Защо условие if position е неправилно за проверка на намерен индекс в Python?
Отговори и насоки
  1. Резултатът е [0, 7, 0, 9]; броят замени е 2.
  2. Без break намираме последния индекс 2; след успешна проверка заменяме него.
  3. Съобщение за липса, без редове за елементи.
  4. 0 е невярно в логически контекст, а −1 е вярно. Използвай изрично position == -1 или position != -1.

Запомни: Успешно търсене и действителна промяна са различни неща. Уточни колко срещания трябва да замениш.
