Програмиране - Условна конструкция с две разклонения

В урок 33 пропускахме блока при невярно условие. Сега ще зададем и действие за този случай чрез if и else.

1. Два взаимно изключващи се клона

else означава „иначе“. При вярно условие се изпълнява блокът на if, а при невярно — блокът на else. При едно преминаване през конструкцията се избира точно един клон, след което програмата продължава след двата.

В Python else е на същото ниво като if и завършва с двоеточие. В C# else е след затварящата скоба на първия блок. Не пишем второ условие след else.

2. По-голямото от две числа

Алгоритъмът е познат от урок 18. При равенство се избира b, чиято стойност е същата. В C# maximum е декларирана преди конструкцията и получава стойност и по двата пътя.

Въведи последователно: 8, 3. След всяка стойност натисни Enter.

Python

a = int(input())
b = int(input())
if a > b:
    maximum = a
else:
    maximum = b
print(maximum)

C#

using System;

int a = int.Parse(Console.ReadLine() ?? "");
int b = int.Parse(Console.ReadLine() ?? "");
int maximum;
if (a > b)
{
    maximum = a;
}
else
{
    maximum = b;
}
Console.WriteLine(maximum);

Изход на двете програми:

8

3. Стойност, достъпна след избора

Ако ще използваме резултата след конструкцията, той трябва да е зададен по всеки възможен път. В C# променлива, декларирана само вътре във фигурните скоби, е достъпна само в съответния блок — това е нейната област на видимост. Затова декларираме maximum отвън и присвояваме отвътре.

В Python if не създава отделна такава област, но името все пак трябва да получи стойност преди употреба. Ако го зададем само в единия клон, другият вход може да доведе до грешка.

4. Четно или нечетно

Остатъкът и проверката за равенство са въведени в предишните уроци. Не е необходимо отделно да проверяваме втори път за нечетност.

Въведи последователно: 0. След всяка стойност натисни Enter.

Python

n = int(input())
if n % 2 == 0:
    print("Четно")
else:
    print("Нечетно")

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
if (n % 2 == 0)
{
    Console.WriteLine("Четно");
}
else
{
    Console.WriteLine("Нечетно");
}

Изход на двете програми:

Четно
