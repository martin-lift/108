Програмиране - Годишен преговор и обобщение

Ще свържем представянето на информацията, алгоритмите и програмите. Целта е да избираш подходящи действия и да проверяваш с тестове какъв резултат получаваш.

1. От число до представяне

Една числова стойност може да се запише в различни бройни системи. Например десетичното 10 е 1010 в двоична система и A в шестнадесетична. При позиционния запис стойността на цифрата зависи от мястото: 1010 в основа 2 означава 1·2³ + 0·2² + 1·2¹ + 0·2⁰ = 10.

За преобразуване от десетична към друга основа делим последователно на основата и четем остатъците отзад напред. За обратното преобразуване събираме цифрите, умножени по съответните степени на основата. Не смесвай стойността с нейния запис.

2. От условие до алгоритъм

Определи входа, допустимите стойности и търсения изход. Раздели решението на крайни, ясни стъпки. Последователността изпълнява действия по ред; разклонението избира според условие; цикълът повтаря. Преди да пишеш код, проследи малък пример на хартия.

4. Обща практическа задача

Дадени са четири неотрицателни цели стойности. Въвеждаме праг. Намираме броя и сумата на стойностите, които са поне равни на прага. Равенството е част от условието; нулата също може да се брои. Изходът е първо броят, после сумата, всеки на отделен ред.

5. Избери, преброй и събери

За праг 10 избираме 12 и 20. Алгоритъмът е еднакъв: начални резултати, обхождане, условно натрупване и изход.

Въведи последователно: 10. След всяка стойност натисни Enter.

Python

values = [12, 0, 7, 20]
threshold = int(input())
count = 0
total = 0
for value in values:
    if value >= threshold:
        count = count + 1
        total = total + value
print(count)
print(total)

C#

using System;

int[] values = new int[] { 12, 0, 7, 20 };
int threshold = int.Parse(Console.ReadLine() ?? "");
int count = 0;
int total = 0;
foreach (int value in values)
{
    if (value >= threshold)
    {
        count = count + 1;
        total = total + value;
    }
}
Console.WriteLine(count);
Console.WriteLine(total);

Изход на двете програми:

2
32

6. Сравни езиците

Python определя блоковете чрез отстъпите и свързва имената със стойности. В C# декларираме типа на променливите и ограждаме блоковете с фигурни скоби. Python списъкът може да променя дължината си, а C# масивът има фиксирана дължина след създаването. В този пример само четем елементите, така че не ни е нужен индекс.

Синтаксисът е различен, но правилността идва от същия алгоритъм. Входът в примерите трябва да е валидно цяло число в допустимите за C# int граници, а сумата трябва също да се побира в int.

7. Провери и обясни

Изпълнение без съобщение за грешка не доказва верен резултат. Изчисли очаквания изход самостоятелно. Провери границата на условието, липсата на съвпадения, всички съвпадения, повторените стойности и празната структура, ако е допустима. При разлика проследи променливите стъпка по стъпка.

За самоподготовка разшири задачата: намери първия индекс над прага и замени само този елемент с 0. Изведи началните и крайните данни и обясни защо броят и сумата, пресметнати преди замяната, не се обновяват сами.

8. Самостоятелни задачи

  1. Запиши десетичното 13 в двоична и шестнадесетична система.
  2. Какво ще се промени в основния пример, ако >= стане > при праг 20?
  3. Защо броят при праг 0 е 4, макар един елемент да е 0?
  4. Кога може да се приложи двоично търсене и защо основната структура не е подходяща?
  5. Кои два различни смисъла имат count и total?
Отговори и насоки
  1. 1101 в двоична, D в шестнадесетична.
  2. Няма избрани стойности; изходът е 0 и 0.
  3. Нулата изпълнява условието >= 0 и заема една позиция, но не увеличава сумата.
  4. При възходящо подредени данни; [12, 0, 7, 20] не е подредена.
  5. count брои подходящите позиции; total събира стойностите им.

Запомни: Уточни задачата, избери алгоритъм, проследи данните и сравни резултата с предварително изчислени тестове.
