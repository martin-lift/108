Програмиране - Контролна работа върху масиви и списъци

Приложи знанията си за едномерни структури, индекси, обхождане, търсене и промяна.

Общо: 30 точки. Покажи проследяването и обоснови избраните конструкции. При четене на код предвиди резултата, преди да го изпълниш. За задачите за съставяне дай решения на Python и C#.

1. Индекси и достъп — 4 точки

За структурата [6, 2, 9, 2] запиши дължината, първия и последния допустим неотрицателен индекс и стойността на индекс 2. Обясни защо индекс, равен на дължината, не е допустим.

2. Проследяване — 6 точки

Използвай кода в края. Запиши всички изходни редове, крайното съдържание на структурата и стойността на count след всяко повторение. Обясни защо за замяната е нужен индекс.

3. Съставяне на програма — 12 точки

Дадена е структура [5, 3, 5, 8]. Въведи търсена и нова цяла стойност. Замени само първото срещане на търсената стойност и изведи индекса му. Ако липсва, изведи съобщение и не променяй елементите. Накрая покажи всички стойности.

Разпредели решението на вход и подготовка (2 т.), правилно търсене на първо срещане (4 т.), безопасна проверка и замяна (4 т.), изход (2 т.). Дай решения на двата езика.

4. Избор на търсене — 4 точки

За [9, 1, 7, 3] и [1, 3, 7, 9] посочи кога може да се използва двоично търсене и защо. Обясни какво означава low > high и дали основният вариант гарантира първото срещане при повторения.

5. Тестове — 4 точки

За задача 3 запиши входове и очаквани крайни структури за: намерен първи елемент, намерен последен елемент, липсваща стойност и нова стойност, равна на старата. Включи проверка, че при повторение се заменя само първото срещане.

6. Код за проследяване

Python

values = [3, 0, 3]
count = 0
for i in range(len(values)):
    if values[i] > 0:
        count = count + 1
    else:
        values[i] = 9
print(count)
for value in values:
    print(value)

C#

using System;

int[] values = new int[] { 3, 0, 3 };
int count = 0;
for (int i = 0; i < values.Length; i = i + 1)
{
    if (values[i] > 0)
    {
        count = count + 1;
    }
    else
    {
        values[i] = 9;
    }
}
Console.WriteLine(count);
foreach (int value in values)
{
    Console.WriteLine(value);
}

7. Проверка преди предаване

  • Описани ли са допустимите входни стойности?
  • Показани ли са промените в променливите и очакваните резултати?
  • Проверени ли са границите, равните стойности и празният случай, когато е допустим?
  • Съвпадат ли алгоритмите на двата езика?
