Програмиране - Оператори за сравнение и логически изрази

В урок 24 въведохме логическите стойности и направихме първи сравнения. След аритметичните упражнения вече можем да проверяваме твърдения за данните и изчислените резултати. В този урок извеждаме дали твърдението е вярно; още не избираме различни действия в програмата.

1. Логически израз и резултат

Логически израз е израз, който в разглежданите примери получава стойност от типа bool: вярно или невярно. Например „броят е поне 10“ може да е вярно за един вход и невярно за друг.

В Python литералите са True и False, а в C# — true и false. При използваното конзолно извеждане и двата езика показват True или False. Не бъркай този изходен текст с начина, по който записваш литерала в C# кода.

2. Шест оператора за сравнение

СмисълPython и C#ПримерРезултат
Равно==5 == 5Вярно
Различно!=5 != 5Невярно
По-малко<3 < 5Вярно
По-малко или равно<=5 <= 5Вярно
По-голямо>3 > 5Невярно
По-голямо или равно>=5 >= 5Вярно

Записите са еднакви в двата езика. Използвай двата отделни знака <= и >= в кода, а не математическите символи ≤ и ≥. За „различно“ записът е !=, а не ≠.

3. Провери шестте сравнения

При равни числа строгите сравнения < и > са неверни, а сравненията <= и >= са верни. Редът на изходните стойности съответства на реда на инструкциите.

Python

a = 5
b = 5
print(a == b)
print(a != b)
print(a < b)
print(a <= b)
print(a > b)
print(a >= b)

C#

using System;

int a = 5;
int b = 5;
Console.WriteLine(a == b);
Console.WriteLine(a != b);
Console.WriteLine(a < b);
Console.WriteLine(a <= b);
Console.WriteLine(a > b);
Console.WriteLine(a >= b);

Изход на двете програми:

True
False
False
True
False
True

4. Присвояване и сравнение

От урок 23 знаеш, че = задава стойност. При quantity = 10 променяме quantity. При quantity == 10 само проверяваме дали текущата стойност е 10. Самото сравнение не променя quantity.

Логическият резултат може да се пази в променлива с ясно име. В C# я декларираме като bool. В Python името получава логическата стойност от израза.

5. Провери минимален брой

Условието е „поне 10“, затова самата граница 10 трябва да се приема. Второто извеждане показва, че проверката не е променила входната стойност.

Въведи последователно: 10. След всяка стойност натисни Enter.

Python

quantity = int(input())
has_minimum = quantity >= 10
print(has_minimum)
print(quantity)

C#

using System;

int quantity = int.Parse(Console.ReadLine() ?? "");
bool hasMinimum = quantity >= 10;
Console.WriteLine(hasMinimum);
Console.WriteLine(quantity);

Изход на двете програми:

True
10

6. Гранични случаи

Граничен случай е вход близо до стойност, при която резултатът от условието се променя. За „поне 10“ провери 9, 10 и 11. Това различава правилното >= от погрешно използваното >.

quantityquantity > 10quantity >= 10
9НевярноНевярно
10НевярноВярно
11ВярноВярно

Свързвай думите с точния оператор: „над 10“ означава > 10; „поне 10“ — >= 10; „под 10“ — < 10; „най-много 10“ — <= 10. Уточняването на границата е част от разбирането на задачата.

7. Сравняване на резултат от изчисление

В логическия израз могат да участват и аритметични действия. Първо намираме числовите стойности, после ги сравняваме. Скобите могат да направят намерението по-ясно.

8. Побира ли се покупката в бюджета?

Общата цена е 12, а 12 <= 10 е невярно. Еквивалентна проверка е (quantity * unit_price) <= budget в Python и (quantity * unitPrice) <= budget в C#. Числовата формула е позната от предишните уроци.

Python

quantity = 4
unit_price = 3
budget = 10
total = quantity * unit_price
fits_budget = total <= budget
print(total)
print(fits_budget)

C#

using System;

int quantity = 4;
int unitPrice = 3;
int budget = 10;
int total = quantity * unitPrice;
bool fitsBudget = total <= budget;
Console.WriteLine(total);
Console.WriteLine(fitsBudget);

Изход на двете програми:

12
False

9. Текст и съвместими типове

С == и != можем да сравняваме и текстове. За обикновените низове в следващия пример главните и малките букви и интервалите имат значение. „Да“ и „да“ са различни текстове, както и „да“ и „да “ с интервал накрая.

10. Провери текстов запис

Не се извършва автоматично изравняване на главни и малки букви. При текстов вход провери и дали потребителят не е добавил допълнителни интервали.

Python

answer = "Да"
print(answer == "Да")
print(answer == "да")
print(answer != "да")

C#

using System;

string answer = "Да";
Console.WriteLine(answer == "Да");
Console.WriteLine(answer == "да");
Console.WriteLine(answer != "да");

Изход на двете програми:

True
False
True

За числово сравнение първо преобразувай числовия текст, както в урок 25. Числото 12 и текстът "12" не са едно и също. Python връща False при равенство между тези конкретни стойности, а пряко сравнение с == между int и string в C# не е допустимо. Не използвай текстов запис вместо числова величина.

При float и double точността е ограничена, както в урок 24. След пресмятане с дроби точното равенство може да не съответства на очакването от десетичната формула. Не приемай показаните два дробни знака от форматирането като доказателство за точна вътрешна стойност.

11. Упражнения

  1. Предвиди резултатите: 7 != 9; 7 >= 7; 7 < 7; 0 == 0.
  2. Запиши условие за „брой най-много 20“ и провери 19, 20 и 21.
  3. Запиши условие за „температура под 0“ и провери −1, 0 и 1.
  4. За покупка на 5 артикула по 2 и бюджет 10 какъв е резултатът от total <= budget? А от total < budget?
  5. Каква е разликата между count = 5 и count == 5?
  6. Защо текстовете "007" и "7" са различни, въпреки че могат да обозначават едно и също число след подходящо преобразуване?
Отговори за самопроверка
  1. True, True, False, True.
  2. count <= 20; True, True, False.
  3. temperature < 0; True, False, False.
  4. Общата цена е 10; първата проверка е True, втората — False.
  5. Първото присвоява, второто проверява текущата стойност и дава bool.
  6. Низовете имат различни последователности от символи.

Запомни: сравнението дава логически резултат и не присвоява нова стойност на сравняваните променливи. Проверката точно на границата помага да различиш < от <= и > от >=.
