Програмиране - Цикъл с предварително условие

При while условието се проверява преди всяка итерация, включително преди първата. Затова тялото може да не се изпълни нито веднъж.

1. Зависимост от входа

В урок 45 краят беше зададен в кода. Сега потребителят ще въведе неотрицателно цяло n. Ще броим от n надолу до 1. При 0 няма число за извеждане и преминаваме направо след цикъла.

2. Обратно броене

Всяка итерация намалява положителното n с 1, така че в крайна сметка то достига 0.

Въведи последователно: 3. След всяка стойност натисни Enter.

Python

n = int(input())
while n > 0:
    print(n)
    n = n - 1
print("Готово")

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
while (n > 0)
{
    Console.WriteLine(n);
    n = n - 1;
}
Console.WriteLine("Готово");

Изход на двете програми:

3
2
1
Готово

3. Проверката е преди тялото

При n = 1 проверката е вярна, показваме 1 и намаляваме до 0. Едва след това отново проверяваме. Втората проверка е невярна, затова не показваме 0. Ако задачата иска и нулата, условието и броят повторения трябва да бъдат променени съзнателно.

4. Изведи четни числа до граница

За този пример входът е цяла граница от 0 до 10000. След последното извеждане броячът се увеличава още веднъж; избраният предел осигурява, че и тази стойност се побира в C# int. Стъпка е промяната на брояча между две последователни итерации. Стъпката 2 прескача нечетните стойности. При граница под 2 няма изходни редове.

Въведи последователно: 6. След всяка стойност натисни Enter.

Python

limit = int(input())
i = 2
while i <= limit:
    print(i)
    i = i + 2

C#

using System;

int limit = int.Parse(Console.ReadLine() ?? "");
int i = 2;
while (i <= limit)
{
    Console.WriteLine(i);
    i = i + 2;
}

Изход на двете програми:

2
4
6

5. Промяна на входната променлива

В обратното броене използвахме самото n и след цикъла то е 0. Ако първоначалният вход е нужен по-късно, запази го и използвай отделен брояч. Във втория пример limit остава непроменено, а се променя i.

Не поставяй празна точка и запетая след while в C#: това би отделило празно тяло от желания блок. Използвай еднакво ясно оформление на всеки цикъл.

6. Самостоятелни задачи

  1. Направи обратно броене, което включва 0.
  2. Проследи четната редица при limit = 7.
  3. Запази първоначалното n в отделна променлива.
  4. Кое доказва, че обратното броене приключва?
Отговори и насоки
  1. При неотрицателен вход използвай условие n >= 0 и намалявай n.
  2. 2, 4, 6; след тях i става 8 и проверката е невярна.
  3. Използвай i = n и променяй i, а не n.
  4. Неотрицателната стойност намалява към границата с фиксирана положителна стъпка.

Запомни: Условието се проверява преди всяко повторение. Нулата итерации е нормален случай, който трябва да се тества.
