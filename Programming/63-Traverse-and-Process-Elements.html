Програмиране - Обработка на едномерен масив или списък чрез цикъл

Ще приложим едно и също действие върху всеки запазен елемент. Можем да обхождаме по индекс или направо по стойност.

1. Кога е нужен индексът?

Когато променяме елемент или ни трябва позицията му, обхождаме индексите от 0 до дължината минус 1. Когато само прочитаме стойности, можем да използваме for value in values в Python или foreach (int value in values) в C#.

Обхождане означава последователно посещаване на елементите. foreach е новият тук C# запис: тялото се изпълнява за всяка стойност на масива в реда на позициите.

2. Промени по индекс и покажи по стойност

Първото обхождане заменя всяка стойност с двойната. Второто само показва елементите, без да използва индекс.

Python

values = [3, 1, 4]
for i in range(len(values)):
    values[i] = values[i] * 2
for value in values:
    print(value)

C#

using System;

int[] values = new int[] { 3, 1, 4 };
for (int i = 0; i < values.Length; i = i + 1)
{
    values[i] = values[i] * 2;
}
foreach (int value in values)
{
    Console.WriteLine(value);
}

3. Променлива в цикъла или елемент?

В Python присвояването value = value * 2 в цикъл по стойност не заменя целочисления елемент в списъка. То свързва името value с друг резултат. За промяна използвай values[i] = ... . В C# не присвояваме нова стойност на променливата от този foreach; за замяна на int елемент също използваме индексния for.

4. Сума при обхождане по стойност

Няма нужда от позиция, защото само натрупваме сумата. За празна структура началното total остава 0.

Python

values = [3, -1, 4]
total = 0
for value in values:
    total = total + value
print(total)

C#

using System;

int[] values = new int[] { 3, -1, 4 };
int total = 0;
foreach (int value in values)
{
    total = total + value;
}
Console.WriteLine(total);

5. Едно преминаване

Във всеки от циклите всеки елемент се посещава точно веднъж. За n елемента има n повторения. Проверявай дали границата е самата дължина, а не предварително написано число 3: така алгоритъмът остава правилен при друга дължина.

6. Самостоятелни задачи

  1. Замени умножението по 2 с добавяне на 5 към всеки елемент.
  2. Изведи позиция и стойност за всяка позиция.
  3. Кой цикъл е удобен само за сумата?
  4. Защо промяна на value не е замяна на values[i] в Python?
Отговори и насоки
  1. Използвай values[i] = values[i] + 5.
  2. Нужен е индексен цикъл.
  3. Цикъл по стойност: for value / foreach.
  4. Името и позицията в структурата са различни цели на присвояване.

Запомни: Използвай индекс, когато променяш или показваш позиция; използвай стойност, когато позицията не е нужна.
