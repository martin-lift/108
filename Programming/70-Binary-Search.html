Програмиране - Търсене в подреден списък

В подредени данни можем да отхвърляме големи части от възможните позиции. Ще въведем двоично търсене.

1. Необходимо условие: възходящ ред

Възходящо подредена поредица има всеки следващ елемент по-голям или равен на предишния. Двоично търсене сравнява търсената стойност със средния елемент на оставащия участък. Ако тя е по-голяма, търсим вдясно; ако е по-малка — вляво.

Този извод е верен заради подредбата. В неподредена структура използвай линейно търсене. Двоичното търсене само по себе си не подрежда данните.

2. Граници на оставащия участък

low и high са включени крайни индекси. В началото low е 0, а high е дължината минус 1. Докато low ≤ high, участъкът не е празен. Средният индекс е low + половината от разликата high − low, взета като цяло число.

В Python целочисленото деление тук се записва с //, а в C# делението на две int стойности дава цял резултат с /. Разликата в този алгоритъм е неотрицателна. След неуспешно сравнение изключваме и средната позиция: low = middle + 1 или high = middle − 1.

3. Търсене чрез стесняване на участъка

Всеки неуспешен опит оставя приблизително половината позиции. При празна структура high е −1 и цикълът изобщо не започва.

Въведи последователно: 12. След всяка стойност натисни Enter.

Python

values = [2, 5, 8, 12, 16, 23]
target = int(input())
low = 0
high = len(values) - 1
position = -1
while low <= high:
    middle = low + (high - low) // 2
    if values[middle] == target:
        position = middle
        break
    elif values[middle] < target:
        low = middle + 1
    else:
        high = middle - 1
if position == -1:
    print("Не е намерено")
else:
    print(position)

C#

using System;

int[] values = new int[] { 2, 5, 8, 12, 16, 23 };
int target = int.Parse(Console.ReadLine() ?? "");
int low = 0;
int high = values.Length - 1;
int position = -1;
while (low <= high)
{
    int middle = low + (high - low) / 2;
    if (values[middle] == target)
    {
        position = middle;
        break;
    }
    else if (values[middle] < target)
    {
        low = middle + 1;
    }
    else
    {
        high = middle - 1;
    }
}
if (position == -1)
{
    Console.WriteLine("Не е намерено");
}
else
{
    Console.WriteLine(position);
}

5. Граници и повторения

Условието трябва да допуска low == high: и една останала позиция заслужава проверка. При липса границите се разминават. Преместване само до middle, без +1 или −1, може да остави същия участък и цикълът да не завърши.

Ако има повторени стойности, този вариант намира някое срещане, не непременно първото. За [4, 4, 4] и цел 4 той връща индекс 1. Не го заменяй без промяна в задача, изискваща първия индекс.

Линейното търсене може да провери всички n позиции. Двоичното многократно дели участъка приблизително на две: при 8 подредени елемента са достатъчни най-много 4 сравнения със среден елемент. Предимството се заплаща с изискването за подредени данни.

6. Самостоятелни задачи

  1. Проследи търсенето на 9 в основния пример.
  2. Провери едноелементна поредица [5] при цели 5 и 6.
  3. Защо алгоритъмът не е подходящ за [8, 2, 5]?
  4. След произволна замяна на елемент може ли веднага да продължим с двоично търсене?
Отговори и насоки
  1. Сравняваме с 8, 16 и 12; накрая low = 3, high = 2 и няма резултат.
  2. За 5 получаваме индекс 0; за 6 — липса след едно сравнение.
  3. Подредбата е нарушена и отхвърлянето на половина не е обосновано.
  4. Само ако възходящият ред е запазен. Иначе използвай линейно търсене.

Запомни: Двоичното търсене изисква подредба и строго намаляващ оставащ участък.
