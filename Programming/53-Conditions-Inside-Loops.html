Програмиране - Съчетаване на условни и циклични конструкции

Ще изпълняваме едно и също условие за всяка нова стойност. Цикълът определя колко данни се посещават, а if — кои от тях се обработват допълнително.

1. Проверка за всяка стойност

Въвеждаме n цели числа. Търсим само тези от затворения интервал [10, 20]. Всички n числа трябва да бъдат прочетени, дори когато част от тях не отговарят на условието. Условното извеждане и увеличаването на брояча са в едно и също разклонение.

2. Изведи и преброй стойности в интервал

Входът започва с неотрицателен брой. Границите 10 и 20 се включват. Последното извеждане е извън цикъла.

Въведи последователно: 4, 9, 10, 20, 21. След всяка стойност натисни Enter.

Python

n = int(input())
selected_count = 0
for i in range(n):
    value = int(input())
    if (value >= 10) and (value <= 20):
        print(value)
        selected_count = selected_count + 1
print("Брой:", selected_count)

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
int selectedCount = 0;
for (int i = 0; i < n; i = i + 1)
{
    int value = int.Parse(Console.ReadLine() ?? "");
    if ((value >= 10) && (value <= 20))
    {
        Console.WriteLine(value);
        selectedCount = selectedCount + 1;
    }
}
Console.Write("Брой: ");
Console.WriteLine(selectedCount);

Изход на двете програми:

10
20
Брой: 2

3. Две нива на принадлежност

Прочитането на value е в цикъла, но извън if: то трябва да се изпълнява всяка итерация. Извеждането на избрана стойност е едновременно в цикъла и в условния блок. Извеждането на общия брой е след цикъла.

В Python това са три различни нива на отстъп. В C# ги показват вложените фигурни скоби. Ако преместим крайния брой в тялото, ще виждаме междинни броячи, а при n = 0 няма да видим резултат.

4. Избрани стойности и повторения

Повторени стойности се обработват при всяко срещане. За 15, 15, 10 броят е 3, а не 2 различни числа. Ако задачата изисква различни стойности, това е друго условие и не се решава с този прост брояч.

За сума на избраните добави начална сума 0 преди цикъла и увеличавай сумата с value само във верния клон. Не използвай брояча вместо сумата.

5. Самостоятелни задачи

  1. Избери само четните числа.
  2. Добави сума на стойностите в интервала.
  3. Защо входът трябва да остане извън условния клон?
  4. Какъв е изходът за 10, 9, 20, 20?
Отговори и насоки
  1. Условието е value % 2 == 0.
  2. Инициализирай selected_total и добавяй value във верния клон.
  3. Всяка от n стойности трябва да бъде прочетена.
  4. 10, 20, 20 и краен брой 3.

Запомни: Цикълът посещава всички данни; условието избира кои събития да се броят или кои стойности да се обработват.
