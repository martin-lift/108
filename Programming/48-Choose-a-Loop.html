Програмиране - Избор на циклична конструкция според задачата. Упражнение

Вече познаваш while и for. Изборът зависи от това дали знаем броя повторения или приключваме при получаване на определена стойност.

1. Известен брой или условие за край?

СитуацияУдобен избор
Покажи първите n числаfor
Прочети точно n стойностиfor
Чети до специална стойностwhile
Повтаряй, докато проверка стане вярнаwhile

Това е избор за четимост: много задачи могат да се решат и с двата цикъла. Важни са началото, условието и промяната, а не само името на конструкцията.

2. Чети до стойност за край

Стойността 0 е сигнал за край: не е обикновена обработвана стойност и не се извежда. Преди цикъла прочитаме първата стойност, а в края на всяка итерация — следващата.

Въведи последователно: 5, -2, 0. След всяка стойност натисни Enter.

Python

number = int(input())
while number != 0:
    print(number)
    number = int(input())

C#

using System;

int number = int.Parse(Console.ReadLine() ?? "");
while (number != 0)
{
    Console.WriteLine(number);
    number = int.Parse(Console.ReadLine() ?? "");
}

Изход на двете програми:

5
-2

3. Защо са нужни двете места за вход?

Първото прочитане осигурява стойност за първата проверка. Следващото променя проверяваните данни. Ако забравим входа в тялото, една ненулева стойност ще се извежда безкрайно. Ако обработим данните преди проверката, може погрешно да включим сигнала 0 в резултатите.

4. Същата идея за точно три входа

Тук броят е предварително известен: прочитаме точно три реда. Нулата вече е обикновена стойност и не прекратява цикъла.

Въведи последователно: 5, 0, -2. След всяка стойност натисни Enter.

Python

for i in range(3):
    number = int(input())
    print(number)

C#

using System;

for (int i = 0; i < 3; i = i + 1)
{
    int number = int.Parse(Console.ReadLine() ?? "");
    Console.WriteLine(number);
}

Изход на двете програми:

5
0
-2

5. Провери договора за вход

Потребителят трябва да знае дали първо се въвежда брой, или се очаква сигнал за край. Не смесвай двата начина в една задача без ясни указания. При поток със сигнал трябва да има подадена крайна стойност; при фиксиран брой трябва да има достатъчно редове.

6. Самостоятелни задачи

  1. Избери цикъл за прочитане на броя дни в седмицата и по една температура за всеки ден.
  2. Какво е първото действие преди while в първия пример?
  3. Промени сигнала за край на −1.
  4. Защо 0 може да е данни във втория пример, но не и в първия?
Отговори и насоки
  1. За точно седем температури е удобен for със седем повторения.
  2. Прочитане на число.
  3. Проверката става number != -1; вече 0 може да бъде обработвано.
  4. Различен е договорът за приключване на входа.

Запомни: Избирай цикъл според начина на приключване. Сигналът за край не трябва да се обработва като обикновена стойност.
