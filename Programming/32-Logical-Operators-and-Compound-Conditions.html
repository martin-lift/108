Програмиране - Логически оператори. Съставни условия

В урок 31 едно сравнение отговаряше на един въпрос. Често обаче трябва да проверим няколко изисквания заедно: например число да е едновременно не по-малко от 10 и не по-голямо от 20. За това използваме логически оператори.

1. И, ИЛИ и НЕ

Съставно условие е логически израз, получен чрез свързване или отрицание на условия. В този урок работим с операнди от типа bool.

ДействиеPythonC#Кога е вярно?
Логическо Иand&&Когато и двете условия са верни.
Логическо ИЛИor||Когато поне едно условие е вярно.
Логическо НЕnot!Когато условието след него е невярно.

„ИЛИ“ тук е включващо: ако и двете условия са верни, резултатът също е вярно. „НЕ“ има един операнд и обръща логическата му стойност.

2. Таблици на истинност

Таблица на истинност показва резултата за всички възможни съчетания на логическите стойности. Нека A и B са две условия.

ABA И BA ИЛИ B
FalseFalseFalseFalse
FalseTrueFalseTrue
TrueFalseFalseTrue
TrueTrueTrueTrue
AНЕ A
FalseTrue
TrueFalse

При bool операнди в тези примери Python и C# получават еднакви логически резултати. В Python and и or могат да работят и с други видове стойности и да върнат самите операнди; тук използваме само логически проверки.

3. Число в затворен интервал

Интервал е множество от числови стойности между граници. В затворен интервал границите се включват. За интервала [10, 20] условието е едновременно x >= 10 и x <= 20.

4. Провери двете граници

И двете сравнения трябва да са верни. При 10 и 20 условието е изпълнено, а при 9 и 21 — не. Скобите ясно отделят двете проверки.

Въведи последователно: 10. След всяка стойност натисни Enter.

Python

x = int(input())
is_inside = (x >= 10) and (x <= 20)
print(is_inside)

C#

using System;

int x = int.Parse(Console.ReadLine() ?? "");
bool isInside = (x >= 10) && (x <= 20);
Console.WriteLine(isInside);

Изход на двете програми:

True

В Python е допустим и краткият запис 10 <= x <= 20. C# не поддържа тази верига от сравнения като проверка за интервал; там изписваме двете сравнения с &&. Общият запис чрез две проверки е удобен за сравнение на езиците.

Ако условието изисква отворен интервал (10, 20), границите не се включват: използвай x > 10 и x < 20. Тогава 10 и 20 вече дават False.

5. Поне една възможност и отрицание

Можем да прочетем учебен текст, ако имаме печатен екземпляр или електронен достъп. Достатъчна е поне една от двете възможности; и двете едновременно също са достатъчни.

6. Съчети две възможности

ИЛИ дава True, защото има електронен достъп. Отрицанието на получения True е False. Имената пазят смисъла на всяка логическа стойност.

Python

has_book = False
has_digital_access = True
can_read = has_book or has_digital_access
print(can_read)
print(not can_read)

C#

using System;

bool hasBook = false;
bool hasDigitalAccess = true;
bool canRead = hasBook || hasDigitalAccess;
Console.WriteLine(canRead);
Console.WriteLine(!canRead);

Изход на двете програми:

True
False

7. Извън интервала

За число извън [10, 20] е достатъчно да е под долната граница или над горната. Това е x < 10 или x > 20. Същото получаваме, като отречем цялото условие за принадлежност.

8. Провери извън границите по два начина

При x = 21 числото е над горната граница. Ако замениш 21 с 10 или 20, и двата изходни реда трябва да станат False. Отрицанието се отнася за целия логически резултат, а не само за една от проверките.

Python

x = 21
is_inside = (x >= 10) and (x <= 20)
is_outside = (x < 10) or (x > 20)
print(is_outside)
print(not is_inside)

C#

using System;

int x = 21;
bool isInside = (x >= 10) && (x <= 20);
bool isOutside = (x < 10) || (x > 20);
Console.WriteLine(isOutside);
Console.WriteLine(!isInside);

Изход на двете програми:

True
True

9. Скоби и приоритет

Когато операндите вече са логически стойности, НЕ е с по-висок приоритет от И, а И — от ИЛИ. За яснота отделяй сравненията със скоби и ограждай целия израз, който отричаш: not (x == 5) в Python и !(x == 5) в C#. Приоритетът на not спрямо сравненията в Python и на ! в C# не е еднакъв, затова този изричен запис е по-ясен.

10. Различи две групирания

Първият израз е a ИЛИ (b И c), затова дава True. Вторият изисква резултатът от (a ИЛИ b) да е едновременно верен с c; понеже c е False, резултатът е False.

Python

a = True
b = False
c = False
print(a or b and c)
print((a or b) and c)

C#

using System;

bool a = true;
bool b = false;
bool c = false;
Console.WriteLine(a || b && c);
Console.WriteLine((a || b) && c);

Изход на двете програми:

True
False

11. Кога второто условие не се пресмята?

Съкратено изчисляване означава, че вторият операнд се пресмята само ако е нужен за резултата. При И, ако първият е False, целият резултат вече е False. При ИЛИ, ако първият е True, целият резултат вече е True.

Така работят and и or в Python и && и || в C#. В този урок не ги заменяме със знаците & и |: това са други оператори с различни правила за изчисляване.

12. Избягвай деление на нула в проверката

Въведи неотрицателно цяло число. При 0 първата проверка е False и делението изобщо не се извършва. При положителна стойност се изчислява цялото частно и се сравнява с 2. Използваме правилата за деление от урок 27.

Въведи последователно: 0. След всяка стойност натисни Enter.

Python

divisor = int(input())
result = (divisor != 0) and (12 // divisor > 2)
print(result)

C#

using System;

int divisor = int.Parse(Console.ReadLine() ?? "");
bool result = (divisor != 0)
    && (12 / divisor > 2);
Console.WriteLine(result);

Изход на двете програми:

False

Редът на проверките има значение за безопасността на това пресмятане: проверката за ненулев делител трябва да бъде първа. Тук извеждаме стойността на логическия израз, без още да пишем конструкция за избор между действия.

13. Упражнения

  1. Запиши на двата езика условие за x в затворения интервал [0, 100]. Провери −1, 0, 100 и 101.
  2. Промени условието за отворения интервал (0, 100). Как се променя резултатът при границите?
  3. Предвиди: True И False; True ИЛИ False; НЕ False.
  4. Условие за извън [0, 100] е записано като x < 0 И x > 100. Защо то не може да е вярно за едно обикновено цяло число? Поправи го.
  5. Провери израза с делителя при 0, 3 и 6. Защо е важно кое условие е първо?
  6. Покажи с пример, че „ИЛИ“ допуска и двете условия да са верни.
Отговори за самопроверка
  1. (x >= 0) and (x <= 100); в C# замени and с &&. Резултатите са False, True, True, False.
  2. Използвай > и <; при 0 и 100 резултатът става False.
  3. False; True; True.
  4. Едно число не може едновременно да е под 0 и над 100. Трябва or в Python или || в C#.
  5. False, True, False. При нулев делител първата проверка трябва да спре изчисляването преди делението.
  6. True or True и true || true дават вярно.

Запомни: И изисква всички свързани условия, ИЛИ — поне едно, а НЕ обръща резултата. Скобите и проверките на границите показват дали записът отговаря на смисъла на задачата.
