Програмиране - Търсене на стойност в масив или списък

Търсенето отговаря дали дадена стойност присъства и на коя позиция я намираме. Ще проверяваме последователно от първия елемент.

1. Линейно търсене

Линейно търсене сравнява елементите един след друг. То не изисква предварително подреждане. Ако е нужен първият индекс, можем да прекратим веднага при първото съвпадение.

Пазим position = −1 като знак „не е намерено“. −1 не е допустим неотрицателен индекс в общия модел. В Python той има специално значение при достъп, затова никога не използвай values[position], преди да провериш дали търсенето е успешно.

break в цикъл прекратява най-близкия обгръщащ цикъл. Това е различен контекст от C# break в switch от урок 40. След прекратяването изпълнението продължава след цикъла.

2. Намери първото съвпадение

При повторени стойности връщаме първия индекс. Индексът 0 е успешен резултат, а не липса.

Въведи последователно: 3. След всяка стойност натисни Enter.

Python

values = [8, 3, 5, 3]
target = int(input())
position = -1
for i in range(len(values)):
    if values[i] == target:
        position = i
        break
if position == -1:
    print("Не е намерено")
else:
    print(position)

C#

using System;

int[] values = new int[] { 8, 3, 5, 3 };
int target = int.Parse(Console.ReadLine() ?? "");
int position = -1;
for (int i = 0; i < values.Length; i = i + 1)
{
    if (values[i] == target)
    {
        position = i;
        break;
    }
}
if (position == -1)
{
    Console.WriteLine("Не е намерено");
}
else
{
    Console.WriteLine(position);
}

3. Колко сравнения са нужни?

Ако първият елемент съвпадне, е нужно едно сравнение. Ако стойността липсва, посещаваме всички n елемента. При празна структура цикълът няма повторения и position остава −1.

Ако премахнем break и продължим да задаваме position при всяко съвпадение, ще получим последната позиция. Това е друга задача; уточни дали се търси първа, последна или всяка позиция.

5. Самостоятелни задачи

  1. Потърси 3 в основния пример и запиши сравненията.
  2. Промени алгоритъма да намира последното съвпадение.
  3. Как да изведеш всички позиции без променлива за първи резултат?
  4. Защо position = 0 не е добро начално означение за липса?
Отговори и насоки
  1. 8 != 3; 3 == 3; резултат 1.
  2. Премахни break и запазвай всяко намерено i.
  3. Извеждай i при всяко съвпадение и продължи цикъла.
  4. 0 е валиден индекс на първия елемент.

Запомни: Изясни какъв резултат търсиш и използвай отделно означение за липса. Не достъпвай масива чрез −1.
