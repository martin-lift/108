Програмиране - Последователна проверка на няколко условия

Двата клона не са достатъчни, когато трябва да различим отрицателна стойност, нула и положителна стойност.

1. Верига от проверки

В Python използваме if, след него elif („иначе ако“) и по желание else. В C# съответният запис е if, else if, else. Проверяваме отгоре надолу и изпълняваме първия клон с вярно условие. Останалите условия във веригата не се проверяват.

Последният else обхваща всички случаи, които не са удовлетворили предишните проверки. Така трябва да мислим за данните, които остават след всеки отказ.

2. Класифицирай по знак

Всеки цял вход попада в точно един от трите случая.

Въведи последователно: 0. След всяка стойност натисни Enter.

Python

n = int(input())
if n < 0:
    print("Отрицателно")
elif n == 0:
    print("Нула")
else:
    print("Положително")

C#

using System;

int n = int.Parse(Console.ReadLine() ?? "");
if (n < 0)
{
    Console.WriteLine("Отрицателно");
}
else if (n == 0)
{
    Console.WriteLine("Нула");
}
else
{
    Console.WriteLine("Положително");
}

Изход на двете програми:

Нула

3. Ред на праговете

За „голямо количество“ при поне 100 и „средно“ при поне 10 проверяваме първо >= 100. Ако започнем с >= 10, стойността 120 ще попадне там и никога няма да стигне до проверката за 100. Това е логическа грешка, а не грешка в синтаксиса.

4. Подреди праговете от по-високия

Входът е неотрицателно цяло число. Когато стигнем второто условие, вече знаем, че count е под 100.

Въведи последователно: 120. След всяка стойност натисни Enter.

Python

count = int(input())
if count >= 100:
    print("Голямо")
elif count >= 10:
    print("Средно")
else:
    print("Малко")

C#

using System;

int count = int.Parse(Console.ReadLine() ?? "");
if (count >= 100)
{
    Console.WriteLine("Голямо");
}
else if (count >= 10)
{
    Console.WriteLine("Средно");
}
else
{
    Console.WriteLine("Малко");
}

Изход на двете програми:

Голямо

5. Верига или независими if?

Няколко отделни if са отделни конструкции: възможно е да се изпълнят няколко блока. Веригата if/elif/else или if/else if/else избира само един. Изборът зависи от задачата: една категория или всички изпълнени характеристики.

6. Самостоятелни задачи

  1. Добави случай за недопустимо отрицателно количество преди категоризирането.
  2. Защо 100 трябва да е „Голямо“, а 99 — „Средно“?
  3. Какво ще стане с 120, ако >= 10 бъде първият клон?
  4. За две независими характеристики „положително“ и „четно“ верига ли е подходяща?
Отговори и насоки
  1. Първият клон проверява count < 0.
  2. Това са съседните стойности от двете страни на границата.
  3. Ще бъде избран „Средно“ и веригата ще приключи.
  4. Не, използвай две отделни if, ако и двете съобщения са нужни.

Запомни: При верига се изпълнява първият подходящ клон. Подреждай условията според техните припокривания.
